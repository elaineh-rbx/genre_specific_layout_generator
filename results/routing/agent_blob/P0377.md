# Scene prompt

Create a 3D racing game map collection for Battle of the Racing Cars, with five separate compact one-lap circuit courses designed to be completed in roughly 1–2 minutes each. Build a tanghulu ASMR course, a chewy chocolate-cookie ASMR course, a pop-it ASMR course, a wax-bubble-ball ASMR course, and a keycap ASMR course; each track forms a closed loop through oversized props and themed surfaces associated with its ASMR material.

# Agent decision

## Genre

The dominant and sole genre is Racing: player-controlled cars complete finite, closed-loop races.

## Shape and preset

Use `route-circuit` as the one shape, instantiated as five separate compact closed loops. Match the Circuit Racing preset, retaining its starting grid, lap detection, and physical track barriers but dropping its 180-degree turnaround because each course is a continuous loop rather than an out-and-back route.

## Config requirements

Draw `spawn-grid` as a standardized multi-car starting front on each course and `barrier-guardrail` along exposed track edges. Add `startpoint-line` as a clearly visible start and completion stripe on each loop. The five environments must use oversized tanghulu, chewy chocolate-cookie, pop-it, wax-bubble-ball, and keycap props and material-themed driving surfaces respectively.

## Layout requirements

Place five `spawn-grid` arrays, one immediately behind each course’s start line. Place five `startpoint-line` markers and five `trigger-lap` detection regions across those same lines so crossing after a full circuit completes the single lap. Place `checkpoint-respawn` recovery points at safe intervals around every loop, aligned with forward track direction and away from hazards.

## Layout components

Create five isolated small maps, each containing one compact closed track sized for a roughly 1–2 minute lap. Give every loop a readable start straight, bends, a continuous drivable corridor, themed surface treatment, oversized matching ASMR props around and beside the route, and guardrails where cars could leave the course. Do not connect the five maps. Frame each circuit as a complete loop from above.

## Render order

Use `authored_plan`: generate each closed circuit blueprint first, then derive its top-down and isometric images. The authored loops are authoritative because every route must close without broken or ambiguous crossings.

## Scale, theme, and pipeline cost

The collection is large overall, comprising five separate compact courses. Its theme is playful oversized ASMR materials. Route with `P6` for valid racing circuits and `P4` because the five courses are separate maps.
