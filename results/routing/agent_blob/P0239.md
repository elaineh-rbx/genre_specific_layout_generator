# Scene prompt

Create a classic mini-golf layout with fifteen separate compact holes, entered in sequence. Each hole is a self-contained astroturf lane with a tee area, cup, bordered course edges, and simple colorful obstacles; include windmill-style decorations where appropriate.

# Agent decision

## Genre

The genre is Sports, specifically a directed target sport based on putting.

## Shape and preset

Use `range-directed`: each hole is a compact lane leading from one tee to one cup. The preset is Target Sport.

## Config requirements

Draw fifteen separate astroturf holes. Use `startpoint-play` as the visible tee area at the beginning of every hole, `trigger-scoring` as the cup and flag at each endpoint, and `trigger-bounds` as the raised bordered edges that contain the ball on the course. Use `marker-distance` sparingly as readable lane shaping and directional cues rather than numerical yardage. Add simple colorful obstacles and occasional windmill-style decoration without inventing a fixed obstacle count.

## Layout requirements

Place exactly fifteen `startpoint-play` ball-reset positions, one centered in each tee area. Place exactly fifteen functional `trigger-scoring` cup volumes, one at the reachable end of each lane. Place exactly fifteen `trigger-bounds` perimeters following the interior edge of each hole’s border. Add fourteen one-way sequence teleport exits, each after holes one through fourteen and linked to the next hole; the fifteenth hole ends the course.

## Layout components

Build fifteen self-contained compact hole maps. Every map contains one flat or gently shaped green astroturf lane, one tee, one cup, continuous raised edging, and a small arrangement of colorful bumpers, ramps, blocks, or tunnels. Windmill decorations appear only where they do not obscure the playable lane. Keep each hole visually independent, with no shared walking park or connecting path, and compose each frame from tee toward cup so the intended shot direction reads immediately.

## Render order

Render `topdown` first and make it authoritative, then dress each isometric view; each ball route must leave a viable path from tee to cup around its obstacles, while `authored_plan` is not available for golf holes.

## Scale, theme, and pipeline cost

Use a large aggregate scale because there are exactly fifteen maps, though every individual hole is small. The theme is classic colorful mini-golf with green astroturf and windmill accents. Apply `P4` because the fifteen holes are separate maps entered by teleport rather than one continuous park.
