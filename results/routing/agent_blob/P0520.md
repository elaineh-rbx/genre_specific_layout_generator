# Scene prompt
Create a 3D obby map built as a small, bright stylized tower: one continuous vertical climb of approximately 10 short stages, using colorful platforms and simple, readable obstacles.

# Agent decision
## Genre
The genre is Obby & Platformer, canonically `obby-platformer`: the author explicitly requests a parkour-style obby tower.

## Shape and preset
Use `course-tower` for a single uninterrupted vertical climb whose platforms stack above one another. Tower Obby is the matching preset, kept compact and immediately playable.

## Config requirements
Draw one physics-valid `path-track` of approximately ten short stages. Use `obstacle-jump` for straightforward platform gaps and stepped jumps, `obstacle-climb` for short ladders or truss ascents, and `obstacle-timing` sparingly for simple, clearly readable timing sections. Draw a broad final platform for `winner-zone`. Avoid hidden paths, precision shortcuts, and decorative complexity that would obscure the route.

## Layout requirements
Place one `winner-zone` at the top of the final stage, beyond the last safe landing. The compact course needs no additional checkpoints or pickups; failure returns to the tower’s base.

## Layout components
Build a small open-sided tower around one narrow footprint, beginning with a generous ground-level start pad. Arrange approximately ten short obstacle stages as one continuous upward spiral or zigzag, with a safe landing between obstacle types and no branches. Alternate bright jumping platforms, a simple climb, and one or two readable timing pieces while keeping every critical gap legal. Use saturated classic Roblox colors, clean block forms, contrasting obstacle edges, and minimal visual clutter. An open void surrounds the course, while lightweight rails and framing elements make each landing readable without enclosing the tower. Compose the view so the entry, full vertical route, and celebratory summit are all visible.

## Render order
Use `topdown`: the playable chain and legal jump spacing must be authoritative before the isometric render applies the bright stylized treatment.

## Scale, theme, and pipeline cost
Scale is small, driven by approximately ten short stages. The theme is bright, colorful, classic Roblox obby geometry. `P6` ensures the complete climb is valid by construction, and `P2` captures stacked platforms that overhang earlier stages.
