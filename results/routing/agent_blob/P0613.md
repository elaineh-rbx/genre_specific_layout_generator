# Scene prompt
Build a 3D realistic wilderness forest with muddy trails winding through dense trees, scattered rocks, and uneven off-road terrain for driving cars.

# Agent decision
## Genre
The dominant genre is Simulation. The player freely drives off-road cars through wilderness, with no lap, finish, hauling task, or competitive objective.

## Shape and preset
Use `world-open`, one shared forest map that drivers can explore in any order. The preset is Vehicle Sim, retaining the open vehicle world and drivable route network while dropping the unrelated shared resource field.

## Config requirements
Use `path-road-vehicle` for broad muddy off-road trails winding through the trees and linking the explorable clearings. Use `terrain-relief` for uneven ground, low ridges, dips, and slopes that make off-road driving spatially distinct. The image should include several drivable cars, dense realistic forest vegetation, and scattered rocks, but should not invent buildings, shops, or formal roads.

## Layout requirements
No canonical post-segmentation option is required. Place several vehicle spawn markers in a broad trailhead clearing, each aligned toward the trail network with enough side clearance. Place the player arrival marker beside that clearing and outside moving-vehicle paths. No checkpoint or winner placement is needed because exploration is open-ended.

## Layout components
Build a continuous forest floor crossed by a loose network of muddy vehicle-width trails. Start with a broad trailhead clearing, then branch into several routes that reconnect around dense tree stands so drivers can choose directions without immediately dead-ending. Include shallow mud basins, rocky edges, low climbs, and uneven ground, while keeping the actual driving corridors clear enough for cars. Trees should be dense beyond the routes but thinned near bends for visibility. Scatter rocks singly and in small clusters, avoiding impassable choke points. Use a natural forest edge, steep planted embankment, or dense vegetation belt as the outer boundary. Compose the trails and main clearing as the readable structure beneath the canopy.

## Render order
Use `isometric`: the realistic muddy forest look leads, and the forgiving free-roam trail network can be projected into top-down afterward without requiring exact race topology.

## Scale, theme, and pipeline cost
The scale is medium, enough for multiple off-road branches without implying a huge world. The theme is realistic wet wilderness. Use `tiered` for uneven relief on one surface; otherwise this is the `P0` baseline with no overhang or interior transition.
