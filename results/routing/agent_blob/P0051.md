# Scene prompt

Create a compact World War II-era 3D battlefield map viewed in third-person, with four separate player-built military bases spaced around the map. Each base has its own defensible area and open ground between bases, with travel routes short enough to cross on foot. Include a prominent tank as a battlefield threat.

# Agent decision

## Genre

The dominant genre is Strategy because territorial base construction, attack, and defense organize the map. Action is secondary because players directly traverse and fight on the battlefield as soldiers.

## Shape and preset

Use `terrain-open`: four bases occupy one contiguous field and attackers path dynamically across open ground rather than following fixed lanes. Use the Real-Time Strategy preset, omitting its unasked contested resource sites.

## Config requirements

Use `buildzone-plot` for exactly four broad, clearly separated buildable territories radiating around player bases. Use `tracker-core` to give each territory a fixed, defensible military headquarters at its heart. Draw one prominent World War II-era tank as a battlefield threat. Keep sightlines readable through open ground and avoid a hard-coded enemy lane.

## Layout requirements

Place exactly four `tracker-core` objectives, one centered in each base territory, with ownership and attack regions aligned to the visible headquarters. Define exactly four build zones around those cores, leaving neutral buffers between them. Place one hostile tank spawn on neutral ground and give it a patrol route that can approach every base without starting inside any player territory.

## Layout components

Build one compact battlefield with four defensible base plots distributed around the perimeter or cardinal quadrants and a shared neutral center. Connect all bases with short foot-travel roads, trenches, or worn tracks across open ground, avoiding long detours. Each plot needs a central headquarters footprint, perimeter room for player construction, and multiple attack approaches. Add one prominent tank, sparse wartime barriers, crates, and earthworks while preserving buildable space. Bound the map with natural ridges, ruined fencing, or distant battlefield scenery and show all four territories clearly in frame.

## Render order

Render in `topdown` order so the four territories, neutral spacing, and balanced short travel routes are authoritative before isometric dressing.

## Scale, theme, and pipeline cost

The scale is small, as requested, while still fitting four independent bases. The theme is a grounded stylized World War II battlefield. The route is `P0`: one open single-surface map requires no extra geometry pass.
