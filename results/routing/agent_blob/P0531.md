# Scene prompt
Create a bright, colorful, stylized 3D obby tower with 67 compact stacked stages, built and framed floor by floor for practical play. The tower rises vertically through sequential platform sections, with checkpoints between floors and a simple completion reward at the top.

# Agent decision
## Genre
The genre is Obby & Platformer: a long, ordered tower climb made of discrete platform challenges.

## Shape and preset
Use `course-tower` from the Tower Obby preset, expanded to exactly 67 compact stacked stages. Keep its sequential track and summit reward, add the requested inter-floor checkpoints, and omit specific timed or climbing obstacles because the brief does not name them.

## Config requirements
`path-track` forms 67 compact, physics-valid platform sections ascending floor by floor. `checkpoint-respawn` draws a flat, enclosed transition landing between every adjacent pair of stages. `winner-zone` is a simple, brightly marked completion platform at the top. The visual language is classic Roblox obby geometry in saturated, clearly separated colors.

## Layout requirements
Place 66 `checkpoint-respawn` markers, one on each safe landing between consecutive stages, so failure returns the player to the last completed floor. Place one `winner-zone` trigger centered on the final top platform. The start pad remains the default initial spawn rather than an additional checkpoint.

## Layout components
Build a ground-level start, 67 compact sequential stage volumes stacked vertically, 66 inter-floor landing pads, and one summit reward platform. Each floor contains a short ordered chain of simple platforms with legal gaps, and its exit aligns cleanly with the next floor’s protected landing. The repeated footprint keeps the tower practical while color changes distinguish neighboring stages and checkpoint pads. Open air surrounds the active course, with edge protection only on starts, checkpoints, and the finish. Treat each floor as a legible sectional unit; use a tall cutaway isometric composition that reveals several consecutive floors while clearly communicating that the same ordered stack continues to the 67th stage.

## Render order
Use `topdown`: establish each floor’s valid jump chain and every floor-to-floor handoff first, then dress the sectional isometric views from the plan.

## Scale, theme, and pipeline cost
Scale is huge in height because the tower contains exactly 67 stages, even though each floor is compact. The theme is bright, colorful, stylized classic Roblox obby. `P6` is required because all platform chains must be playable by construction. `P2` is required because 67 stacked floors overhang and occlude one another.
