# Scene prompt
Create a 3D hide-and-seek game with mouse-sized players moving through gigantic oversized environments. Include a simple lobby space between rounds, then make the bedroom the first playable map: a vast bedroom scaled around enormous furniture and objects that create hiding spaces and routes. Plan additional giant maps themed as a circus, swimming pool, garden, and trampoline park, each built from oversized environment features relative to the players.

# Agent decision
## Genre
The dominant genre is Party & Casual: this is explicitly a round-based hide-and-seek game.

## Shape and preset
Use `space-staged` so the lobby and each selected match map are isolated spaces. Match the Childhood Game preset, but substitute its continuous-space shape because the brief explicitly separates a lobby from multiple round maps.

## Config requirements
Apply `social-hub` for a simple full-server waiting lobby. Apply `cover-los` as dense clusters of enormous bedroom furniture and objects that break seeker sightlines and provide mouse-scale concealment. Apply `obstacle-maze` to form navigable hiding routes around and beneath the oversized furnishings. Apply `teleporter-link` visibly as the lobby departure and return portal.

## Layout requirements
Place `spawn-protected` as evenly distributed round-start markers in the bedroom, away from immediate seeker sightlines. Place both ends of `teleporter-link`: one in the lobby and one safe arrival/return point in each match map. Future circus, pool, garden, and trampoline-park maps need equivalent links when built.

## Layout components
Build a modest central lobby with an unobstructed portal area, then a separate vast bedroom as the first playable stage. The bedroom needs a readable circulation loop around a giant bed, wardrobe, desk, chair, drawers, and scattered toys, with mouse-scale routes beneath furniture, behind props, and through clutter clusters. Keep major hiding pockets connected rather than creating accidental dead ends. Treat the circus, swimming pool, garden, and trampoline park as four planned additional isolated maps, not simultaneous zones in the bedroom. Enclose the bedroom with walls; frame it to emphasize the extreme player-to-object scale.

## Render order
Use `topdown`: hiding-route connectivity and fair access around giant obstacles must be established before the isometric dressing.

## Scale, theme, and pipeline cost
Scale is huge, driven by five total themed maps and mouse-sized players, though only the bedroom is the initial detailed stage. The theme is playful domestic gigantism. Use `P4` for isolated lobby and match maps and `P6` because the hide-and-seek warren must remain navigable by construction.
