# Scene prompt
Create a 3D first-person sci-fi combat map inspired by a futuristic space-military arena. Build one medium-sized enclosed arena with open routes for running, scattered solid cover objects to hide behind, and positions for a fixed set of hostile alien enemies. Use generated mesh assets for the arena architecture, cover, and alien characters; compose the space for a first-person camera with clear sightlines and combat lanes.

# Agent decision
## Genre
The genre is Shooter, specifically a solo first-person PvE encounter against a fixed alien force.

## Shape and preset
Use `space-bounded` from outside Shooter’s usual shape list: one medium enclosed arena contains the complete encounter. Preset is none. PvE Shooter assumes wave origins, chokepoints, and an outside-to-inside structure, while this brief asks for a fixed enemy set in one arena.

## Config requirements
Use `cover-los` for scattered waist-high and full-body futuristic cover, distributed so the player can run between protected positions without eliminating clear firing lanes. Draw generated-mesh space-military walls, floor modules, cover pieces, and distinct alien combatants. Keep the arena interconnected and readable from first person, with no decorative clutter blocking the main routes.

## Layout requirements
Place one unkeyed player spawn near the arena edge behind initial cover, facing into the combat space. Place a fixed but unspecified number of unkeyed alien encounter positions around the arena, each grounded beside usable cover or on a readable sightline, with none directly overlapping the spawn. No `spawner-npc` is used because the enemies are a fixed set rather than waves entering over time.

## Layout components
The map is one bounded medium combat zone. A broad central engagement floor is crossed by several open running routes, while solid cover clusters create alternating safe pockets and exposed lanes. Peripheral recesses provide alien positions without becoming separate rooms. All paths reconnect across the same floor. Futuristic wall panels enclose the arena; the ground is hard sci-fi decking. Compose the scene so foreground cover, central combat space, and distant alien positions remain visible in one frame.

## Render order
Use `isometric`: the generated mesh language and cover composition are authoritative, with the straightforward arena plan derived afterward.

## Scale, theme, and pipeline cost
Scale is medium, driven by room to run and fight a fixed enemy group. The theme is futuristic space-military sci-fi. The route is `P0`; a single ground-level enclosed surface needs no overhang, transition, separate map, or procedural topology.
