# Scene prompt
Create a 3D third-person action roguelike map set in an abandoned underground stone temple, viewed from behind the explorer. The descent spans five procedurally arranged dungeon floors, each containing 6–10 compact 3D chambers crossed in seconds, connected by short corridors and ending at a visible downward stone stairway or lift passage to the newly generated floor below. Include small combat arenas, treasure chambers, merchant rooms, elite chambers, and rest rooms within the room network. Keep one unified temple style that grows progressively darker, more ruined, and more saturated in blue-violet tones on deeper floors, with stone walls, torchlight, and shadowed passages. The fifth and lowest floor culminates in a larger boss chamber for the Echo King, with an escape route from the temple beyond it.

# Agent decision
## Genre
Action is dominant because the authored game explicitly centers physical real-time combat. RPG is secondary because the roguelike has weapon progression, merchants, loot, and a five-floor dungeon structure.

## Shape and preset
Use `world-chaptered` for five procedurally regenerated floor maps loaded one after another. This shape comes from outside Action’s usual set and matches the explicit per-floor loading. Use the secondary RPG’s Dungeon Crawler preset with this substituted shape.

## Config requirements
Use `social-hub` for compact merchant chambers integrated into each floor’s room network rather than a separate town. Use `gate-progression` for the visible downward stairway or lift passage that remains the clear threshold to the next generated floor. Draw small combat, treasure, elite, rest, and merchant chambers as distinct room types, with the fifth-floor boss chamber substantially larger than ordinary rooms.

## Layout requirements
Place `spawner-npc` emitters inside combat, elite, and boss chambers, set away from room entrances and rest spaces. Place scene-specific treasure reward points within treasure chambers. Each floor needs one arrival marker and one descent destination, with the fifth floor instead linking the boss chamber to one escape destination beyond it. No journey checkpoints are required because restarting rather than saving mid-run defines the roguelike structure.

## Layout components
Generate exactly five floors, each with 6–10 compact chambers connected by short stone corridors. Mix the five requested ordinary room roles while preserving a traversable network from arrival to descent. Chambers should be crossable in seconds and combat rooms should hold one wave with enough clear floor for rolling. Floors are separate, not vertically co-visible. Use stone walls, torch niches, worn floors, shadowed passages, and increasingly ruined details; deepen darkness and blue-violet saturation with each descent. Floor five terminates in one larger Echo King arena and a readable escape route. Frame each floor from its arrival toward the first junction or chamber threshold.

## Render order
Use `topdown`: every procedural floor must have connected room topology, reachable special rooms, and a valid arrival-to-descent route before visual dressing.

## Scale, theme, and pipeline cost
Scale is large overall because there are five floors with 6–10 rooms each, though individual chambers are small. The theme is a unified abandoned subterranean stone temple, progressively darker and more blue-violet. Use `P4` because each descent loads a separate generated floor map.
