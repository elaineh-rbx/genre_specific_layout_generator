# Scene prompt
Create a 3D FPS map showing a colorful, slightly stylized Factory arena sized for 8 players. Build a compact looping layout through interconnected warehouses, conveyor-belt work areas, and accessible rooftops, with player spawns distributed around the loop rather than in opposing bases. Use interior warehouse routes and open rooftop sections to create a tight, readable combat space with both close-range cover and longer sightlines; frame the arena with factory structures and industrial walls.

# Agent decision
## Genre
The dominant genre is Shooter: Classic Gun Game is a fast free-for-all FPS in which eight players cycle through weapon ranges.

## Shape and preset
Use `warren-looping`, taken from outside Shooter’s usual set, for a compact factory circuit of interconnected routes with zero dead ends. The preset is Arena Deathmatch, substituting this loop-enforcing shape, retaining interconnected paths and elevated firing positions, dropping unrequested power-up pickups, and adding practical cover and distributed respawns.

## Config requirements
Use `path-loop` for warehouse rooms and work areas with at least two entrances or exits. Use `building-interior` for warehouse routes entered from exterior rooftop and yard sections. Use `cover-elevated` for accessible rooftops reached by exposed stairs or ladders. Use `cover-los` for machinery, crates, and conveyor structures that support close-range cover while preserving selected long sightlines. Use the visible geometry of `spawn-protected` for screened recesses spaced around the loop.

## Layout requirements
Place `spawn-protected` as exactly eight distributed respawn positions, one for each supported player, spread around the loop rather than grouped into opposing bases. Every spawn must be screened from immediate fire and face two valid onward directions. No world weapon pickups are needed because weapon progression is a game rule rather than map geometry.

## Layout components
Build a continuous compact route through multiple interconnected warehouse rooms, conveyor-belt work areas, short exterior links, and accessible rooftops. Connect ground interiors to roof sections by exposed stairs or ladders, then return every branch to the main loop without dead ends. Use conveyor lines, machinery, crates, pallets, and structural columns as readable cover. Rooftops provide longer cross-arena sightlines while interiors support close combat. Industrial walls and factory masses form the hard boundary. Compose the loop clearly enough that all major route choices and vertical transitions remain legible.

## Render order
Render `topdown` first and treat it as authoritative because a broken or dead-ending loop would undermine the free-for-all flow. Dress the isometric from that plan; this is not `authored_plan`, which is reserved for mazes and racing circuits.

## Scale, theme, and pipeline cost
Scale is small, driven by the chosen eight-player capacity. The theme is colorful, slightly stylized industrial machinery. Use `P6` for the guaranteed zero-dead-end loop, `P3` for interior/exterior transitions, and `P2` for rooftops over warehouse floors.
