# Scene prompt
Create a shared-world garden tycoon map with multiple visible player plots arranged side by side, each plot under 100 studs and clearly bounded. Use a bright stylised planter-garden theme. Each individual plot contains a Focus Desk and an Unlock Pad, with space for eight progressively larger plants to grow in an ordered garden display.

# Agent decision

## Genre
The genre is Simulation, specifically a garden tycoon. The focus timer explains the progression loop but adds no layout geometry.

## Shape and preset
Use `plot-isolated`: every player receives a separate bounded plot, while all plots remain visible side by side in one shared world. The preset is none; the standard Tycoon preset assumes a shared team plot and a central bazaar that this compact personal-garden brief does not request.

## Config requirements
Use `gate-progression` for the Unlock Pad and the ordered sequence of eight increasingly large plant beds it reveals. Use `trigger-task` for the visible Focus Desk where each session begins. Draw clear plot boundaries and leave readable growth space around every bed without adding a central shop or unrelated scenery.

## Layout requirements
The functional half of `trigger-task` places one focus-session trigger at the Focus Desk in every player plot. Place one unlock trigger beside the ordered garden display and associate it with eight successive plant positions. No other invisible placement is needed.

## Layout components
Each under-100-stud plot is a compact rectangular garden unit with the Focus Desk near its entrance, the Unlock Pad beside it, and eight plant beds ordered from smallest to largest deeper into the plot. Repeat that unit side by side with narrow shared circulation between plots and visible low boundaries that prevent accidental wandering. Use level bright ground, stylised planters, and an open shared-world boundary composition that shows several plots in frame.

## Render order
Use `isometric`: the bright planter-garden look and readable growth composition lead, and the simple repeated plot plan can be projected from that image.

## Scale, theme, and pipeline cost
Scale is medium because multiple personal plots share one world, although each stays under 100 studs. The theme is bright, polished, stylised garden tycoon. Route `P0`; all geometry occupies one level on one continuous surface with no interiors, overhangs, or separate maps.
