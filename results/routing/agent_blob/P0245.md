# Scene prompt
Create a 3D game map divided into distinct biome sections for running between: a forest, desert, snowy area, and beach, each visually separated and arranged as accessible zones around a shared central area.

# Agent decision
## Genre
The dominant genre is Party & Casual: this is a physical theme-matching round in which players run to the correct section.

## Shape and preset
Use `space-bounded`, the Continuous Play Space, because the shared center and all four answer zones form one continuously walkable arena. The closest preset is Quiz, retaining its bounded answer-space idea but replacing its generic tile quadrants with the explicitly requested biome sections.

## Config requirements
Use `tile-grid` as four large, immediately distinguishable answer sectors arranged around the center: forest, desert, snow, and beach. Use `social-hub` for the unobstructed shared central gathering area from which every biome is equally accessible. Use `water-body` for the beach’s visible shoreline and water, contained at the outer edge so it does not interrupt routes between sections.

## Layout requirements
Place four `trigger-scoring` volumes, exactly one covering the playable ground of each biome section, so entering the section can register the round answer. Place `spawn-protected` start markers evenly around the shared center, outside all four scoring volumes and with equally short routes to each sector.

## Layout components
Build one central circular plaza with four broad radial openings. Around it, place exactly four similarly sized zones: dense green forest, sandy desert, snowy ground, and a beach with shoreline water. Use clear material and prop transitions at each sector boundary while keeping every route open and level. Enclose the outer perimeter with biome-appropriate natural barriers. Frame the full four-part radial arrangement clearly from above.

## Render order
Use `topdown`: the top-down image is rendered first and is authoritative because equal access from the center to four non-overlapping answer zones is necessary for fair play.

## Scale, theme, and pipeline cost
Use a medium scale, driven by four readable running zones around one hub. The theme is bright, stylized biome contrast. The pipeline is `CHECK` because the beach includes a real water body; otherwise the layout remains a single-surface build.
