# Scene prompt

Create a simple fully 3D endless runner map with a deliberately abstract, clean arcade look. Frame a few-hundred-stud visible and recycled track segment from a third-person camera behind and slightly above the runner, looking forward down the track. The track has clear parallel lanes, with obstacles and collectible coins placed ahead along the route; keep the surroundings minimal so the movement path remains readable.

# Agent decision

## Genre

The dominant and sole genre is Infinite Runner. Automatic forward motion, lane switching, jumping, endless distance, and increasing speed define the core run.

## Shape and preset

Use `lane-snap` as the single shape, with rigid parallel lanes supporting immediate left-right switches. Match the Lane Runner preset, retaining modular chunks and coin trails but replacing moving obstacles with the simple static jump obstacles requested by this tightly scoped game.

## Config requirements

Use `chunk-modular` for a few-hundred-stud visible track assembled from clean segments whose exit and origin pivots align on one forward axis. Use `obstacle-jump` for simple barriers that occupy readable lanes and can be cleared by jumping. Use `hazard-kill` for solid obstacle geometry that ends the run on collision. Keep lane markings high-contrast and the abstract surroundings sparse.

## Layout requirements

Place `collectible-nodes` as coin trails along the parallel lanes, using straight runs and short lane-change patterns that remain readable from the trailing camera. Place one `trigger-despawn` cleanup volume a fixed distance behind the camera to recycle cleared track, obstacles, and coins. Obstacle spacing must increase with current speed to preserve reaction time, and every pattern must leave a clear dodge or jump response. No power-ups, checkpoints, shops, lap regions, or finish trigger are needed.

## Layout components

Build one level, few-hundred-stud visible track segment from repeatable straight chunks. Divide it into clear parallel lanes and place simple geometric barriers and coin trails ahead without clutter. Use minimal abstract side planes or low edge forms only to frame the route; add no city, terrain, interiors, alternate modes, or decorative systems. Compose the scene from behind and slightly above the runner, looking toward a clean forward vanishing point in both portrait and landscape crops.

## Render order

Use `topdown`: establish valid chunk alignment and clear obstacle patterns first, then dress the plan as the authoritative third-person 3D arcade view. Invalid spacing would make the run unfair.

## Scale, theme, and pipeline cost

The scale band is small, defined by one recycled few-hundred-stud segment supporting a focused roughly five-minute play session. The theme is polished abstract arcade minimalism. Use `P6` because endless chunk alignment and speed-aware obstacle clearance must be valid by construction.
