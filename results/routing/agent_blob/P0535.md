# Scene prompt
Create a 3D strawberry-themed tycoon map with separate small strawberry plots for each player, laid out as independent farm spaces. Each plot includes strawberry growing areas and a strawberry shortcake bakery that can become fully upgraded.

# Agent decision
## Genre
The genre is Simulation, specifically a strawberry production tycoon in which each player independently grows, processes, and sells goods.

## Shape and preset
Use `plot-isolated`, substituting it for the Tycoon preset’s shared plot because every player explicitly receives a separate small farm. Retain progression gates and production circulation, but omit the preset’s shared central bazaar because the plots operate independently.

## Config requirements
`path-circulation` forms a short, obvious production route inside each plot from strawberry beds to the shortcake bakery and its sales frontage. `gate-progression` appears as clearly marked bakery expansion pads and upgrade bays that fill in as the building reaches its fully upgraded form. Draw each plot with strawberry growing beds, a compact processing area, and a whimsical strawberry-shortcake bakery shell, separated from neighboring plots by generous non-overlap buffers.

## Layout requirements
Place `collectible-nodes` in repeated rows within every strawberry growing area for harvestable crop positions. Place three `trigger-task` station types per plot: harvesting beside the beds, shortcake production inside or against the bakery work area, and selling at the bakery counter. Keep all station markers inside their owning plot and align upgrade triggers to the bakery expansion pads.

## Layout components
Lay out a repeatable grid of independent small player plots, each with a clear entrance, neat strawberry beds at the front or side, a short paved production path, and one bakery footprint that visibly expands through upgrades. Every plot follows the same orientation and spacing so ownership is immediately legible, while low fences, hedges, and open buffer strips prevent overlap. Use flat strawberry-red and cream paving accents, green crop rows, frosting-like trim, berry-shaped signs, and cheerful garden landscaping without copying protected characters or locations. The outer boundary encloses the overall tycoon field, while each plot has its own soft boundary. Compose the isometric view to show several complete plots and one fully upgraded bakery as the visual goal.

## Render order
Use `isometric`: the readable strawberry-land visual identity and repeated plot composition lead, then derive the top-down production paths and station footprints.

## Scale, theme, and pipeline cost
Scale is medium overall, made from multiple small independent plots. The theme is an original candy-bright strawberry shortcake farm and bakery world. `P0` applies because all plots and production paths occupy one flat, non-overlapping surface.
