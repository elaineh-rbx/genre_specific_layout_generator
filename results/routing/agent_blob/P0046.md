# Scene prompt

Create a 3D game map showing a compact 5-by-5 grid of clean sci-fi floating arena tiles suspended over an abyss. Each tile is roughly 40 player-widths across, separated by mechanical seams and built on visibly articulated infrastructure that allows tiles to rotate, slide, rise, or drop. Arrange cover pieces, control terminals, and occasional small buildings across the tiles; include some elevated fortress-like tiles and lower hazard-level sections. Emphasize the modular grid silhouette, open void between shifting sections, and clear mechanical connections beneath the platforms.

# Agent decision

## Genre

The genre is Shooter because squads fight around cover and sniper positions until one remains.

## Shape and preset

Use `arena-stacked`, taken from outside Shooter’s usual set: the arena has elevated tiles and lower hazard sections with surfaces and machinery vertically overlapping. The preset is none because the shifting-grid mode replaces the defining Battle Royale boundary and does not request its loot distribution.

## Config requirements

Use `cover-los` for varied waist-high and full-body sci-fi cover on the combat tiles. Use `building-interior` for occasional small enterable buildings. Draw control terminals, articulated rails, pistons, mechanical seams, and visible undersides as scene-specific geometry. The map contains exactly 25 tiles in a 5-by-5 grid, each about 40 player-widths across.

## Layout requirements

Place one tile-control trigger at each control terminal and bind it to a specific neighboring tile shift. Mark all 25 tile footprints as independently movable regions capable of rotating, sliding, rising, or dropping. Place hazard volumes in the abyss and on lower hazard-level sections. Ensure every scheduled configuration preserves at least one playable connected route between surviving tiles.

## Layout components

Build 25 square floating combat arenas in five rows of five over an open abyss. Separate them with readable mechanical seams while showing articulated connections beneath. Mix cover fields, occasional compact buildings, terminal pads, elevated fortress tiles, and recessed hazard sections. Keep the grid silhouette dominant in frame and expose enough underside machinery to explain movement.

## Render order

Render in `topdown` order so the 5-by-5 indexing, seams, and valid adjacency lead before the isometric view dresses the machinery.

## Scale, theme, and pipeline cost

The scale is large because every tile is itself a small arena. The theme is clean modular sci-fi machinery over a void. Use `P2` for vertically overlapping levels, `P3` for enterable buildings, and `P6` because playable connectivity must remain valid through tile shifts.
