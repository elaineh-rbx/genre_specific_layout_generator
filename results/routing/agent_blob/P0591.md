# Scene prompt
Create a compact lane-defence field as a single playable arena, with all lanes visible at once. Use a grassy, colorful cartoon garden battlefield layout rather than an open world or free-for-all arena.

# Agent decision

## Genre
The dominant genre is Strategy (`strategy`): this is explicitly a compact lane-defence map.

## Shape and preset
Use `lane-actor-track`, the Strategy shape for continuous enemy routes from wave origins to a defended core. Match the Tower Defense preset, adapted to several compact, parallel garden lanes that remain visible together.

## Config requirements
Draw `buildzone-grid` as flat defender-placement strips bordering both sides of every lane. Render `tracker-core` as the colorful garden structure defended at the shared terminal end of the lanes. Add `choke-bottleneck` where each broad approach narrows near the core, while preserving unambiguous routes. Keep the whole field grassy, bright, and cartoon-like.

## Layout requirements
Place one `spawner-npc` at the outer origin of each visible lane, aligned so every wave has a readable forward direction toward the core. Place the functional half of `tracker-core` at the opposite shared end, centered and reachable by every lane. The number of lanes is not stated, so preserve “all lanes visible at once” without inventing an exact count.

## Layout components
Build one compact rectangular garden arena with several non-crossing lanes running from a common outer edge toward a central defended garden core on the far side. Border each lane with flat tower-placement ground and low colorful planting beds. Narrow the routes close to the core to create readable pinch points, but do not add dead ends or branches. Use low hedges, flowers, grass, and playful garden props as decoration while maintaining full-map visibility. Enclose the field with a low garden boundary that visually separates it from the void. Frame the entire arena from a high oblique angle so origins, lanes, placement strips, bottlenecks, and core are simultaneously legible.

## Render order
Use `topdown`: draw the plan first as authoritative, then dress it isometrically, because every enemy lane must remain continuous and valid. This is not a maze or racing circuit, so `authored_plan` is unavailable.

## Scale, theme, and pipeline cost
Scale is small, driven by the single arena and all-at-once visibility. The theme is a colorful cartoon garden battlefield. Use `P6` because the enemy tracks must be valid by construction.
