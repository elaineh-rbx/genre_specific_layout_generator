# Scene prompt

Create a 3D obby map built across one full-scale clean modern laptop QWERTY keyboard, with oversized keys forming the course surface.

# Agent decision

## Genre

The genre is Obby & Platformer. The coin award is a gameplay reward attached to traversal, not a Simulation progression loop.

## Shape and preset

Use `course-flat`, with one full QWERTY keyboard forming a finite horizontal platform course. Preset is none: the scene asks for a bespoke keyboard surface and does not request the moving obstacles or checkpoint structure bundled into Classic Obby.

## Config requirements

Draw `path-track` as a readable route across oversized laptop keys, and use `obstacle-jump` for the real gaps between keycaps. The keyboard should be a complete clean modern laptop QWERTY board, including letter rows, number row, modifiers, spacebar, and surrounding laptop deck. Preserve recognizable legends and staggered key rows so the subject reads immediately.

## Layout requirements

Place one invisible coin-award trigger on the walkable top of every keycap so stepping onto a key grants the stated coin reward. These are scoring triggers rather than visible collectible props and should conform to each key’s top surface without bridging the gaps. Put the initial spawn on a broad edge key or laptop palm-rest start pad. Because the prompt does not define a destination, assume the course terminates on the far-side Enter key and place one `winner-zone` there.

## Layout components

The entire map is one oversized modern laptop keyboard laid horizontally over a fall void. Its full QWERTY arrangement is the sole main zone, with discrete raised keycaps acting as platforms and narrow but real gaps separating them. A start pad sits along the near edge, the intended route zigzags across the staggered letter and number rows, the long spacebar provides a broad recovery landing, and the Enter key forms the endpoint. The laptop deck frames the board but is non-playable beyond the designated start. Keep the course bounded to this single keyboard and compose it from a high diagonal angle so the QWERTY pattern, key gaps, start, and endpoint all remain legible.

## Render order

Use `topdown`: draw the authoritative plan first because the key-to-key jump route must be connected and physically completable, then dress that layout isometrically.

## Scale, theme, and pipeline cost

Scale is medium, driven by enlarging one complete keyboard to avatar scale. The theme is a clean modern laptop with crisp dark keycaps and luminous readable legends. Use `P6` because the obby route and jump gaps must be valid by construction.
