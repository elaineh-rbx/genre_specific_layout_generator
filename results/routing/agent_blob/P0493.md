# Scene prompt
Create a compact 3D tower defense map viewed from directly overhead so the physical parts read like a 2D board. Use a grassy toy-soldier board theme with one simple dirt path winding across the map as the single enemy lane, surrounded by clearly marked build areas for towers. Keep the full play space comfortably within one overhead view, with room along the path for a modest number of tower placements.

# Agent decision
## Genre
The dominant genre is Strategy, specifically a physical 3D tower defense game rather than a flat interface.

## Shape and preset
Use `lane-actor-track`: one fixed, continuous enemy lane winds across the compact board without forks. The preset is Tower Defense.

## Config requirements
Use `buildzone-grid` for clearly marked grassy tower-placement areas bordering the dirt lane, `tracker-core` for a toy-soldier base at the lane's endpoint, and `choke-bottleneck` for one readable narrowing that creates a useful defensive focal point. Keep every object as chunky physical geometry viewed from directly overhead. Do not include coin counters, shop panels, round buttons, range overlays, or other GUI mechanics in the rendered layout.

## Layout requirements
Place one `spawner-npc` at the lane entrance and bind enemy movement to the complete lane centerline. Place the `tracker-core` objective at the opposite endpoint. Distribute a modest number of tower-placement markers across the allowed `buildzone-grid` areas on both sides of the path, with no marker overlapping the enemy lane; the exact count is left flexible because the brief gives no number.

## Layout components
Build one small rectangular grassy board with a single winding dirt path crossing from the wave entrance to the defended core. Flat, clearly outlined build plots fill the usable ground beside the path, leaving enough spacing for tower silhouettes and targeting radii. Add one modest choke where the path passes between toy fortifications. Use a crisp board edge or low toy barrier as the boundary. Compose the entire map orthographically from directly overhead so all physical parts fit comfortably in one frame and read with 2D clarity.

## Render order
Render `topdown` first and make it authoritative, then derive the isometric dressing, because the enemy lane must be continuous and every allowed placement area must remain separate from it.

## Scale, theme, and pipeline cost
Scale is small, as the whole board must fit one overhead view. The theme is grassy toy-soldier tabletop terrain with chunky readable parts. Use `P6` because the enemy track must be valid by construction.
