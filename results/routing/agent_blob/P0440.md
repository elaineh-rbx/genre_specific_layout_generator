# Scene prompt
Create a 3D game discovery world as one compact futuristic plaza hub, with six distinct portal destinations arranged clearly around the central gathering space. Each portal leads into a separate themed zone within the same build, creating a cohesive virtual-world setting with the plaza as the shared arrival point.

# Agent decision
## Genre
The dominant genre is Entertainment, specifically a discovery hub meant to be explored rather than won. No secondary genre is required because the six games are represented as destinations, not as six fully specified gameplay genres.

## Shape and preset
Use `hub-portals` with the Hub preset. The compact plaza is the shared hub, while six portal-linked themed zones form distinct destinations inside this build rather than external Roblox places.

## Config requirements
Draw six `teleporter-link` portal gates as large, clearly distinguishable futuristic structures arranged around the plaza. Draw `social-hub` as an open central gathering floor with comfortable circulation and sightlines to all portals. Use `landmark-focal` for a central holographic discovery beacon that visually anchors the plaza. Draw the visible arrival framing for `spawn-first-reveal` so the central beacon and portal ring form the first composition.

## Layout requirements
Place exactly six functional `teleporter-link` pairs, with one portal in the hub linked to an arrival marker in each themed zone. Each destination must also have a clear return link to the plaza. Place one `spawn-first-reveal` arrival marker at the center-front of the gathering space, oriented toward the beacon and the full portal array. Keep all teleporter activation volumes separated and unambiguous.

## Layout components
Build one compact circular or hexagonal futuristic plaza with a broad central gathering zone, a holographic beacon at its center, and six evenly legible portal bays around the perimeter. Beyond each portal, create one small self-contained themed zone with its own landing pocket and visual identity, for six destination zones total. Use clean radial walkways, luminous floor inlays, metallic panels, glass, holograms, and bold color coding. Bound the plaza with futuristic architecture while leaving portal bays visually open. Compose the hub symmetrically enough to scan instantly without making the six destinations look identical.

## Render order
Use `topdown`: the radial portal-to-zone relationships must remain clear and correctly paired before the futuristic dressing is applied.

## Scale, theme, and pipeline cost
The scale is medium, combining one compact hub with six small destination zones. The theme is polished futuristic virtual-world spectacle. Use `P4` because portals transition between distinct zones within the build.
