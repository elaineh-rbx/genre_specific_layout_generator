# Scene prompt

Create a small cartoon-blocky 3D town as a free-for-all physics playground, with a few compact streets that players can cross in seconds.

# Agent decision

## Genre

The genre is Action because players use swords and rocket launchers against one another in a free-for-all ragdoll playground, even though there is no score or formal objective.

## Shape and preset

Use `settlement-static`, taken from outside Action’s usual shape set because the requested space is specifically a fixed town of compact streets rather than a generic empty arena. Start from the Battlegrounds preset but substitute this town shape and omit its ring-out hazard; its free-for-all cover and protected-spawn concepts remain applicable.

## Config requirements

Use `settlement-density` as a very small cartoon-blocky town with only a few closely spaced streets. Use `cover-los` as chunky building corners, low walls, and broad street props that break combat sightlines while leaving ragdoll trajectories readable. Draw screening geometry for `spawn-protected` at several outer street corners. Buildings are exterior town masses only because the prompt does not request enterable interiors. Do not place weapon racks or pickups: players spawn already equipped with the rocket launcher and sword.

## Layout requirements

For `spawn-protected`, place player start markers in the screened outer street corners, distributed so no two starts face directly down the same street. The player count is unspecified, so do not invent a marker count. Nothing else needs placing after segmentation: there are no score zones, objectives, enemy emitters, or collectible weapons.

## Layout components

Build one small town containing a few short streets, a central intersection, compact blocky building rows, and several quick cross-connections so the whole map can be traversed in seconds. Keep roads wide enough for physics knockback and avoid narrow dead-end alleys that trap ragdolled players. Use simple facades, low walls, and sparse chunky street furniture as impact-readable obstacles. Close the outer edge with continuous facade backs or a simple town boundary. Compose the central intersection as the main visual anchor while showing all street branches.

## Render order

Render `isometric` first and make it authoritative, then derive the top-down image; the cartoon town character leads and no exact computed topology is required.

## Scale, theme, and pipeline cost

The scale is small because every street must be crossable within seconds. The theme is colorful, chunky, cartoon-blocky urban physics play. Use `P0` because all play is exterior on one non-overlapping ground surface.
