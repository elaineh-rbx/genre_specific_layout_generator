# Scene prompt

Create a 3D classic Roblox obby map: a flat, ground-level course of 50 stages, arranged as several linked segments progressing across the ground. Use one consistent bright, colorful visual style throughout, with simple platforming hazards along the route.

# Agent decision

## Genre

The genre is Obby & Platformer, with player-paced traversal across a fixed sequence of 50 stages.

## Shape and preset

Use `course-flat`, forming one long horizontal course divided into several linked, manageable segments. The Classic Obby preset fits directly.

## Config requirements

Draw `path-track` as exactly 50 sequential stages with no breaks in the critical route. Use `obstacle-jump` for clear gap jumps, stepped blocks, and simple wrap-around sections, and `obstacle-moving` sparingly for rotating or sliding platforms that vary the rhythm without changing the classic style. Draw broad, visible safe pads for `checkpoint-respawn` and a colorful final platform for `winner-zone`. Keep all 50 stages in one consistent palette of bright primary and secondary colors with simple, readable hazard silhouettes.

## Layout requirements

Place `checkpoint-respawn` markers on safe pads at the start and at regular segment boundaries, so failure returns the player to the current linked segment rather than the beginning of all 50 stages. Each checkpoint must sit after a completed obstacle and before the next challenge. Place one `winner-zone` at stage 50, clearly separated from the last hazard. Number or otherwise identify every stage from 1 through 50 so segment progression remains unambiguous.

## Layout components

Build exactly 50 ground-progressing obstacle stages grouped into several linked course segments. A start pad leads into repeated but varied chains of bright platforms, short gap runs, stepped blocks, wrap-arounds, and occasional moving hazards. Larger checkpoint pads divide the segments, and short safe connector paths link one segment to the next without teleportation or separate maps. Keep the route on one ground-level plane apart from modest obstacle height, with open fall zones or reset floors flanking the playable track. Low barriers or color-coded edging define segment boundaries without enclosing the course. Compose the map in a long diagonal or gentle serpentine footprint so all segments fit in frame while stage order remains obvious.

## Render order

Use `topdown`: the authoritative plan must come first because all 50 stages need a connected, correctly ordered, completable route, then the isometric pass applies the classic visual dressing.

## Scale, theme, and pipeline cost

Scale is huge because the map contains exactly 50 stages. The theme is classic Roblox obby: bright colorful blocks and simple readable hazards. Use `P6` because every stage connection and jump must be valid by construction.
