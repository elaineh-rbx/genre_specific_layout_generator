# Agent decision

## Clarifications resolved
- [author] theme — Q: What should the riding grounds look like - a desert freestyle compound, green hills, an industrial skatepark? A: Make it a desert freestyle compound with dirt tracks, large ramps, and open riding space, matching an MX Bikes-style motocross game.
- [author] free: custom building — Q: Should players build ramps anywhere in the world, or on a set-aside plot? A: Use a set-aside build plot so players can make custom ramps without cluttering the main riding compound.
- [author] scale — Q: How large should the terrain be - one big freestyle compound, or an open world you ride between spots in? A: Start with one big freestyle compound rather than a larger open world, with enough room for tracks, ramps, and the building plot.
- [author] free: bike selection — Q: Where do players pick a bike - a garage in the world, or a menu? A: Players should pick and customize their bikes from a garage in the world.

## Enriched image prompt
Create one large 3D desert freestyle motocross compound with broad open riding ground, connected dirt tracks, and multiple large freestyle ramps arranged with long unobstructed takeoff and landing space. Set one clearly bounded custom-build plot to the side of the main riding ground so player-made ramps do not clutter the fixed compound. Place one enterable garage at the compound edge, opening directly toward the tracks, with display and customization space for varied original motocross and electric dirt bikes rather than copied branded models. Keep the main ramps, dirt circulation, build plot, and garage legible together in one elevated view.

## Genre
The dominant genre is Simulation (`simulation`), specifically a motocross physics and trick-riding simulation; it is not Racing because no lap or finish condition is requested.

## Shape and preset
Use `world-open`: one shared freestyle compound contains the fixed tracks, ramps, garage, and custom-build plot. Use the Physics Sim preset, dropping `hazard-kill` because the author did not request a damaging region.

## Config requirements
Use `physics-rig` for the large freestyle ramps and stunt surfaces. Use `path-circulation` for dirt tracks connecting ramps, open riding ground, garage, and build plot. Use `building-interior` for the bike-selection and customization garage. Use `buildzone-plot`, taken from the shared catalogue, for the single bordered custom-ramp plot. Original bike displays remain scene-specific geometry.

## Layout requirements
Place one free-text BuildZone permission volume exactly within the set-aside plot, excluding all fixed ramps and tracks. Place free-text SpawnZone bike deployment markers and a TriggerZone customization marker inside the garage, with deployment facing the compound. Trick rewards, ride earnings, play-time rewards, and named trick detection are gameplay systems rather than fixed layout objects.

## Layout components
The map contains one desert riding compound, a connected dirt-track network, several large ramps with clear approaches and landings, broad open trick ground, one side build plot, and one enterable garage. The garage and plot sit at the perimeter so they do not interrupt fixed riding lines. A natural desert edge bounds the single contiguous map.

## Render order
Use `isometric`: ramp profiles, desert material, and the relationship between garage, tracks, and build plot lead; the circulation plan can be derived afterward.

## Scale, theme, and pipeline cost
Scale is large, explicitly one big compound with room for tracks, ramps, and construction while keeping those features legible. The theme is a realistic-stylized desert motocross facility. Use `P3` because players travel from the outdoor compound into the garage; standard ground-supported ramps do not force an overhang pass.
