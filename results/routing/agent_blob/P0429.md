# Scene prompt
Create a 3D exploration map with 234 hedgehogs placed throughout a single connected world. Arrange three walkable biomes that link together: a candy-themed area, a mountain area, and an underwater area, with obby-style traversal sections integrated across the map.

# Agent decision
## Genre
The dominant genre is Adventure, specifically a large scavenger hunt. Obby & Platformer is secondary because skill-based traversal sections are explicitly part of the search, but it does not own the overall open-world shape.

## Shape and preset
Use `world-open`, one contiguous explorable map in which all three biomes can be visited on foot without separate instances. The preset is Scavenger Hunt, retaining its collectible objective and open search shape while adding the requested obby traversal.

## Config requirements
Use `path-track` for physics-valid platform chains integrated into each biome, plus `obstacle-jump` for the explicitly requested obby-style sections. Use `terrain-relief` for the climbable mountain biome and `water-body` for the underwater biome's traversable water volume. Do not add secret alcoves or a quest board that the brief did not request.

## Layout requirements
Place exactly 234 `collectible-nodes` as hedgehogs distributed across the candy, mountain, and underwater biomes, including safe-route and obby-route positions while keeping every one reachable. Place `checkpoint-respawn` pads at the start and safe landing at the end of each distinct obby section, with additional pads between long chains so a fall does not reset the entire world.

## Layout components
Build three large adjoining zones on one connected footprint: a bright candy landscape, an elevated mountain region, and a submerged underwater region. Join each pair through broad walkable transition corridors rather than portals. Thread several discrete obby chains through all three regions, using candy platforms, mountain ledges, and submerged stepping structures while preserving ordinary walkable bypasses for circulation. The mountain rises in terraces without overhangs; the underwater zone is a broad readable basin. Use continuous outer scenery to bound the world. Compose the overview so all three biomes, their transitions, and the embedded obstacle routes remain legible.

## Render order
Use `topdown`: draw the authoritative connected plan first, then dress it isometrically, because broken biome links or impossible obby gaps would make collectibles unreachable. This is not `authored_plan`, since the build is neither a maze nor a racing circuit.

## Scale, theme, and pipeline cost
The scale is huge, driven by 234 objectives across three biomes. The theme is playful candy fantasy, rugged mountain, and colorful underwater adventure. Use `P6` for valid obstacle spacing, `tiered` for mountain relief without overhangs, and `CHECK` for the underwater play volume, which is acceptable provided it does not self-occlude.
