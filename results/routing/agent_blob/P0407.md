# Scene prompt

Create a 3D medieval kingdom-building layout with a separate small buildable plot for each player. Each plot is open ground for arranging simple medieval village decor and nature, including trees, wooden benches, and stone wells.

# Agent decision

## Genre

The dominant genre is Simulation because the core activity is a 3D building sandbox in which each player arranges scenery on personal land.

## Shape and preset

Use `plot-isolated`: a collection of separate, equally spaced small plots, one per player, with enough clearance that neighboring builds never overlap. The closest preset is Sandbox. Keep its isolated-plot shape, but omit its usual resource nodes and social hub because neither was requested.

## Config requirements

No canonical image option is required beyond the chosen shape. The image must nevertheless depict each plot as open buildable ground in a medieval village register, with representative trees, simple wooden benches, and stone wells showing the intended decorating vocabulary without turning the plots into prebuilt settlements.

## Layout requirements

Nothing invisible needs placement after segmentation. The brief does not specify pickups, task triggers, checkpoints, or scripted stations; decor placement is the player’s building activity rather than a fixed post-segmentation placement request.

## Layout components

Build a repeated field of small rectangular personal plots arranged in a clear, readable grid. Give each plot a flat open center for free placement, a subtle low medieval boundary such as packed-earth edging or short timber stakes, and a narrow access path connecting it to the shared perimeter circulation. Keep substantial empty clearance between plots. Use grass and packed earth as the ground materials. Place only sparse sample medieval village decor—trees near plot edges, simple wooden benches, and stone wells—so the available building area remains obvious. Enclose the overall plot field with a modest rustic boundary and compose the view so several equivalent plots are visible at once.

## Render order

Render `isometric` first and treat it as authoritative, then derive the top-down image from it; visual readability and the medieval decorating character lead, while the plot grid is straightforward.

## Scale, theme, and pipeline cost

Use a medium scale, driven by multiple independent small player plots rather than one large world. The theme is a clean, rustic medieval kingdom worksite with village-grade wood, stone, grass, and packed earth. Route through `P0`: all play occupies one flat, unobstructed surface with no interiors, overhangs, separate maps, or topology that must be computed.
