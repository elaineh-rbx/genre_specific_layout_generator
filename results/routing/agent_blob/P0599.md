# Scene prompt
Create a bright, stylised 3D mountain scenery map for relaxed walking and sightseeing. Build one small, visually appealing mountain peak that can be crossed in about one minute, with clear walkable slopes and scenic viewpoints looking across the surrounding mountain landscape.

# Agent decision

## Genre
This is `No Genre`: the author wants a scenic place for walking and sightseeing, not a game with scoring, enemies, rounds, or a finish condition.

## Shape and preset
Use the Explorable Place preset. With no genre shape, set the no-genre `verticality` axis to tiered for the climbable peak while leaving enclosure exterior, zone-count single, structure dressed, and play-space grounded at their defaults. The map is one compact mountain surface rather than separate ranges.

## Config requirements
Use `terrain-relief` for one small stylised mountain peak with clear sloping ground and elevated overlooks, with no caves, overhangs, or stacked surfaces. Use `path-circulation` for an obvious walkable route across the peak that can be completed in about one minute. Use `vignette-photo` for scenic viewpoints composed toward the surrounding mountain panorama. Use `landmark-focal` for the bright, readable summit as the map’s orientation anchor.

## Layout requirements
Nothing needs functional placement after segmentation. The brief asks for no collectibles, triggers, checkpoints, teleporters, or gameplay spawn system.

## Layout components
Build one small mountain zone with a clear lower approach, a gently climbing traverse, a compact summit, and a descending path on the far side. Connect these spaces with broad stylised slopes and a legible footpath rather than difficult jumps. Place several safe viewing shelves along the ascent and summit, each facing layered distant mountain scenery. Use bright grass, exposed rounded rock, sparse colourful shrubs, and atmospheric background peaks. Natural drop-offs, rock outcrops, and dense vegetation define the boundary while keeping the playable route safe. Frame the summit and panoramic horizon as the main composition.

## Render order
Use `isometric`: establish the bright scenic silhouette and viewpoint composition first, then derive the top-down plan because exact topology is not gameplay-critical.

## Scale, theme, and pipeline cost
Use a small scale, explicitly crossable in about one minute. The theme is bright, clean, stylised alpine scenery. Apply `tiered` because the mountain has real elevation without overhang; no other modifier is required.
