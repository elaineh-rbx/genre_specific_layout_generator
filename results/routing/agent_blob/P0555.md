## Enriched image prompt
Create one large, bright, clean working industrial warehouse hall for a 3D physics puzzle. Keep the floor open and readable so the player can walk around and line up blast shots. Scatter one or more sturdy indestructible crates across the hall and paint one clear target on the floor as the goal. Preserve long unobstructed views between crates and the target, with enough surrounding space for crates to launch upward and land. The warehouse remains the same for every level; only the crate positions and painted target location change between challenges.

## Genre
The dominant genre is Puzzle, canonical slug `puzzle`, with Simulation (`simulation`) secondary because a physics contraption is the means of solving each challenge.

## Shape and preset
Use `interior-single`, one Single Interior containing the entire walkable warehouse puzzle. The preset is none: this is neither a gated escape-room chain nor an open-air clue puzzle, and its defining action is launching reusable crates onto a movable floor target.

## Config requirements
Use `physics-rig`, taken from the shared catalogue, for the indestructible crate-and-bomb launch setup. Use `trigger-solve` for the painted floor target that accepts a landed crate. The bright industrial hall, one-or-more crates, and clear launch space are required scene-specific visible geometry.

## Layout requirements
Place exactly one `trigger-solve` TriggerZone aligned to the painted target in each challenge configuration. Place one free-text Marker for the player-selected CrossHair floor location, enforcing a maximum of one active marker and moving it when a new location is chosen. Reposition at least one crate and the target within the same hall between levels; bomb size and controls are mechanics.

## Layout components
The map is one open warehouse hall with a clear floor boundary, one or more movable crate start positions, one painted target position, and unobstructed overhead launch volume. No second building, exterior yard, or per-level map is required.

## Render order
Use `topdown`; crate starts, the painted target, and open shot lanes should be authoritative before industrial dressing.

## Scale, theme, and pipeline cost
Scale is medium because a single large hall must fit while individual crates, crosshair placement, and floor target remain legible. The theme is bright, clean working industry. Use `P0`; one interior-only hall with no stacked surfaces or map transitions forces no additional pass.
