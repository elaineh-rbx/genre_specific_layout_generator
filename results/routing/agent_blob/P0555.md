# Scene prompt
Create a 3D game map set in a single large, clean working industrial warehouse hall, brightly lit for clear sightlines across the floor. The open interior contains one or more sturdy crates scattered at challenge positions, with a distinct target painted directly onto the warehouse floor; crates and target reposition within this same hall for each level. Keep broad open floor space around the crates and target for lining up shots, framed by simple warehouse walls, ceiling structure, and industrial fixtures.

# Agent decision
## Genre
The genre is Puzzle: each challenge asks the player to use bomb placement and force to move a crate onto a target.

## Shape and preset
Use `interior-single`: the entire game map is one large enclosed warehouse hall, reused with rearranged challenge pieces rather than traversed as a sequence of rooms. Match the Open-Air Puzzle preset but substitute this single-interior shape; retain its physical solve target and completion gate while dropping the clue facade because no riddle or displayed hint is requested.

## Config requirements
Apply the drawn side of `trigger-solve` as one distinct, high-contrast target painted directly on the warehouse floor. Use `gate-solve` as the visual completion state associated with landing a crate on that target, without adding an unnecessary doorway. Draw a bright clean industrial shell with broad uncluttered floor, simple walls, visible ceiling structure, lights, loading fixtures, and enough clearance around every challenge position.

## Layout requirements
Place the functional side of `trigger-solve` once per level, aligned exactly to the painted floor target. Place `collectible-nodes` as one or more sturdy indestructible physics crates at level-specific challenge positions, with the crates and target repositioned inside the same hall between challenges. Also place one movable floor CrossHair marker at the player’s selected bomb location, replacing its previous position whenever moved; this marker has no canonical option ID.

## Layout components
Build one large rectangular warehouse hall with a mostly open level concrete floor. Keep shelving, support columns, wall equipment, loading doors, and industrial props around the perimeter so central sightlines and blast trajectories remain clear. The active arrangement contains one painted target and one or more crates, each surrounded by generous setup space. Use bright overhead lighting, pale walls, safety-yellow accents, and a solid exterior wall boundary. Frame the isometric view from high enough to read the full hall, target, crates, and open firing space at once.

## Render order
Use `isometric`: establish the clean warehouse and readable challenge composition first, then derive the top-down plan, because level pieces can be repositioned and no fixed topology can become unsolvable.

## Scale, theme, and pipeline cost
Use a large scale band because the single hall needs long clear blast trajectories. The theme is bright, clean working industry with high visual contrast. Route through `P0`; the entire playable area is one unobstructed interior floor with no outside transition.
