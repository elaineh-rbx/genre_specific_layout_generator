# Scene prompt
Create a 3D hide-and-seek map set inside a large neon retro arcade, with rows of glowing arcade cabinets, game machines, prize counters, seating areas, and back corridors arranged to create clear hiding spaces.

# Agent decision
## Genre
The dominant genre is Party & Casual because this is a timed, round-based hide-and-seek game with one seeker.

## Shape and preset
Use `interior-single`, taken from outside Party & Casual’s usual shape set, because the entire map is one large arcade interior and players never need an exterior transition. Match the Childhood Game preset with that shape substituted and omit its unrequested social lobby.

## Config requirements
Apply `cover-los` as dense but readable rows of glowing cabinets, game machines, counter corners, seating clusters, and prize displays that interrupt long seeker sightlines. Apply `obstacle-maze` as a connected warren of public aisles and back corridors, preserving multiple escape routes rather than dead-end traps.

## Layout requirements
Place `spawn-protected` as distributed hider starts near several distinct cabinet and seating clusters, plus one seeker start screened from immediate views into those positions. Keep all start markers on accessible floor and outside tight prop gaps. No other invisible placement is required.

## Layout components
Build one large enclosed neon retro arcade. Organize the front and centre into several rows of glowing arcade cabinets and larger game machines, with broad cross-aisles joining them. Put a prize counter along one side, seating pockets at aisle ends, and a connected set of staff-like back corridors behind the public floor. Use cabinet backs, counter returns, machine clusters, and seating edges to create clear hiding pockets without blocking the main circulation loop. The boundary is the arcade’s exterior wall shell; no outdoor zone is shown. Compose the scene so the bright central arcade floor remains the visual focus while darker back corridors are still legible and reachable.

## Render order
Use `topdown`: every hiding route and corridor loop must remain connected before the neon machines and décor are dressed.

## Scale, theme, and pipeline cost
Scale is medium, driven by one large venue with several functional subareas. The theme is neon retro arcade glow with high-contrast carpet and machines. Use `P6` because the hide-and-seek warren must be navigable by construction; `P3` is unnecessary because this is interior-only.
