# Scene prompt
Create a simple physics vehicle test area with a Studio-default-sized, untextured grey baseplate. Above the baseplate, place a single floating rectangular part sized to resemble a scooter, with no additional vehicle model, terrain, props, or theme.

# Agent decision
## Genre
The dominant genre is Simulation: this is a minimal physics vehicle test rather than a decorative place or a scored course.

## Shape and preset
Use `space-bounded` as one clearly bounded, single-level baseplate where the entire test occurs. This shape comes from outside Simulation’s usual set because no persistent world, plot, or route is requested. The preset is none: Physics Sim would add ramps, hazards, and circulation that the prompt explicitly excludes.

## Config requirements
Use `physics-rig` only for the single floating rectangular player part, sized like a scooter and left as plain placeholder geometry. Draw one Studio-default-sized baseplate as an untextured grey plane. Do not add terrain, roads, ramps, buildings, scenery, barriers, decorative props, vehicle bodywork, or a visual theme.

## Layout requirements
Place exactly one player-vehicle spawn marker at the center of the baseplate and bind it to exactly one scooter-sized rectangular part floating slightly above the surface. Orient the part parallel to the baseplate so it begins stable and has clear test space in every direction. No checkpoints, pickups, task stations, hazards, or other invisible volumes are needed.

## Layout components
The build contains one zone: a Studio-default-sized flat grey baseplate. Its only prop is one floating rectangular part with scooter-like length, width, and height, but no wheels, handlebars, shell, or other model detail. The baseplate’s own rectangular edge is the boundary; leave the surroundings empty. Use no terrain relief or additional ground material. Compose the part near the exact center with enough empty baseplate visible around it to communicate scale and permit basic driving tests.

## Render order
Use `isometric`: render the sparse placeholder scene first, then derive its trivial top-down placement from that authoritative image.

## Scale, theme, and pipeline cost
Use a small scale band, driven by the single default baseplate and one test object. The theme is intentionally absent: untextured grey Studio placeholders only. Apply `P0`; one flat surface and one unobstructed floating part require no special capture or structural validation.
