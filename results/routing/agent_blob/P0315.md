# Scene prompt

Create a colorful, stylized Roblox game map for a satisfying ASMR squishy-toy factory collecting game. Build a small shared map with 6 separate player factory plots arranged around a central social area for trading and movement between factories. Each plot contains a walkable factory interior that players enter and upgrade, with display areas for collected squishy toys and visible security around the collection. Use toy-factory styling, vibrant materials, glowing effects for rarer displays, and relaxing rainy-weather ambience.

# Agent decision

## Genre

The dominant genre is Simulation: this is a factory tycoon whose build-and-upgrade loop produces collectible toys.

## Shape and preset

Use `plot-isolated` for six independent, equally spaced player factories around shared social ground. Start from the Tycoon preset, but substitute its shared-team plot with isolated per-player plots because ownership is individual.

## Config requirements

Apply `social-hub` as the central trading plaza; `path-circulation` as clear walkways linking that plaza to all six factories; `gate-progression` as visible security doors and upgrade barriers protecting each collection; and `building-interior` as six enterable factory interiors. The interiors contain colorful production styling, squishy display shelves, vibrant materials, and rare-item displays with glowing accents. Rain and wet surfaces establish the relaxing ambience.

## Layout requirements

Place one player start/claim marker at each of the six factory entrances, oriented toward the central plaza. Place interaction stations beside each toy display and security control, preserving clear circulation through every interior. No genre-table layout-only option is required.

## Layout components

Build one central medium-sized social trading plaza, surrounded radially by 6 comparable factory plots. Each plot has an entrance, walkable production-and-display interior, protected collection area, and visible security threshold. Six short paths connect the plaza directly to the six entrances without crossing private production space. Keep terrain mostly flat, with rain-darkened paving and colorful toy-factory façades. Frame the whole arrangement so the six plots and central hub read at once.

## Render order

Render `isometric` first and treat it as authoritative; this arrangement is simple and appearance-led, with no topology requiring computed construction.

## Scale, theme, and pipeline cost

Scale is small, driven by six compact factories around one hub. The theme is vibrant toy-factory whimsy with relaxing rainy ASMR ambience. Use `P3` because play crosses between the shared exterior and six walkable interiors.
