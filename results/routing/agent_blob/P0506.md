# Scene prompt
Create a 3D medieval-meets-technology Tower Defense world. Build a large landscaped lobby with a central fountain, separate tutorial NPC, shop, code, achievement, and player leaderboard areas, plus several elevator bays for Easy, Normal, Hard, and Nightmare matches. Surround the lobby with detailed trees, rocks, flowers, mountains, and rivers.

Build the Forest match map first as a compact, readable arena with a clear enemy lane that is mostly visible at once, running from an entrance through forest terrain to a defended base at the route’s end. Leave distinct build spaces along the path for archer, swordsman, cannon, mage, sniper, electrical, ice, fire, and laser tower positions. Future compact maps retain clear reliable routes but each has its own visual identity and path layout: castle, city, snow, volcano, laboratory, and desert.

# Agent decision
## Genre
The dominant genre is Strategy, specifically tower defense.

## Shape and preset
Use `lane-actor-track` for the first Forest match: one reliable, continuous enemy lane runs from the woodland entrance to the defended base. The preset is Tower Defense. The large lobby is a separate support map; the six future environments are design commitments but are not rendered in this scene.

## Config requirements
`buildzone-grid` draws exactly nine distinct build spaces alongside the Forest lane, respectively suited to archer, swordsman, cannon, mage, sniper, electrical, ice, fire, and laser towers. `tracker-core` draws the defended base. `npc-population` draws the tutorial NPC and its station. `water-body` draws the lobby rivers, while `terrain-relief` supplies surrounding mountains. The lobby also draws one central fountain, separate shop, code, achievement, and leaderboard areas, and four elevator bays for Easy, Normal, Hard, and Nightmare.

## Layout requirements
Place one `tracker-core` marker at the Forest base and one `spawner-npc` at the lane entrance. Place the tutorial NPC at its station and one teleport trigger in each of the four elevator bays. Site the nine tower build spaces at useful intervals along the route without narrowing it, and keep them reachable from the player arrival area.

## Layout components
Build a large landscaped lobby centered on the fountain, with five service areas and four elevator bays distributed around its main plaza. Trees, rocks, flowers, rivers, and mountains frame the hub. The separate Forest arena is compact, with one winding but mostly visible lane, exactly nine flanking build positions, dense woodland framing, and a defended endpoint. Use clear hard boundaries and an elevated composition that reads well on all platforms.

## Render order
Use `topdown`: the Forest lane and nine build positions must be valid before isometric dressing.

## Scale, theme, and pipeline cost
Scale is large because it combines a large lobby and separate compact match. The theme is polished medieval woodland with technological accents. Use `P4` for separate maps, `P6` for the valid lane, `tiered` for mountains, and `CHECK` for rivers.
