# Scene prompt
Create a 3D game map centered on a modern city high-rise, with an exterior climbing route running up its facade to a rooftop. The roof is a broad open jumping area for multiple players, with the city ground far below and clear space around the tower for long jumps or falls.

# Agent decision
## Genre
The dominant genre is Obby & Platformer. The exterior ascent is a fallible climbing challenge, followed by a social rooftop where multiple players jump for fun.

## Shape and preset
Use `course-tower`: the playable route wraps and stacks upward along one high-rise facade, placing climbing surfaces directly above lower sections. The preset is Tower Obby, retaining its tower shape, sequential route, climbing obstacles, and rooftop payoff while omitting timed disappearing obstacles that were not requested.

## Config requirements
Use `path-track` for the ordered exterior platform chain from street level to roof. Use `obstacle-climb` for facade-mounted ladders, trusses, narrow ledges, and wall-scramble sections. Use `obstacle-jump` for physics-legal transfers between exterior ledges. Use the visible half of `winner-zone` as the broad, open rooftop jumping area. Keep the facade route visually distinct from decorative windows and architectural trim.

## Layout requirements
Place the functional half of `winner-zone` across the rooftop beyond the final climb. Place one start and failure-respawn anchor on a safe ground-level apron directly beside the first climbing element. No intermediate `checkpoint-respawn` is selected because the brief only establishes a simple challenge and does not request staged recovery. Keep the rooftop trigger clear of the roof edges so players can deliberately choose where to jump.

## Layout components
Build one modern city high-rise as the dominant central zone, with a safe street-level start at its base. Run one continuous exterior route up the facade using projecting ledges, ladders, trusses, and short jump gaps, then open onto one broad flat roof sized for several players. Include a minimal city-ground surround far below, with neighboring buildings kept distant enough to preserve open falling and long-jump space. Use glass, steel, concrete, rooftop vents, and safety markings without cluttering the playable surfaces. Frame the tower vertically so the base, climb, and roof relationship is unmistakable.

## Render order
Use `topdown`: generate the playable climbing chain first so every transfer is reachable, then dress it as an exterior high-rise ascent.

## Scale, theme, and pipeline cost
The scale is medium, driven by one tall building and a multiplayer roof. The theme is clean modern metropolitan glass and steel. Use `P6` for physics-valid climbing structure and `P2` because stacked facade surfaces overhang and occlude lower route sections.
