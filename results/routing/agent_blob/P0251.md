# Scene prompt
Create a 3D tag-game layout centered on a compact, medium-sized grass park field arena, roughly 150 by 150 studs, kept open and readable for about 30 players. All ten selectable map arenas connect to a shared central lobby, where a prominent map-selection spinner stands as the focal prop; each chosen map is a separate fast-paced arena space.

# Agent decision
## Genre
The dominant and only genre is Party & Casual, specifically a large-server childhood tag game with timed map rotation.

## Shape and preset
Use `hub-portals`, the Portal Hub, taken from outside Party & Casual’s usual set because one shared lobby sends players to ten genuinely separate arena maps. Use the Minigame preset with this shape substituted for its single isolated stage; retain lobby-to-stage transport and round-completion placement while omitting unrequested leaderboard and spectator structures.

## Config requirements
Use `social-hub` for a compact central lobby sized for about 30 players, with the map-selection spinner as its dominant prop. Use `teleporter-link` as ten clearly readable arena destinations arranged around the spinner. Each destination represents a compact grass park field kept open and readable, without adding dense cover or maze geometry that would contradict fast-paced tag.

## Layout requirements
Place the functional half of exactly ten `teleporter-link` destinations around the lobby spinner and matching return markers in the ten arenas. In every arena, place 30 evenly distributed `spawn-protected` start points around the field edge, all with comparable access to the center. Place one `trigger-scoring` round volume over each full arena play area so the five-minute round can register active participants. Reserve bot starts among the same 30 positions rather than creating a separate team.

## Layout components
Build one shared lobby map and exactly ten separate arena maps. The representative arena is roughly 150 by 150 studs: flat grass, sparse park-edge trees and fencing, an open center, and no sightline-blocking clutter. Arrange ten labeled destination bays radially around one prominent spinner in the lobby, leaving broad circulation for 30 occupants. Bound each field with a clear park perimeter and frame the spinner centrally in the lobby.

## Render order
Use `topdown`: render each top-down first and make it authoritative so spawn spacing and open pursuit routes remain fair across every arena.

## Scale, theme, and pipeline cost
Use huge overall scale because the build contains ten 150-by-150-stud arenas plus a shared lobby. The theme is bright, readable grass-park competition. `P4` is required because the lobby and ten arenas are separate maps.
