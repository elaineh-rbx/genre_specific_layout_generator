# Scene prompt
Crea un mapa 3D de Escape Room de terror ambientado en el interior cerrado de un hospital abandonado. Diseña un ala hospitalaria de una sola planta con cinco cuartos conectados por pasillos amplios y suficientes espacios para explorar, sin exteriores ni pisos adicionales. Distribuye tres llaves como objetos recogibles dentro de distintas habitaciones y coloca una puerta final de salida al extremo del ala, cerrando el recorrido.

# Agent decision
## Genre
The genre is Puzzle: players search an abandoned hospital wing for keys that unlock the final escape door.

## Shape and preset
Use `interior-single`, one sealed hospital interior explored freely on a single floor. Use the Escape Room preset with its ordered chamber sequence replaced by this explorable ward, retaining collectible key items and the final progression gate.

## Config requirements
Draw `gate-progression` as the locked final exit door at the far end of the ward. Give each of the five rooms a distinct abandoned-hospital identity and enough environmental clutter to support searching, but do not add monsters, chase routes, exterior space, or extra floors.

## Layout requirements
Place exactly three `collectible-nodes` keys, each in a different one of the five rooms and each reachable from the main corridors. Site them against distinct room landmarks rather than in the hallway. Place one exit-completion trigger immediately beyond the final door; the door unlock condition is collecting all three keys.

## Layout components
Build exactly five rooms in one hospital wing, connected by broad single-level corridors with enough width and branching space for exploration. Suggested room roles are reception or nurses’ station, patient ward, treatment room, supply room, and operating room, with the final exit at the extreme end of the circulation spine. Distribute the three key rooms across the wing so the search uses more than one branch and naturally returns toward the final door. Use cracked tile, peeling paint, overturned medical furniture, abandoned beds, cabinets, and dim emergency lighting. Seal the map with interior walls and blocked non-playable doors; include no exterior. Compose the plan so all five rooms, corridor branches, and terminal exit are readable.

## Render order
Use `topdown`: all three key locations, five rooms, corridor access, and the final return route must be valid before horror dressing.

## Scale, theme, and pipeline cost
The scale is medium, driven by five spacious rooms and connecting corridors. The theme is abandoned-hospital horror with restrained decay and suspenseful lighting. Use `P0`; the entire closed, one-floor interior is captured by one plan.
