# Scene prompt
Create a 3D horror game map showing an endless, cramped hallway packed with genuinely frightening monsters, with a continuous forward-running path through the corridor.

# Agent decision
## Genre
The dominant genre is Infinite Runner, with Survival secondary. Continuous forward running and distance reached define the game, while frightening monsters provide the pursuing and contact threats.

## Shape and preset
Use `lane-free` for continuous lateral steering within one cramped forward corridor rather than rigid snap lanes. The preset is Chase Runner, augmented with deterministic hallway chunks because the route is explicitly endless.

## Config requirements
Draw `chunk-modular` as reusable hallway segments whose entry and exit pivots align on one forward axis without drift. Use `hazard-kill` for frightening monsters that end the run when they catch or touch the player. Draw `obstacle-moving` as monsters crossing, lunging into, or partially blocking the forward route, with spacing based on current speed and at least half a second of reaction time. Use `barrier-horizon` as darkness, haze, and occasional corridor bends that conceal newly appearing chunks. Add `marker-distance` as grim wall markings or numbered maintenance signs showing forward progress.

## Layout requirements
Place `spawner-npc` origins for hostile monsters within repeated hallway chunks, offset beyond the immediate visible horizon and never creating an impossible full-width blockade. Place `trigger-despawn` as a cleanup volume a fixed safe distance behind the camera and player. Keep monster emergence rules and moving-obstacle positions tied to chunk sockets so each generated sequence remains clearable. No exit, winner zone, collectible, checkpoint, or final destination is required because the run ends only when a monster catches the player.

## Layout components
Build a library of cramped enclosed hallway chunks with a continuous forward floor, tight walls, low ceiling, occasional shallow side recesses, and no branching destination. Populate the chunk set with frightening monster silhouettes, crossing points, partial obstructions, dark bends, and repeated distance markings. Every segment must connect cleanly to the next while preserving avatar clearance and an evasive lateral line. The hallway shell is the boundary, and composition should force a narrow forward vanishing point swallowed by darkness.

## Render order
Render `topdown` first and make it authoritative, then derive the isometric dressing; invalid chunk alignment or an unclearable monster arrangement would break the endless run.

## Scale, theme, and pipeline cost
Use a huge scale in experienced distance because the hallway generates endlessly, although each authored chunk is small. The theme is claustrophobic, genuinely frightening corridor horror. Route with `P6`, forced both by the Infinite Runner genre and by deterministic clearable chunk construction.
