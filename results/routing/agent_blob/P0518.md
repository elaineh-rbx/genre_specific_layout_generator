# Scene prompt
Create a small, colorful cartoon-style 3D obby tower with 5 stacked levels forming a vertical climbing course.

# Agent decision
## Genre
The genre is Obby & Platformer, canonically `obby-platformer`, because the avatar climbs a player-paced obstacle tower.

## Shape and preset
Use `course-tower`: five compact course levels stack vertically around a continuous ascent. Tower Obby is the matching preset, simplified to the brief rather than padded with elaborate timed hazards.

## Config requirements
Draw one physics-valid `path-track` that rises through all five levels, with `obstacle-climb` expressed as simple cartoon stairs, ladders, narrow climbs, and short vertical platform sequences. Draw the top payoff platform for `winner-zone`. Do not add checkpoints or moving and timed obstacles, since this is a small simple course and the prompt did not request them.

## Layout requirements
Place one `winner-zone` on the fifth-level summit platform, centered beyond the final legal climb. No other post-segmentation placements are required.

## Layout components
Build five clearly readable stacked levels inside one small tower footprint. Each level is a safe landing zone connected upward by a short climbing sequence, with no route branching and no impossible gaps. Use chunky rounded platforms, bold color blocking, oversized toy-like rails, and clear contrast between traversable surfaces and the surrounding void. The first level is the entry floor; levels two through four are compact intermediate landings; level five is an open celebratory summit. The tower boundary is open-sided enough to reveal the climb in isometric view while guard geometry frames each landing. Keep all five levels visible as one coherent vertical composition.

## Render order
Use `topdown`: the ordered ascent and valid platform spacing must be established first, then the isometric render dresses the playable plan.

## Scale, theme, and pipeline cost
Scale is small, driven by exactly five compact levels. The theme is colorful, rounded cartoon construction. `P6` is required because the climbing chain must be valid by construction, and `P2` is required because stacked levels overhang surfaces below.
