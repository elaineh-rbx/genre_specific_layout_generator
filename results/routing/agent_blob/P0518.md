# Agent decision

## Clarifications resolved
- [author] genre — Q: What kind of avatar tower - a tower you climb like an obby, a tower that displays avatars or outfits, or somewhere to change your avatar? A: Make it a tower you climb like a simple obby.
- [author] theme — Q: What should it look like - stone, neon, cartoon? A: Use a colorful cartoon look.

## Enriched image prompt
Create a small colorful cartoon obby tower with exactly five stacked climbable levels rising from a bottom start to a clear reward platform at the top.

## Genre
Obby & Platformer is the dominant genre.

## Shape and preset
Use `course-tower`, Tower / Spiral Ascent, because five obstacle levels stack directly above one another. Use the Tower Obby preset, omitting timed obstacles to keep the course simple as requested.

## Config requirements
Use `path-track` for one ordered platform route through all five levels, `obstacle-climb` for the simple upward transitions between levels, and `winner-zone` for the visible payoff platform at the tower top. Do not add outfit displays, avatar-changing rooms, complex moving hazards, or unrelated tower interiors.

## Layout requirements
Place one free-text SpawnZone at the bottom of level 1. For `winner-zone`, place one completion trigger on the top platform of level 5. No checkpoint is inferred for this short five-level course, so a fall restarts the tower.

## Layout components
The build is one compact vertical tower containing exactly five stacked obstacle levels. A single sequential route begins on the bottom start pad, climbs through each level once, and ends on the level-5 reward platform. Every required jump and climb has a clear landing surface and remains within standard avatar reach. The tower walls or open outer silhouette define the boundary, and the five-level stack should read clearly in one isometric view.

## Render order
Use `topdown`: the five-level route must be valid by construction before colorful cartoon dressing, while `authored_plan` is unavailable because this is neither a supported maze nor a racing route.

## Scale, theme, and pipeline cost
Scale is small, explicitly driven by only five compact levels. The theme is colorful cartoon. Use `P6` because every obstacle connection must be valid by construction, plus `P2` because the five levels overhang one another.
