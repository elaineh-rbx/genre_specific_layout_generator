# Scene prompt
Create a bright, stylized island adventure map with a simple colorful look, built as a sequence of islands that increase in challenge. Each island provides explorable terrain and scattered ingredient-gathering areas, with a cooking spot as a clear central destination before the route continues to the next island.

# Agent decision

## Genre
The dominant genre is Adventure, with Simulation secondary: exploration and forward travel organize the map, while gathering ingredients and repeatedly cooking five meals supply the task loop.

## Shape and preset
Use `route-guided`, one continuous forward sequence through the islands, with each island acting as a stage before the next. The preset is none because no Adventure or Simulation preset preserves both the staged island journey and central cooking loop without adding unrequested systems.

## Config requirements
Use `island-cluster` for several colorful landmasses separated by water, `path-trail` for the readable forward route across each island and onward, `trigger-task` for a visible central cooking spot on every island, and `gate-progression` for the physical threshold to the next island. Ingredient-gathering areas should be visibly distinct and become more spatially challenging from island to island.

## Layout requirements
Place the functional half of `trigger-task` once at the clear center of each island. Place `collectible-nodes` as ingredients across each island’s explorable terrain, distributed away from the cooking spot but along reachable branches. Site one progression gate at each onward route; its layout marks the transition that opens after the player cooks exactly five meals on that island. The brief gives no island or ingredient count.

## Layout components
Build a forward sequence of bright stylized islands, each with a central cooking station, several scattered gathering pockets, and one clear onward connection. Increase challenge through longer or less direct terrain routes without inventing specific hazards. Water separates the landmasses and defines the outer boundary. Bridges, stepping connections, or another visible continuous crossing should link the ordered islands. Compose the frame so the current island’s cooking destination and the next-island direction are immediately readable.

## Render order
Render `topdown` first and make it authoritative, then dress the isometric image, because the ordered island connections and reachable gathering branches must remain valid.

## Scale, theme, and pipeline cost
Scale is large because several sequential islands must fit a progression arc. The theme is bright, simple, colorful island adventure. Use `CHECK` for water-separated landmasses; the route remains one continuous map rather than separate chapter maps.
