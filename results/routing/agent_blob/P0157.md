# Scene prompt
Create a 3D horror escape map set inside a single-floor facility: a tense network of corridors leading toward a clear exit, with enclosed rooms and connecting hallways arranged for pursuit.

# Agent decision
## Genre
The dominant genre is Survival because an AI granny pursues the player through a facility while the player tries to reach an exit.

## Shape and preset
Use `warren-looping` as a single-floor facility circulation network with interconnected corridor loops and zero dead ends, while still giving the overall escape route a clear destination. The preset is Escape. Retain its hiding geometry and exit, but drop `building-interior` because the facility interior is the entire map and no exterior transition is played.

## Config requirements
Draw `cover-los` as wall recesses, lockers, equipment bays, room corners, and short corridor offsets that let the player break the pursuer’s sightline. Draw the visible half of `gate-escape` as one unmistakable exit door embedded in the facility boundary. Keep rooms and hallways enclosed, distressed, and readable enough that pursuit routes remain navigable.

## Layout requirements
Place one `spawner-npc` origin for the AI granny in an interior room well separated from the player start and the final exit, with immediate access to the looped corridor network. Place the functional half of `gate-escape` as exactly one win trigger at the exit door. No key pickups, power controls, or prerequisite triggers are needed; reaching this trigger directly completes the escape.

## Layout components
Build one floor of enclosed rooms joined by a tense network of connecting hallways. Use several corridor loops and cross-links so the pursuer cannot force the player into accidental dead ends, while maintaining a readable progression from the start side toward the exit side. Add lockers, equipment cabinets, maintenance clutter, observation windows, and recessed doorways as pursuit cover. The facility shell forms a hard boundary with no playable exterior. Compose the plan with the start and exit apart, loops through the center, and the pursuer origin offset from both.

## Render order
Render `topdown` first and make it authoritative, then dress the isometric view from the plan; valid zero-dead-end connectivity is essential to fair pursuit.

## Scale, theme, and pipeline cost
Use a medium scale for one focused floor with enough corridor choices to sustain a chase. The theme is severe, claustrophobic facility horror. Route with `P6` because the looping warren must be valid by construction. No `P3` is required because players never cross an outside-inside boundary.
