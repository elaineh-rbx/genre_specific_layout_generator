# Scene prompt
Create a simple stylized-toon tower-defense map on a flat grey baseplate, using clean colorful, highly readable shapes. A straight path made of parts runs from an enemy spawn point at one end to a base at the opposite end. Arrange fixed agent placement slots at intervals along both sides of the path, with open space around them for clear visibility; the base is the path endpoint.

# Agent decision
## Genre
The dominant genre is Strategy, specifically a minimal tower-defense prototype.

## Shape and preset
Use `lane-actor-track`: one fixed, straight, continuous path links the enemy origin to the base. The preset is Tower Defense, but omit its usual `choke-bottleneck` because the brief explicitly requires an open straight path.

## Config requirements
Use `buildzone-grid` for fixed, clearly marked agent slots at regular intervals along both sides of the lane. Use `tracker-core` for the colorful, immediately readable base structure at the endpoint. Keep the baseplate flat and grey while using clean toon colors and simple silhouettes to distinguish path, slots, spawn, and core. Do not draw menus, account systems, currency counters, or wave UI into the world.

## Layout requirements
Place one `spawner-npc` at the first end of the straight path and constrain enemies to its ordered centerline. Place the `tracker-core` objective at the opposite endpoint. Place agent deployment markers at each fixed slot, evenly spaced on both sides with open clearance around every marker. The prompt gives no slot count, so use a modest symmetrical set suitable for a simple prototype rather than inventing an exact quantity.

## Layout components
Build one flat rectangular grey baseplate. A straight path of contiguous parts runs down its center from the enemy spawn to the defended base. Two parallel rows of colorful fixed agent slots flank the lane, leaving open visibility and clean targeting space between structures. Use a low perimeter curb or simple board edge as the boundary and avoid decorative clutter. Compose from a slightly raised angle that keeps the complete path, both slot rows, spawn, and core readable in one frame.

## Render order
Render `topdown` first and make it authoritative, then dress the isometric view, because the fixed enemy route must remain continuous and every placement slot must stay outside it.

## Scale, theme, and pipeline cost
Scale is small, driven by the single straight lane and minimal prototype scope. The theme is clean, colorful stylized-toon geometry on a grey baseplate. Use `P6` because the enemy track must be valid by construction.
