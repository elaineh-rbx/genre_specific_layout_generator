# Scene prompt
Create a 3D obby map built across a giant keyboard, with eight platforming stages numbered 1 through 8 arranged sequentially over the oversized keys.

# Agent decision
## Genre
The genre is Obby & Platformer: players traverse eight discrete platforming stages at their own pace.

## Shape and preset
Use `course-flat`, a horizontal sequence carried across the giant keyboard. The closest preset is Classic Obby, adapted so the oversized keys provide the platforms.

## Config requirements
Draw `path-track` as one ordered chain across exactly eight numbered stages. Use `obstacle-jump` for physics-legal jumps between oversized keycaps. Draw `checkpoint-respawn` as a safe labeled landing pad at each stage boundary, and draw `winner-zone` as the clear payoff area after stage 8.

## Layout requirements
Place eight `checkpoint-respawn` functions, one on the safe opening key of each numbered stage, so failure returns the player to the current stage. Place one `winner-zone` at the reachable end of stage 8. Keep every critical jump at no more than 11 studs horizontally and 7.2 studs vertically at default movement settings.

## Layout components
Build one enormous freestanding 3D keyboard as the course base, with rows of raised blocky keys and visible gaps between them. Route stages 1 through 8 sequentially from one end of the keyboard to the other, using clusters of keys as landing platforms and short connector keys to prevent route ambiguity. Mark each stage number prominently at its start and keep the eight stage areas visually separable while preserving one continuous path. The surrounding floor or void acts as the failure boundary. Compose the view high and oblique enough to read the keyboard silhouette, all eight labels, the start, and the finish.

## Render order
Use `topdown`: a valid continuous jump chain and unambiguous order from stage 1 through stage 8 must lead the visual dressing.

## Scale, theme, and pipeline cost
The scale is medium, driven by eight stages spanning a giant keyboard. The theme is playful oversized computer hardware in clean 3D. Use `P6` because all platform spacing and the complete stage sequence must be valid by construction.
