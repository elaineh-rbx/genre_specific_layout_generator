# Agent decision

## Clarifications resolved
- [author] theme — Q: What do the rooms look like - a modern house, an old mansion, a laboratory? A: Use an old mansion theme, with distinct objects and furnishings in each room to hide the keys among.
- [author] scale — Q: How many rooms in the chain, and how big is each one? A: Make a small chain of 3 rooms, each a compact single-room escape area that is easy to explore.
- [agent_inferred] key count — Q: How many required key items should each compact room contain? A: Use one required key item per room, hidden among that room's distinct furnishings.

## Enriched image prompt
Create a small old-mansion escape map made from exactly three compact enclosed rooms connected in a strict sequence. Give each room distinct furnishings and objects, with enough clear floor to search easily. Hide one required key item among the objects in each room and place a visibly locked mansion door at its exit; unlocking that door leads into the next room, while the third door leads out of the chain. Increase hiding difficulty through the sequence without enlarging the rooms.

## Genre
The genre is Puzzle.

## Shape and preset
Use `rooms-sequence`, a Zone (Sealed Chambers) containing three locked rooms worked through in order. The preset is Escape Room, dropping its unsupported button and clue-wall features and using physical keys and receptacles instead.

## Config requirements
Use `gate-progression` for the three locked mansion doors and `trigger-solve` for the visible keyholes or key receptacles on those doors. Each room's distinct old-mansion furniture and hiding objects are direct scene-specific visual requirements. Do not add `button-solve` or `facade-clue`.

## Layout requirements
Place exactly three `collectible-nodes` Collectibles, one key item hidden among the furnishings of each corresponding room. Place exactly three `trigger-solve` TriggerZones at the exit doors, each accepting only its room's key and opening forward into the next room or, for room three, out of the map.

## Layout components
Build three compact single-room segments in a linear chain. Every room has a distinct furniture arrangement, one searchable key hiding area, one entrance, and one locked forward exit. Corridors or thresholds between rooms remain short, and no alternate route bypasses the order. Compose the cutaway so all three rooms and their progression direction are clear.

## Render order
Use `topdown` because the sealed three-room sequence and one-way progression must be unambiguous before mansion furnishing is applied.

## Scale, theme, and pipeline cost
Use small scale because each room is compact and keys must remain findable among furniture in one frame. The theme is an old furnished mansion. `P0` is sufficient because the map is one connected interior sequence with no maze topology, outside transition, or overhanging playable floor.
