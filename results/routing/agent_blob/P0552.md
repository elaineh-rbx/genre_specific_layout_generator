# Scene prompt
Crea un mapa 3D de una calle de ciudad moderna, sencilla y clara, corta y compacta. Alinea cuatro bases separadas, una para cada jugador, a lo largo de la calle; cada base tiene espacio para colocar objetivos coleccionables y crece verticalmente de forma visible hasta 15 pisos. Sitúa una zona de aparición de objetos y un estacionamiento en la calle, conectados claramente con las cuatro bases mediante la vía principal.

# Agent decision
## Genre
The genre is Simulation, specifically a collection tycoon: players carry spawned objectives to personal bases, generate money, and visibly upgrade those bases.

## Shape and preset
Use `plot-isolated`: exactly four independent player-base plots line one shared compact street. Match the Tycoon preset, substituting isolated per-player plots for its shared team plot and omitting the central bazaar because the street’s object-spawn area is the shared destination.

## Config requirements
Apply `gate-progression` as the visible locked construction stages through which each base grows to exactly 15 floors. Apply `path-circulation` as the short main street and sidewalks connecting all four bases to the object-spawn zone and parking area. Draw a clear deposit/display area inside every base where collected objectives can accumulate.

## Layout requirements
Place `collectible-nodes` in the designated shared object-spawn zone beside the street, with multiple spawn points distributed across that zone rather than inventing a collectible count. Keep every node directly reachable from the parking area and from all four base entrances. Money generation and speed-shop purchases are gameplay systems and add no invisible layout placements.

## Layout components
Build one short, straight modern-city street with two base plots on each side or four evenly aligned along one edge, while preserving equal travel distance to the shared objective area. Each of the exactly four plots needs a distinct entrance, a ground-level collectible deposit/display pad, and a base tower footprint capable of visibly progressing to exactly 15 floors. Place the object-spawn plaza and a compact marked parking lot at a central or end-cap node on the same road. Use level asphalt, concrete sidewalks, simple curbs, streetlights, and low plot dividers. Bound the compact block with clean city facades or a perimeter wall. Frame the isometric view so the street, all four bases, spawn plaza, parking, and tower growth are legible together.

## Render order
Use `isometric`: establish the vertical tycoon identity and compact streetscape first, then derive the top-down plan; the straight road network has no topology requiring procedural construction.

## Scale, theme, and pipeline cost
Use a medium scale band, driven by four compact plots despite their 15-floor visual growth. The theme is a simple, clean contemporary city block. Route through `P0`; no prompt text requires traversable stacked floors or outside-to-inside transitions.
