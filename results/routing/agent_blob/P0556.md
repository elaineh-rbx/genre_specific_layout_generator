# Scene prompt
Create a clean, abstract 3D labyrinth with simple geometric walls, clear paths, and high visibility. The maze contains extensive but compact branching corridors designed to take a few minutes to solve, leading through logical route choices toward a final exit.

# Agent decision
## Genre
The genre is Puzzle: the player explores a three-dimensional maze and uses logic and observation to find the correct route to the final exit.

## Shape and preset
Use `puzzle-maze`: the solvable corridor topology is the challenge itself, with compact branching choices leading from one entrance to one reachable exit. Match the Maze / Labyrinth preset, but omit its collectible items because the prompt asks only for route-finding.

## Config requirements
Apply `path-loop` as selected corridors that reconnect to the central route, limiting frustrating backtracking while preserving meaningful wrong choices. Draw the maze with simple abstract geometric walls, consistent corridor width, clear intersections, and high visibility. Give the final exit a distinct visible frame or opening so its role is immediately legible once reached, without adding clues, keys, hazards, enemies, or decorative clutter that the brief did not request.

## Layout requirements
Nothing needs placement after segmentation. The challenge is entirely the authored corridor network and reachable exit; there are no collectibles, checkpoints, buttons, NPCs, trigger targets, or progression gates to site.

## Layout components
Build one compact rectangular labyrinth zone with a single entrance near one outer edge and one final exit on a different outer edge. Between them, create extensive branching corridors sized for a few minutes of exploration, mixing short false branches, recognizable junctions, and several loop-back connections that return players toward useful routes. Keep all corridors level and use uniformly tall, clean geometric walls with open space above, strong floor-wall contrast, and unobstructed sightlines at each immediate choice without exposing the whole solution. Enclose the play space with a continuous outer maze wall. Compose the dressed isometric view from high enough to communicate the abstract structure while preserving wall readability.

## Render order
Use `authored_plan`: generate the solved maze blueprint in code first, then derive the top-down and isometric images from that authoritative plan, because a sealed route or unreachable exit would make the game unplayable.

## Scale, theme, and pipeline cost
Use a medium scale band, driven by a few-minute solve with substantial but not sprawling branching. The theme is clean, bright abstract geometry with accessible contrast and no threatening elements. Route through `P6` because maze solvability must be guaranteed by construction.
