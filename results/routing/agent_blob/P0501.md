# Scene prompt
Create a 3D Tower Defense game layout in a medieval world blended with technology. Begin with a large, polished lobby centered on a fountain, with distinct physical areas for a tutorial NPC, shop, code redemption, achievements, and a player leaderboard; surround it with detailed trees, rocks, flowers, mountains, and rivers. Place several prominent elevator portals around the lobby, one each for Easy, Normal, Hard, and Nightmare matches, with enclosed elevator interiors and animated doors. Build the first match map as a compact Forest arena with a single clearly visible enemy route winding from a spawn entrance to a defended base, leaving open ground along the route for tower placement. The forest path has its own distinct layout, while later Castle, City, Snow, Volcano, Laboratory, and Desert maps each use a different enemy path arrangement.

# Agent decision
## Genre
The dominant genre is Strategy, specifically tower defense.

## Shape and preset
Use `lane-actor-track` for the first Forest match: one continuous, unambiguous enemy route winds from its entrance to the defended base. The preset is Tower Defense. The lobby remains a separate support map, while the six later named maps are deferred rather than rendered now.

## Config requirements
`buildzone-grid` draws clear, flat tower-placement ground along both sides of the forest route. `tracker-core` draws the defended base at the lane’s end. `npc-population` draws the tutorial NPC and its station. `building-interior` draws four enterable elevator interiors with doors. `water-body` draws the lobby rivers, and `terrain-relief` draws the surrounding mountains. The lobby also includes a central fountain and five distinct service areas for tutorial, shop, codes, achievements, and leaderboard.

## Layout requirements
Place one `tracker-core` marker at the Forest base and one `spawner-npc` at the route entrance. Place the tutorial NPC at its station. Place one teleport trigger inside each of the four Easy, Normal, Hard, and Nightmare elevators. Keep the Forest lane continuously traversable and all build ground accessible from the match arrival area.

## Layout components
Build a large scenic lobby centered on one fountain, with five service areas nearby and four prominent elevator bays around the perimeter. Trees, rocks, flowers, rivers, and mountain silhouettes frame it. The separate Forest match is compact: one winding route crosses woodland from spawn to base, flanked by open build pads and bounded by dense trees and rocks. Compose the match from high enough that most of the full route is visible at once.

## Render order
Use `topdown`: the single enemy route must be valid and readable before the isometric forest dressing.

## Scale, theme, and pipeline cost
Scale is large because it combines a substantial lobby with one compact match. The theme is polished medieval woodland fused with restrained technology. Use `P6` for the valid lane, `P4` for separate lobby and match maps, `P3` for entered elevator interiors, `tiered` for mountains, and `CHECK` for rivers.
