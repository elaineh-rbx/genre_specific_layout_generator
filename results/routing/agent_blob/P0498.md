## Enriched image prompt
Create a generic futuristic tower-defense experience with two separate spaces. The lobby is a compact high-tech hosting hub with three identical teleport pads arranged around a central gathering area. Each pad launches a separate instance of the same match map. The hosted match is a medium open field with one enemy deployment edge and one defended futuristic core on the opposite side. Keep the ground between them broad, continuous, and buildable, with no fixed lane: enemies must be able to find a new route across the open terrain whenever players place walls. Use clear placement ground and sparse futuristic landmarks that do not create accidental impassable pockets. Present original scout, gun, wall, mech, and heavy-tech visual motifs without copying named units or games.

## Genre
The dominant genre is Strategy.

## Shape and preset
Use `space-staged`, a Zone (Lobby and Isolated Stage), taken from outside Strategy’s usual set because the hosting lobby and match are separate maps. The match segment uses `terrain-open`, Zone (Open Contested Terrain), rather than a fixed enemy lane. The preset is Tower Defense, with its lane, placement grid, and authored chokepoint replaced by dynamic open-ground pathfinding and free wall placement.

## Config requirements
Use `social-hub` for the lobby center and the visible side of `teleporter-link` for three hosting pads. In the match, use `buildzone-plot` for broad open placement ground and the visible side of `tracker-core` for the defended futuristic base. Scout guns, walls, mechs, unit ownership, and rerouting behavior are dynamic gameplay systems rather than fixed image props.

## Layout requirements
Place `teleporter-link` as three Teleporter endpoints in the lobby, each targeting a separate hosted instance of the match template. Place `spawner-npc` as one Spawner along the match field’s enemy edge. Place `tracker-core` as one Tracker at the opposite edge. Preserve a runtime-navigable route between them after legal wall placements.

## Layout components
The Lobby map contains one social hub and three hosting pads. The Hosted Match map contains one medium open build field, one wave-origin edge, one defended core, sparse original futuristic scenery, and broad free-placement ground. These are two map segments, so the `P4` route has an explicit split.

## Render order
Use `topdown`: make the hosting-pad arrangement and open match navigation field authoritative, then dress both isometric scenes from their plans.

## Scale, theme, and pipeline cost
The scale band is medium because wall placements, wave origin, and core must remain legible across the match. The theme is original futuristic military technology with generic scouts and mechs. Use `P4` for lobby-to-hosted-match transitions; no `P6` fixed-lane pass applies because enemies path dynamically over open terrain.
