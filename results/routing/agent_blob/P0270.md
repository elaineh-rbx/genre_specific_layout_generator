# Scene prompt
Create a dim, frightening 3D horror survival map with task locations distributed around the playable area and space for a killer to pursue players between them.

# Agent decision
## Genre
The genre is Survival: players move between tasks while avoiding a pursuing killer, and completing all tasks ends the round.

## Shape and preset
Use `warren-looping`, a compact horror space whose task routes reconnect with zero dead ends so the killer cannot create unavoidable corner traps. The preset is 1 vs All, with its escape gate omitted because task completion itself wins the round.

## Config requirements
Draw `cover-los` as localized wall recesses, lockers, partitions, and bulky props that break the killer’s view while keeping every route readable. Draw several non-catalogued task stations as distinct physical work surfaces distributed across different parts of the map; the brief gives no exact count, so do not invent one.

## Layout requirements
Place `spawn-protected` as separated survivor and killer start areas, screened from one another and connected to different portions of the loop network. Place one interaction trigger at each rendered task station, bound to the matching surface. No `gate-escape` is required. The killer’s navigable ground must reach every task route without dead ends.

## Layout components
The playable area is a dim enclosed horror environment organized as several connected spaces around a central loop, with cross-connections that provide alternate approaches to each task. Short corridors, doorways, and wider pursuit rooms join without terminal branches. Task stations occupy visually distinct pockets around the perimeter and center rather than clustering together. Lockers, partitions, corners, and large props create temporary sightline breaks. Solid walls enclose the map. Compose the scene so a player can read the next junction or task landmark through pools of weak light while deeper connecting routes remain frightening.

## Render order
Use `topdown` because every pursuit path must reconnect and each task must remain reachable through fair alternate routes.

## Scale, theme, and pipeline cost
Scale is medium, allowing distributed tasks without long empty travel. The theme is dim, frightening pursuit horror with sparse pools of task lighting. Use `P6` because the no-dead-end loop structure must be valid by construction.
