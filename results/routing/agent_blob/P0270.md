# Agent decision

## Clarifications resolved
- [author] theme — Q: I assumed horror from the killer - should it be dim and frightening, or bright and cartoonish? A: Make it dim and frightening, since the game is about surviving a killer.
- [author] goal — Q: Do the tasks win the round, or do you still have to escape after finishing them? A: Finishing all the tasks wins the round; no separate escape is needed.
- [agent_inferred] setting — Q: What physical setting holds the chase and tasks? A: Use one compact, single-level interior of connected rooms and looping corridors, large enough for tasks to be spread apart without becoming a maze players get lost in.

## Enriched image prompt
Create a compact dim horror chase map inside one single-level building. Arrange connected rooms and corridors as several interlocking loops with no dead ends, so hunted players always have more than one route away from the killer. Spread visible task stations across different parts of the map rather than clustering them, and place localized hiding and sightline-breaking spaces such as lockers and low crawlspaces along the loops. Keep the lighting frightening and low while preserving clear route silhouettes. Do not add an escape gate: completing the distributed tasks ends the round within the map.

## Genre
The genre is Survival, canonical slug `survival`, because players evade a killer while completing objectives around a chase space.

## Shape and preset
Use `warren-looping`, Path (Looping Warren), so the chase architecture is made of interconnected loops with zero dead ends. The matched preset is 1 vs All.

## Config requirements
Use `cover-los` for localized lockers, low crawlspaces, and room geometry that briefly breaks the killer's sightline without blocking the loops. Use `trigger-task`, taken from Simulation, for visible task stations distributed around the interior. Do not use `gate-escape`, because the author explicitly said task completion wins without a separate exit.

## Layout requirements
Place `trigger-task` TriggerZones at task stations in separate loop sectors, with no two stations sharing the same small room or choke point. Place `spawn-protected` SpawnZones as separated role starts: hunted-player starts distributed around one side of the route network and the killer start screened elsewhere, with no immediate direct sightline between them.

## Layout components
The build contains one compact single-level interior, multiple connected rooms, looping corridors with zero dead ends, several distributed task stations, localized lockers and crawlspaces, separated role starts, and a sealed outer wall. Every room has at least two route connections. Compose the complete loop network and task distribution legibly in plan.

## Render order
Use `topdown`: draw and validate the zero-dead-end loop network, task distribution, and separated starts first, then dress it as a dim frightening interior. The top-down plan is authoritative because a dead end would make the chase unfair and break the shape's required topology.

## Scale, theme, and pipeline cost
The scale is medium, the default for a compact multi-room chase map where task stations, hiding spaces, and corridors remain legible. The theme is dim, frightening indoor horror. Use `P6` because every chase route must remain connected in loops with no dead ends; the entire map is one interior, so there is no outside-to-inside `P3` transition.
