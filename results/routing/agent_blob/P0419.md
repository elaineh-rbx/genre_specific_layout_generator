# Scene prompt
Create a 3D suburban neighborhood for building dream homes, with up to eight separate medium-sized residential lots, each large enough for a house and small yard. Arrange assigned open plots along simple roads with grass verges and scattered trees, leaving each lot clearly defined and protected as its own home-building space.

# Agent decision

## Genre
The dominant genre is Simulation because freeform home construction on protected player plots is a sandbox building loop. No secondary genre is necessary; the brief does not describe open-ended social roleplay.

## Shape and preset
Use `plot-isolated`: eight independent, equally usable residential plots keep each player’s construction from overlapping a neighbor. The matched preset is Sandbox, retaining its defining isolated-plot structure while omitting resource collection and a central shop because neither was requested.

## Config requirements
Use `settlement-density` for a small suburban neighborhood rather than isolated wilderness buildings. Draw up to eight medium open residential lots along simple roads, each with room for one dream home and a small yard, plus grass verges, scattered trees, and clear plot edges. The roads are neighborhood circulation, not hauling routes, so no Simulation road option is added.

## Layout requirements
Place eight protected plot-assignment zones, one per residential lot, each covering the buildable house-and-yard footprint without overlapping roads, verges, trees, or another lot. Give every plot one arrival edge facing the road and preserve equivalent usable area across all eight. No collectible, task, or shop placements are needed.

## Layout components
Build one compact suburban district with eight medium rectangular lots arranged evenly along a simple connected road system. Grass verges separate road edges from the plots, scattered trees soften shared roadside ground, and visible lot boundaries distinguish protected build space. Keep each lot open and mostly flat for construction. The outer neighborhood boundary should be clear but understated, and the composition should show the full road-and-lot pattern in one frame.

## Render order
Render `topdown` first and make it authoritative, then dress the isometric image from it, because eight non-overlapping lots need a legible, balanced plan even though the topology is simple.

## Scale, theme, and pipeline cost
Scale is medium, driven by eight player plots with yards and roads. The theme is clean, simple suburban greenery. Use `P0`; all plots occupy one flat continuous surface with no interiors, overhangs, or separate maps.
