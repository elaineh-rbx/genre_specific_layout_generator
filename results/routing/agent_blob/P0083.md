# Scene prompt
Create three separate small, flat toon-bright hide-and-seek maps that rotate between rounds: a cliff map with colour-blocked rock walls and ledges, a desert map with clearly coloured canyon or sandstone walls, and a town map with colourful building walls, alleyways, and street-facing surfaces. Each map uses bold, easy-to-read wall colours and compact hiding spaces where players can blend against vertical surfaces.

# Agent decision
## Genre
The dominant genre is Party & Casual because the original game is round-based hide-and-seek.

## Shape and preset
Use `space-staged` for three isolated match stages rotated between rounds. Match the Childhood Game preset, substituting its usual continuous shape because the author explicitly requested separate maps.

## Config requirements
Apply `cover-los` as compact arrays of colour-blocked walls, ledges, corners, and street clutter that break seeker sightlines while leaving broad vertical surfaces available for blending. Apply `obstacle-maze` as short, connected hiding routes through cliff recesses, canyon turns, town alleys, and building gaps. Apply `terrain-relief` to the cliff ledges and shallow desert canyon relief, with no overhangs. No enterable building interiors are requested.

## Layout requirements
Place `spawn-protected` in each of the three maps: balanced hider starts distributed near several colour surfaces, plus a seeker start separated from immediate lines of sight. No other invisible placement is required by the brief.

## Layout components
Build exactly three separate small maps. The cliff map uses bold rock-wall colour blocks, broad ledges, and connected recesses. The desert map uses bright sandstone or canyon walls around compact bends and hiding pockets. The town map uses colourful street-facing façades, narrow alleys, corners, and simple street props, with buildings acting as exterior masses rather than interiors. Give every map several large, flat, readable wall planes in distinct colours and enough clear floor for movement. Bound each stage cleanly and compose each plan around a compact loop so hiding pockets do not become dead ends.

## Render order
Use `topdown`: each compact hiding network must remain connected and fair before the toon-bright surfaces are dressed.

## Scale, theme, and pipeline cost
Scale is medium overall because there are three small isolated maps. The theme is flat, bold, toon-bright colour blocking. Use `P4` for separate rotating maps, `P6` for valid connected hiding warrens, and `tiered` for the non-overhanging cliff and canyon relief.
