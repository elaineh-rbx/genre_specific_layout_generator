# Agent decision

## Clarifications resolved
- [author] scale — Q: How long should a round last - is finding the exit a minute of searching, or five? A: Make each round a quick one-minute search so the game stays fast and replayable.
- [author] goal — Q: Does the round end when the first player is out, or does everyone keep going until only the loser is left inside? A: Everyone keeps going after finding the exit; the round ends once only the last player is still inside, and that player loses.
- [agent_inferred] map-count — Q: How many arcade maps should the initial build include? A: Use the narrowest plural: two compact arcade maps, plus a small staging lobby for map selection.

## Enriched image prompt
Create a compact 3D first-person arcade escape game with a small staging lobby and two separate arcade-interior maps selected between rounds. Make each playable map short enough for a one-minute search. Build each as a compact arrangement of connected arcade rooms, with feature walls and room dressing that provide genuine hints as well as misleading visual cues toward one reachable exit. Give the two maps distinct but simple arcade treatments: one bright neon and one retro-colorful. Keep the exit structural but not obvious from the starting room, and avoid long corridors or excessive backtracking. The lobby and either active arcade map are isolated spaces rather than parts of one continuous building.

## Genre
Puzzle is dominant, with Party & Casual secondary for the quick multiplayer map-rotation format.

## Shape and preset
Use `space-staged`, Lobby and Isolated Stage, from outside Puzzle's usual set because a small staging lobby feeds two separately loaded arcade maps. Start from the Escape Room preset, substituting the container shape while retaining compact clue rooms and exits.

## Config requirements
Use `facade-clue` for arcade feature walls that carry true hints and deceptive cues. Use `path-loop` for short reconnecting corridors so wrong turns do not consume most of a one-minute round. Use `social-hub` for the compact map-selection lobby, `teleporter-link` for the lobby-to-selected-map transition, and externally sourced `gate-escape` for one physical exit in each arcade map.

## Layout requirements
For `teleporter-link`, place one lobby departure marker and one corresponding arrival point in each of the two maps. For `gate-escape`, place one exit trigger at the reachable structural exit of each map. Map voting, first-person camera, six-player competition, round timing, and last-player loss logic are mechanics rather than geometry.

## Layout components
There are three map segments. The Lobby is a small bounded staging zone. Neon Arcade and Retro Arcade are separate compact maps, each using `rooms-sequence` as a short connected run of hinting and trick rooms with one hidden-but-reachable exit. Each map keeps routes concise enough for a one-minute search and uses loops to prevent severe dead ends. No segment shares walkable ground with another; transitions occur through the lobby.

## Render order
Use `topdown`: room connectivity and a reachable exit must be established before arcade dressing, but these compact room networks do not require a supported procedural maze blueprint.

## Scale, theme, and pipeline cost
Scale is small, driven by room-level clues and the one-minute search target. The theme is colorful indoor arcade, split into bright neon and retro variants. Use `P4` because the lobby and two active maps are separate spaces.
