# Scene prompt
Create a compact 3D map with a bright, cartoony Roblox-style street lined with 8 separate player base plots. Give the bases an exaggerated, over-the-top modded appearance with special-looking structures and oversized 3D props arranged along the street.

# Agent decision

## Genre
The dominant genre is Simulation (`simulation`): the Steal a Brainrot reference supplies the persistent player-base collection loop, while the private admin panel is UI and does not affect layout.

## Shape and preset
Use `plot-isolated`: eight independent, equally separated player base plots arranged along one shared street. The preset is none because the map uses isolated plots but does not request the collectible nodes and bazaar of Sandbox or the shared plot and gates of Tycoon.

## Config requirements
Draw `path-circulation` as the bright central street linking all eight bases. Render each plot as a clearly bounded special-looking structure with exaggerated silhouette and oversized 3D props, while keeping footprints equal and non-overlapping. Preserve a readable central travel corridor and do not draw an admin panel or other UI.

## Layout requirements
Place one uncatalogued player arrival marker within each of the 8 base plots, set back from the central street and facing outward toward it. No task, rebirth, training, or purchase trigger is stated, so none should be invented.

## Layout components
Build one compact straight street with 4 base plots on each side, for 8 total. Give every plot the same usable footprint and street setback, but vary the exaggerated decorative structures and oversized props enough to make each base feel special. Connect each base entrance directly to the street with a short apron, preserving an uninterrupted central circulation spine. Use low plot dividers and a cartoony perimeter barrier to prevent overlap and close the map. Keep oversized props inside their plots so they do not obstruct movement. Frame the scene from a high oblique view along the street, showing all eight plots and the paired symmetry at once.

## Render order
Use `isometric`: the modded silhouettes and oversized-prop composition lead, and the simple equal-plot plan can be derived from that image.

## Scale, theme, and pipeline cost
Scale is medium: the map is compact but must fit 8 distinct playable plots. The theme is bright, cartoony, over-the-top Roblox street fantasy. Use `P0`; all plots and the street share one exterior surface with no required overhang or interior transition.
