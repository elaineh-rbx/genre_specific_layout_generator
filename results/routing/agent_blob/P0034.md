# Scene prompt
Create a 3D survival map set in a decades-abandoned, overgrown city spanning a few connected blocks. Empty streets and sidewalks run between weathered urban buildings, with vegetation reclaiming pavement, courtyards, and building edges; include accessible-looking alleys and sheltered spaces within the block network for a cat-sized viewpoint.

# Agent decision
## Genre
The genre is Survival: the cat must manage hunger and thirst while evading stray dogs and other predators indefinitely.

## Shape and preset
Use `space-bounded` for a focused cluster of clearly contained city blocks that keeps resources and threats in meaningful proximity. No preset fits without importing base building, disaster destruction, or an escape objective, so the preset is none.

## Config requirements
Use `cover-los` for cat-sized sheltered recesses, low wall cutouts, alleys, and crawl-under spaces that break predator sightlines. Use `settlement-density` for the few connected blocks of weathered urban buildings. The overgrown streets, sidewalks, courtyards, cracked pavement, and vegetation-reclaimed building edges are required scene geometry even though they have no more specific loaded option.

## Layout requirements
Place `spawner-npc` origins for stray dogs and other predators at separated outer alleys and concealed block edges, with patrol ground spanning streets and courtyards but not the cat-only shelters. Place `collectible-nodes` for survival food and water in scattered, risk-balanced locations: some near sheltered recesses and some exposed in courtyards or street crossings. No escape gate is placed because survival is endless.

## Layout components
Build a few connected city blocks around an intelligible street-and-sidewalk network. Include weathered exterior buildings, accessible alleys, small courtyards, low sheltered spaces, cracked pavement, and dense vegetation reclaiming edges and open ground. Keep openings, cover, and path widths legible from a cat-sized viewpoint. Enclose the playable blocks with continuous derelict structures, rubble, and overgrowth. Compose the frame so the street network is readable while foreground shelter communicates the small player scale.

## Render order
Use `isometric`: the overgrown urban atmosphere and cat-scale cover lead the design, while the simple bounded block network can be derived afterward without requiring computed topology.

## Scale, theme, and pipeline cost
The scale is medium, reflecting a few connected blocks. The theme is decades-abandoned, weathered, overgrown urban survival. Use `P0`; all play stays on one exterior grounded surface without required interiors, overhangs, or separate maps.
