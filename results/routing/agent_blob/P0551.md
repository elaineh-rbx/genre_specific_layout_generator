## Enriched image prompt
Create a small shared Georgian farming village with four neighboring personal yards connected by walkable village paths. Enclose each compact yard with wooden fencing and give it one small traditional Georgian house, one modest storage shed, exactly 24 planting plots, and reserved open ground for later expansion. Show active crops in only the available plots rather than attempting to display all 300 listed crop types at once. Keep the farmsteads close enough for players to see and visit one another, use a warm rural Georgian visual register, and add no animals.

## Genre
The genre is Simulation. Growing and selling crops for currency is a repeatable production-and-progression loop; collection completion and XP are supporting mechanics.

## Shape and preset
Use `settlement-claimable` from outside Simulation's usual shape set, adapted as four prebuilt Georgian farmsteads assigned to neighboring players rather than empty construction plots. The preset is none because no Simulation preset preserves both assigned personal yards and this crop-growing loop.

## Config requirements
Use `settlement-density` for the four-farmstead village, `path-circulation` for paths connecting all yards, `building-interior` for each small house and storage shed, and `trigger-task` for the visible grid of 24 planting plots in every yard.

## Layout requirements
Place 24 `trigger-task` planting stations in each of four yards, 96 total, in clear grids with expansion ground left open. Co-locate 24 `collectible-nodes` crop-growth and harvest positions per yard; the 300 crop types rotate through these nodes rather than occupying separate permanent plots.

## Layout components
Build four adjacent fenced yards around a simple shared path network. Each yard contains one traditional house, one storage shed, a 24-plot planting grid, and an undeveloped expansion strip. Paths connect every gate without crossing planting beds. The village edge is rural open ground, and the four repeated farmsteads remain individually legible in frame.

## Render order
Use `isometric`: the Georgian village character and repeated farmstead composition lead, while the straightforward yard grid does not require generated topology.

## Scale, theme, and pipeline cost
Use medium scale, driven by legible individual planting plots across four neighboring properties. The theme is a warm traditional Georgian rural village. `P3` is required because players enter the houses and storage sheds from their yards.
