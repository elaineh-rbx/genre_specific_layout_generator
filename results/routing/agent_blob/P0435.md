# Scene prompt
Create a 3D treasure-hunt map on a compact pirate island, sized for a few minutes of walking between the farthest hidden chests. Arrange varied island terrain and landmarks to provide distinct chest-hiding locations across the map.

# Agent decision
## Genre
The dominant genre is Adventure: players explore a pirate island to find scattered hidden treasure chests. The competitive leaderboard is on-screen UI and does not create a second spatial genre.

## Shape and preset
Use `world-open`, one contiguous compact island that can be searched in any order. The preset is Scavenger Hunt, retaining hidden objective locations and an open search shape while omitting its physical tracker board because the leaderboard is explicitly on-screen.

## Config requirements
Use `alcove-secret` for chest-sized hiding recesses behind rocks, vegetation, and small terrain folds. Use `landmark-focal` for conspicuous pirate landmarks that orient the search and distinguish island regions. Use `terrain-relief` for varied hills and low cliffs without overhangs, and `water-body` for the surrounding sea. Do not draw the hidden chest placements into the base image.

## Layout requirements
Place `collectible-nodes` as hidden treasure chests across distinct reachable island locations, with some near landmark areas and others in discovery alcoves. No chest count was stated, so do not invent one. Separate the farthest nodes by a few minutes of walking, keep every chest on navigable ground, and avoid placing any node inside prop collision or inaccessible cliff pockets.

## Layout components
Build one compact pirate island with a complete beach perimeter, a varied interior of low ridges and shallow valleys, and several visually distinct landmark areas. Arrange natural walking corridors between the landmark regions and branch short search spurs toward rock pockets, vegetation screens, and terrain recesses. Keep the island contiguous and entirely outdoors, with no required interiors or separate instances. Use pirate wreckage, marker structures, and tropical dressing as landmark props without specifying unsupported counts. Bound the map naturally with the sea. Compose the overview so the main island regions are readable while individual hiding alcoves remain visually screened.

## Render order
Use `isometric`: render the pirate-island atmosphere and landmark composition first, then derive the top-down plan, because the hunt does not depend on maze, circuit, or ordered traversal topology.

## Scale, theme, and pipeline cost
The scale is medium, reflecting a compact island with several minutes between its farthest chest sites. The theme is readable tropical pirate adventure. Use `tiered` for varied terrain relief and `CHECK` for the surrounding water, which remains a simple non-self-occluding surface.
