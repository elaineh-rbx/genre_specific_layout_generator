# Scene prompt

Create a 3D atmospheric horror map of an uncanny indoor maze, built from procedural models. Keep the space compact, with roughly 12–16 distinct rooms and connecting corridors before procedural sections begin repeating; arrange a disorienting network of low-ceilinged interior spaces for wandering, with no required exit or chase route.

# Agent decision

## Genre

This is No Genre. It is an atmospheric place for unstructured wandering, with no threat, objective, score, round, or required exit that would make it Survival or Puzzle.

## Shape and preset

No genre shape applies, so use the routing axes. `axis-enclosure` is interior-only; `axis-verticality` remains single-surface; `axis-zone-count` remains single; `axis-structure` remains dressed because the network need not be a solvable maze; and `axis-play-space` remains grounded-surface. Use the Explorable Place preset, retaining circulation and composed environmental views while dropping its orientation landmark because deliberate disorientation contradicts one.

## Config requirements

Use `path-circulation` for the low-ceilinged corridors threading the rooms, but make their grain ambiguous rather than goal-directed. Use `vignette-photo` for uncanny composed room views that sell the procedural horror atmosphere. Draw roughly 12–16 distinct rooms and corridors from modular procedural wall, ceiling, doorway, floor, and light models before repeated sections begin.

## Layout requirements

Place one `spawn-area` in an ordinary-looking room near the edge of the first distinct section, oriented toward a strong initial uncanny view but not toward an exit. The drawn arrival room appears in the image, and its functional player entry marker is sited there after segmentation. Nothing else needs placement: there are no enemies, collectibles, checkpoints, exits, or objective triggers.

## Layout components

Build a compact, bounded single-floor interior containing roughly 12–16 rooms and connecting corridors. Vary room proportions, corridor offsets, doorway positions, and occasional partial partitions while retaining a consistent low ceiling and modular construction language. The network should offer several loops and misleading visual similarities, then transition into repeatable procedural room-and-corridor modules at its outer reaches. Walls form the hard map boundary; there is no exterior. Compose the plan as a dense irregular rectangle with the arrival room off-center and repeated sections receding away from it.

## Render order

Use `isometric`: the atmospheric interior look is rendered first and remains authoritative, since exact maze solvability is explicitly unnecessary.

## Scale, theme, and pipeline cost

Scale is small, fixed by the roughly 12–16 distinct spaces. The theme is uncanny low-ceiling procedural horror with repetition, stale artificial light, and anonymous interior finishes. Use `P0`; one top-down surface captures the entire grounded single-floor interior, and no topology-validity pass is needed.
