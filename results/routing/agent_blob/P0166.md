# Scene prompt
Build a 3D escape-room map set in a plain modern prison facility, with the escape route leading through the prison to the main gate at the map boundary. Include prison interior spaces and an exterior yard or approach immediately before the gate.

# Agent decision
## Genre
The genre is Puzzle: progression comes from solving a prison escape-room sequence rather than fleeing an active pursuer.

## Shape and preset
Use `rooms-sequence`, arranged as prison chambers and corridors worked through in order before opening into the yard. The preset is Escape Room.

## Config requirements
Use `button-solve` for prison keypads, levers, or control panels; `facade-clue` for clue-bearing cell or corridor walls in the player’s natural view; `gate-progression` for locked security doors and the final main gate; and `building-interior` for the prison block entered and traversed before the exterior yard. Keep the architecture plain, clean, and modern rather than horrific or decayed.

## Layout requirements
Place `button-solve` interactions beside the security barriers they control, with each input discoverable from its preceding room. Place `collectible-nodes` as prison key items in cells, offices, or guard stations before the corresponding locked door. No respawn checkpoint count is specified.

## Layout components
Build a directed sequence of enclosed prison spaces: an initial cell area, connected secure corridors and functional prison rooms, then an exterior yard or short open approach. Corridors connect each solved room forward without forming a maze. The main prison gate sits at the outer map boundary and is the final visible exit. Use concrete floors, barred cell fronts, reinforced doors, institutional walls, and perimeter fencing. Compose the map so the interior sequence reads toward the yard and boundary gate.

## Render order
Render `topdown` first and treat it as authoritative, then dress the isometric from that plan, because every prison room, clue, and locked barrier must form a connected solvable sequence to the gate.

## Scale, theme, and pipeline cost
Scale is medium, driven by several sequential rooms plus one yard. The theme is a straightforward modern prison facility. Use `P3` because play crosses from the prison interior into the exterior yard; no maze, separate-map, or overhang modifier applies.
