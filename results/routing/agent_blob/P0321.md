# Scene prompt

Create a 3D game map in a bright anime pirate style: one small, focused tropical island built for enemy encounters and level grinding, with open traversable areas and combat spaces across the island.

# Agent decision

## Genre

The dominant genre is RPG, with Action secondary. Repeated enemy fights that raise player levels make progression the organizing loop, while combat supplies the moment-to-moment activity.

## Shape and preset

Use `space-bounded`, taken from outside RPG’s usual shapes, because the entire first map is one compact island with a naturally clear edge. Preset is none: the Action RPG preset assumes a hub feeding separate dungeons, whereas this brief calls for one focused outdoor island.

## Config requirements

Apply `hazard-aggro` as several broad enemy encounter clearings set away from the main traversal route so fights have room without making every crossing hostile. Apply `water-body` as the tropical sea surrounding the island and defining its boundary. Keep the interior of the island open, readable, and suitable for repeated movement between combat spaces.

## Layout requirements

Place `spawner-npc` origins within each encounter clearing, using the clearing edges and nearby cover to give enemies readable entry directions. Keep emitters off the principal circulation route and distribute them so no two encounter groups immediately overlap. No sailing, quest boards, shops, or inter-island travel markers are required.

## Layout components

Build one small tropical island as a single bounded zone. Arrange several open combat clearings across its interior, joined by simple walkable paths and patches of open traversable ground. Use bright sand, colorful tropical vegetation, stylized rock, and a clear shoreline surrounded by ocean. Avoid docks or routes implying another island. The sea forms the outer boundary. Compose the island in frame so its complete shoreline, path network, and separated fight areas are visible together.

## Render order

Render `isometric` first and treat it as authoritative; this compact outdoor island is appearance-led and its simple circulation does not require a computed plan.

## Scale, theme, and pipeline cost

Scale is small, driven by one focused island. The theme is bright anime pirate tropical adventure. Use `CHECK` because the surrounding sea is a volumetric water feature, though no layered or self-occluding swim space is requested.
