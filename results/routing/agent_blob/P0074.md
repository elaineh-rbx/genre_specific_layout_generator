# Agent decision

## Clarifications resolved
- [author] theme — Q: Beyond grass underfoot, what should the place look like — a park, a schoolyard, somewhere stylized? A: Make it a simple park-like grassy arena with basic obstacles and boundary walls; keep the look plain and functional for testing.
- [author] scale — Q: How big should the walled area be — a small yard or a proper field? A: Use a small yard-sized walled area so the one or two slow-moving NPCs are easy to catch while testing.

## Enriched image prompt
Create a small yard-sized 3D tag arena with a flat grassy floor, plain park-like styling, basic solid obstacles distributed across the play space, and continuous boundary walls that prevent anyone from leaving. Keep the layout open and functional enough to chase one or two slow-moving NPCs, with clear routes around every obstacle and no dense maze.

## Genre
The genre is Party & Casual because this is a physical childhood game of tag in one shared arena.

## Shape and preset
Use `space-bounded`: the entire tag game takes place in one small, continuous, enclosed yard. Preset is none because the Childhood Game bundle would add an unrequested social hub and hide-and-seek maze.

## Config requirements
Use `cover-los` for a sparse set of basic chase obstacles that create route choices without hiding the slow test NPCs. Use `barrier-perimeter`, taken from Sports, for the continuous functional walls around the grassy yard.

## Layout requirements
Place one or two `spawner-npc` origins in open, separated parts of the yard so the slow-moving test NPCs can begin circulating without being trapped against a wall. Place `spawn-protected` player start points away from those NPC origins and clear of obstacle corners. Back-tag detection and NPC movement speed are gameplay mechanics, not static map placements.

## Layout components
The build contains one small flat grass yard, one continuous outer wall, a single open chase zone, and a sparse collection of basic obstacles with navigable gaps on all sides. Keep every route short, avoid dead ends, and frame the whole testing arena clearly.

## Render order
Use `isometric`: the simple park-like arena and obstacle composition lead, and the uncomplicated bounded plan can be projected from it.

## Scale, theme, and pipeline cost
Scale is small because the yard, individual obstacles, and one or two NPCs must all remain immediately legible and easy to reach during testing. The theme is a plain functional grassy park. `P0` applies because the map is one flat bounded surface with no special topology, overhangs, interiors, or separate spaces.
