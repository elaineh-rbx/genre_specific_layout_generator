# Scene prompt

Create a 3D open-sea boat racing map with a straight race course from a clear starting line to a distant finish line. Four boats line up side by side at the start, each carrying a red-and-yellow fast-food-inspired mascot or sign with visible text reading "inspired by McDonald."

# Agent decision

## Genre

The genre is Racing. This is a finite competitive boat run with a stated start and distant finish.

## Shape and preset

Use `route-point-to-point` as one straight open-sea corridor ending away from its origin. The preset is Sprint / Drag, adapted from a ground sprint to four parallel boat starts on water.

## Config requirements

Draw `startpoint-line` as a highly visible line across the water, `lane-corridor` as a clear straight marine course marked by buoys, and `trigger-finish` as a distant finish gate spanning the corridor. Add `spawn-grid` as four side-by-side launch positions with four visible boats. Use `water-body` for the open sea surrounding and underlying the complete course. Each boat carries one red-and-yellow fast-food-inspired mascot or sign with the exact visible text “inspired by McDonald.”

## Layout requirements

Place four `spawn-grid` slots evenly across the starting line, one per boat, all facing directly down-course and spaced to avoid collisions. Place the functional `startpoint-line` once across those slots and one `trigger-finish` detection zone at the exact far end beneath the visible finish gate. No lap or split trigger is needed because this is a single straight run.

## Layout components

Build a compact start zone containing four boats in one aligned row, a long straight open-water race corridor, and a clearly separated finish zone. Use paired buoy lines to define both sides of the route, calm open sea as the traversed surface, and an open horizon as the boundary. Keep the course unobstructed and compose the view from behind and slightly above the four-boat starting row so the distant finish remains readable.

## Render order

Use `topdown`: draw the authoritative straight course plan first and dress the isometric image from it, because the start, corridor, and terminal finish must form one valid racing route.

## Scale, theme, and pipeline cost

Use a medium scale, long enough to establish distance while remaining a single straight course. The theme is bright, simple open-sea racing with red-and-yellow boat accents. Apply `P6` because the racing route must be valid by construction, plus `CHECK` for the traversed water play surface.
