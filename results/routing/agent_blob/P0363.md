# Scene prompt
Create three short arcade kart-racing tracks, each sized for a 60–90 second lap and built for up to eight racers. The first track is fully indoors in a shopping mall, routing through recognizable retail corridors and storefront areas before opening into broad atrium spaces. The second track runs through a giant mushroom environment, with the course winding around and through oversized mushroom forms. The third track is set among clouds, with a suspended race route crossing cloud-filled open space.

# Agent decision
## Genre
The genre is Racing. All three requested maps are finite arcade kart circuits.

## Shape and preset
Use `route-circuit` for each of the three closed loops. The preset is Circuit Racing, applied consistently across three separate themed maps.

## Config requirements
Use `spawn-grid` for an eight-kart launch front on every track, `barrier-guardrail` along dangerous edges and tight turns, and `path-turnaround` for clean circuit bends. Use `hazard-kill` specifically at fall-away edges on the cloud course. Each course needs a visible start/finish line and readable track corridor.

## Layout requirements
Place the functional half of `spawn-grid` as exactly eight aligned slots on each track. Place one `trigger-lap` across each start/finish straight to count the stated three laps. Add `checkpoint-respawn` points after the start and at major sectors of every circuit, oriented along travel. There are three lap triggers total, one per map.

## Layout components
Build three separate 60–90-second circuits. The mall track stays entirely inside, linking retail corridors, storefront runs, and a broad atrium. The mushroom track winds around and through oversized mushroom forms. The cloud track is a suspended roadway crossing open cloud-filled space with protected turns and fall-away margins. Each has one eight-racer grid, one continuous loop, and no ambiguous branches. Treat each map as its own framed composition.

## Render order
Use `authored_plan`: each racing circuit must be computed as a closed valid loop before its theme is dressed.

## Scale, theme, and pipeline cost
Scale is huge overall because there are three separate short tracks for eight racers. Themes are indoor shopping mall, giant mushroom fantasy, and bright cloudscape. Use `P6` for valid circuits and `P4` because the three tracks are genuinely separate maps. The mall is interior-only, so it does not add `P3`.
