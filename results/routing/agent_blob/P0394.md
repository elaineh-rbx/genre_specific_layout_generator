# Scene prompt
Create a compact 3D level-based speed-runner map in a bright neon-pastel style, divided into 3 separate stage areas. Each stage is a roughly 30-second running route at starting speed, lined with oversized glowing bubbles placed along the path as the key collectible terrain props. End every stage with a prominent glowing "BIG WIN" finish-line gateway, with a separate transition area beyond it leading to the next stage.

# Agent decision
## Genre
The dominant genre is Simulation because running over bubbles raises the Speed stat and feeds multiplier and rebirth progression. Racing is secondary because each finite stage is completed at a finish line.

## Shape and preset
Use `world-chaptered`, taken from outside Simulation’s usual shape set, because the author explicitly requires three separate stage areas rather than one surface. Preset is none: Stat Grinder identifies the progression family, but changing its tier-ladder shape and omitting its gates, hub, and rebirth pad leaves too little of that layout bundle.

## Config requirements
Use `station-training` for oversized glowing bubbles that physically line each route and raise Speed when crossed. Use `trigger-finish` for a prominent glowing “BIG WIN” gateway at the end of each stage, with a count of 3. Each stage and its beyond-gateway transition apron are distinct neon-pastel image spaces.

## Layout requirements
The layout half of `station-training` places dense bubble activation points along all three routes, with safe spacing and stronger clusters on the intended running line. The layout half of `trigger-finish` places one terminal detector within each of the 3 gateways. Add two stage-transfer markers with no canonical option ID, one beyond Stage 1 and one beyond Stage 2, each linked to the next stage’s start.

## Layout components
Build 3 separate stage areas, each a compact roughly 30-second route at starting speed. Oversized luminous bubbles form a readable chain along every path. A large “BIG WIN” gateway terminates each stage, followed by a small protected transition apron. Keep each map visually self-contained, with a clear start, forward route, finish, and uncluttered pastel backdrop.

## Render order
Render `topdown` first and make it authoritative, because each running route and bubble line must connect unambiguously to its finish.

## Scale, theme, and pipeline cost
Scale is large overall, driven by 3 separate 30-second stages. The theme is bright neon pastel with smooth glowing accents. Use `P4` for separate maps and `P6` because the racing finish routes must remain valid by construction.
