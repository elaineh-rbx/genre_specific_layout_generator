# Scene prompt

Create a true 3D, third-person room-decorating map set in one modern apartment room with a clean, simple interior. The enclosed room has a floor and walls with a set of clearly distributed floor-level furniture placement slots, leaving open walking space between them; furnishable real 3D models include a sofa, table, chair, lamp, plant, and rug, all sized to rest naturally on the floor.

# Agent decision

## Genre

Simulation is the sole genre. The player performs a concrete room-furnishing task in a real third-person space; this is not a roleplay town and explicitly is not a board or screen game.

## Shape and preset

Use `interior-single`, taken from outside Simulation’s usual set because the entire playable map is one enclosed apartment room with no exterior transition. Preset is none: the nearest Sandbox preset would require isolated plots and resource nodes, neither of which describes this focused furnishing room.

## Config requirements

Draw one clean modern apartment room and six recognizable real 3D furniture models: one sofa, one table, one chair, one lamp, one plant, and one rug. These must read as proper asset-quality furniture with depth and natural proportions, not boxes or images. Draw the visible half of `trigger-task` as six subtle floor-level placement stations distributed around the room. Keep broad walking clearances between every station.

## Layout requirements

Place six functional `trigger-task` placement slots, one corresponding to each required furniture model. Site the sofa slot against a wall, table and chair slots as a usable grouping, lamp beside seating, plant near a lit edge or corner, and rug flat in the central seating area. Every slot must be floor-aligned, non-overlapping, reachable on foot, and collectively exhaustive so filling all six completes the room.

## Layout components

The only zone is a medium rectangular apartment living room bounded by four walls, with a doorway or entry recess for the player but no exterior map. Use a level finished floor and clean modern wall surfaces. The six furnishing slots form a coherent living arrangement around an open central circulation path; no corridors or additional rooms are needed. The furniture models are the named props, each appearing once and resting naturally on the floor. Frame the room from a cutaway elevated corner so all slots, furniture, and walking space remain legible.

## Render order

Use `isometric`: the authoritative isometric view is rendered first because appearance and usable furnishing composition lead, then the top-down plan is projected from it.

## Scale, theme, and pipeline cost

Scale is small because the build is exactly one room. Theme is clean, simple modern apartment. Use `P0`; one non-stacked interior and its floor-level placements require no additional capture path.
