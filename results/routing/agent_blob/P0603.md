# Scene prompt
Create a 3D game map showing a dark forest crossed by a clear path leading from the near edge to the far side, sized for roughly a minute-long walk.

# Agent decision

## Genre
The dominant genre is Adventure: the player undertakes a short directed journey through the forest with the explicit objective of reaching the far side.

## Shape and preset
Use `route-guided` with the Guided Trail preset. Keep the preset’s trail and directional focal point, but drop `reveal-exit` because the brief calls for one continuous outdoor forest rather than an outside-to-inside reveal.

## Config requirements
Use `path-trail` for one clear, continuously walkable route crossing the dark forest from near edge to far edge. Use `landmark-focal` for a lighter far-side clearing or exit marker visible in glimpses through the trees, pulling the player toward the endpoint. Dense trunks, undergrowth, and darkness should reinforce the route without hiding it.

## Layout requirements
Place exactly one player spawn marker at the near end of the forest path, oriented toward the route. Place exactly one finish trigger at the far-side clearing, spanning the full usable path width so reaching the opposite edge reliably completes the journey. No checkpoints are needed for a walk lasting roughly one minute, and no collectibles or combat spawners are requested.

## Layout components
Build one small elongated forest zone. Start with a compact arrival pocket at the near edge, lead into a single readable dirt path through dense dark woodland, and terminate at a brighter clearing on the far side. The route may curve gently for atmosphere but must not branch or dead-end. Use uneven forest ground, roots, rocks, leaf litter, thick tree clusters, and low undergrowth while keeping the path fully walkable. Dense impassable vegetation and tree walls form the side boundaries; the start and far-side clearing close the two ends. Compose the frame lengthwise so the route reads as a journey into darkness toward a faint bright exit.

## Render order
Use `topdown`: draw the authoritative plan first so the start-to-finish route remains continuous and unobstructed, then dress it as the dark forest isometric.

## Scale, theme, and pipeline cost
Use a small scale sized for approximately one minute of walking. The theme is dark, moody woodland with a legible dirt trail and hopeful far-side clearing. Route through `P0`; the map is one exterior ground surface with no extra modifier.
