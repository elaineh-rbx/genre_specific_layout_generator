# Scene prompt
Create a small WWI-style shooting test area built as a short zig-zag trench line of period earthworks. The player spawn sits inside the trench, with an NPC target positioned directly ahead along the trench's forward view.

# Agent decision
## Genre
The genre is Shooter: this is a weapon-testing scene built around firing at one target rather than a competitive match.

## Shape and preset
Use `range-directed`, a short directed practice range whose firing position is inside the trench and whose only target sits downrange. The matching preset is Aim Trainer, retaining its target arrangement but omitting a weapon bench because the Lee-Enfield is already supplied.

## Config requirements
Use `target-practice` for one visible NPC silhouette directly ahead of the player. Draw a short WWI zig-zag trench with earthen walls, timber bracing, sandbags, muddy ground, and a period-earthworks backdrop. No unrelated battlefield structures or opposing base are needed.

## Layout requirements
The layout stage places the functional half of `target-practice`: exactly one target point on the trench floor, centered on the player’s initial forward sightline at a safe short testing distance. It also places one unkeyed player spawn inside the rear end of the trench, oriented toward that target.

## Layout components
The build is one small, clearly bounded trench range. A rear spawn bay leads into a short zig-zag earthen trench, but the first firing segment remains visually open toward the single NPC target. Timber-reinforced walls and sandbag lips form the boundary; muddy ground fills the trench, with compact disturbed earth outside. Compose the range lengthwise so the spawn, forward trench segment, and target are legible together.

## Render order
Use `isometric`: render the period trench atmosphere first, then derive the simple top-down placement plan from that authoritative image.

## Scale, theme, and pipeline cost
Scale is small, driven by the requested short test stretch and single target. The theme is WWI period earthworks in muddy, muted military colors. The route is `P0`; one ground-level trench surface has no overhang, interior transition, separate map, or topology requiring procedural construction.
