# Scene prompt
Create a colorful 3D factory-world map with eight separate themed zones connected in one continuous progression path: Starter, Candy, Toy, Technology, Volcano, Space, Galaxy, and Secret Factory areas. Each zone has a shared collecting ground where basic and rare objects spawn, with visible routes leading to individual player-owned factory plots. Each factory plot begins small and expands to roughly a 60x60-stud footprint, organized as a clear automated production line: object intake at the front, conveyor belts carrying objects through crusher, cutter, melter, press, laser, recycler, duplicator, rainbow, galaxy, and secret machines, then finished-object outputs at the back. Use open sightlines so players immediately see the collect-to-factory flow, with animated belts, processing chambers, storage areas, and space for expanding machinery. Include a central shared-event space in the world with enough open sky and ground for oversized falling objects, golden-object rain, rainbow effects, or a large black-hole landmark.

# Agent decision

## Genre
The genre is Simulation: collecting, automated processing, upgrading, and factory expansion form the core loop.

## Shape and preset
Use `route-guided`, taken from outside Simulation’s usual set, because eight themed zones occupy one continuous progression path. The preset is Incremental Simulator, replacing its open-world shape while retaining progression gates and circulation.

## Config requirements
Use `gate-progression` between the Starter, Candy, Toy, Technology, Volcano, Space, Galaxy, and Secret zones; use `path-circulation` for the continuous route and plot links; use `resource-shared` for each common collecting ground. Use `trigger-task` for factory intake points and `hazard-kill` for the central event ground capable of hosting falling objects or a black-hole event.

## Layout requirements
Use `collectible-nodes` for basic and rare object spawn positions across each of the eight shared grounds. Place one functional `trigger-task` intake at the front of every personal factory plot. Keep event spawn and hazard volumes centered in the shared-event clearing, outside private production lines.

## Layout components
Arrange eight named zones in exact progression order along one continuous path, each with a shared collecting field and visible links to personal factory plots. Every plot expands to roughly 60x60 studs and runs front-to-back through intake, ten machines—crusher, cutter, melter, press, laser, recycler, duplicator, rainbow, galaxy, secret—storage, and output. Reserve expansion gaps while preserving open sightlines. Add one central open-sky event clearing large enough for oversized objects and a black-hole landmark.

## Render order
Use `topdown`: the eight-zone order, continuous route, and readable production flow must be established before visual dressing.

## Scale, theme, and pipeline cost
Scale is huge because eight connected zones each hold shared grounds and multiple expanding plots. The theme is colorful, kinetic, polished satisfying-factory fantasy. Route `P0`; the entire world remains one continuous non-overlapping surface.
