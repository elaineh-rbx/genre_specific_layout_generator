# Scene prompt
Create a 3D tycoon map with separate player plots, each containing a classical stone mansion with simple walkable interiors.

# Agent decision

## Genre
The genre is Simulation: the original request explicitly describes a mansion tycoon with one property per player.

## Shape and preset
Use `plot-isolated`, giving each player an independent mansion footprint with enough separation that builds cannot overlap. The preset is Tycoon, replacing its shared-team plot with personal plots while retaining visible construction progression and circulation.

## Config requirements
Use `gate-progression` for mansion sections, walls, and rooms that appear as the tycoon advances. Use `path-circulation` for the approach from the shared map into each property. Use `building-interior` because every classical stone mansion must contain a simple enterable interior linked to its exterior.

## Layout requirements
Place one claim and player-start position at the front edge of every mansion plot, outside the building footprint and clear of future construction. Place purchase triggers in a readable sequence through the plot and simple interior, tied to the mansion sections they unlock. No fixed plot count was supplied, so the repeated unit should scale to server capacity rather than inventing a quantity.

## Layout components
Each personal plot contains a classical stone mansion, a short front approach, an exterior build yard, and a simple walkable interior. The interior should use a small set of broad connected rooms rather than a complex floor plan, with a clearly aligned front door linking the exterior and interior captures. Space plots evenly with visible boundaries and shared circulation around them. Keep the ground level and the mansion massing readable; stone walls, columns, steps, and restrained formal landscaping establish the theme. Frame several separate estates while preserving a clear view into one representative mansion entrance.

## Render order
Use `isometric`: the classical mansion appearance and estate composition lead, while the straightforward room and plot plan follows from the dressed view.

## Scale, theme, and pipeline cost
Scale is medium for several personal mansion plots. The theme is classical stone estate tycoon. Route `P3` because play crosses from each exterior plot into a walkable mansion interior, requiring linked outside and inside plans.
