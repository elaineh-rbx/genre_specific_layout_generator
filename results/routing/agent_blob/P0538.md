# Scene prompt
Create a bright, cartoony tropical island map for a beach resort tycoon, kept compact as a small resort beach island. Arrange separate player-owned resort plots around the island’s beach areas, with ocean surrounding the shoreline. Include palm-lined sand, clear coastal water, and lively scenery such as rolling waves and swaying palm trees.

# Agent decision

## Genre
The genre is Simulation because each player operates a personal beach resort tycoon.

## Shape and preset
Use `plot-isolated`: separate player-owned resort plots occupy independent beach footprints around one compact island. The preset is Tycoon, with its shared-team shape replaced by personal plots to match the brief while retaining progression-oriented resort build areas and circulation.

## Config requirements
Use `gate-progression` for visible resort expansion boundaries within each plot, and `path-circulation` for clear walkable links among plots and the shared beach edge. Use `water-body` for the clear ocean surrounding the island. Palm-lined sand, rolling wave forms, swaying palms, and lively tropical set dressing must remain visible scene geometry rather than additional gameplay systems.

## Layout requirements
Place one player claim or spawn position at the landward entrance of each resort plot and keep it clear of the waterline. No other post-segmentation placement is required by the prompt.

## Layout components
Build one small resort beach island with a continuous sandy shoreline and several clearly separated resort plots distributed around the coast. Each plot gets a compact buildable footprint opening toward the beach, with a path joining it to the other plots without cutting through private build space. Ring the island with clear coastal water and rolling waves; line the sand with clusters of swaying palms while keeping plot entrances and sightlines open. The island itself is the boundary, and the composition should show the complete coastline and multiple resort plots in one cheerful frame.

## Render order
Use `isometric`: the cartoony tropical atmosphere, animated-looking scenery, and resort presentation should lead, with the uncomplicated plot arrangement derived afterward.

## Scale, theme, and pipeline cost
Scale is medium because the island holds multiple plots but remains a small resort beach. The theme is bright, cartoony, polished tropical Roblox resort. Route `CHECK` because the surrounding ocean is volumetric play-adjacent geometry that should be checked for self-occlusion; no additional modifier is forced.
