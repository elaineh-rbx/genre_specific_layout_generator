## Enriched image prompt
Create a small, bright, cartoony neighborhood for a house-building and dress-up game. Arrange exactly eight uniform empty house plots in a clean grid, each with enough flat space for one player to design and decorate a home without overlapping neighboring builds. Connect all plots by simple pedestrian paths to a compact shared shopping hub containing enterable decoration, furniture, and clothing shops. Keep the residential plots visually separate from the busier storefront area while preserving short, obvious walking routes between them. Use playful colors, simple friendly forms, and an uncluttered top-down composition that shows all eight plots and the central shops at once.

## Layout requirements
Place exactly eight free-text Plot placements, one centered within each empty `buildzone-plot` footprint, with uniform boundaries and non-overlapping build extents. No additional fixed triggers, pickups, or spawners are required; purchasing, decorating, building, and dressing are gameplay systems.

## Layout components
The map contains eight square empty residential lots, one compact shared shop cluster, walkable paths linking every lot to the shops, and a clear outer neighborhood boundary. Keep the plots evenly spaced and the shop zone close enough that the first map remains small and playable.

## Render order
Use `topdown`; the exact eight-plot grid, non-overlap, and pedestrian connectivity should be authoritative before cartoony dressing.

## Scale, theme, and pipeline cost
Scale is medium because eight individually legible house plots and a shop cluster must share one frame. The theme is bright, cartoony, simple, and playful. Use `P3` because play crosses between the neighborhood exterior and enterable shops or player-built house interiors.
