# Scene prompt
Create a 3D incremental game map with hyper-realistic visuals: a small park plaza centered on a lake, where people gather along the water’s edge to throw coins. Arrange three separate shops around the lake: an item-selling shop, a coin-upgrade shop, and a luck and item-value upgrade shop, all connected by clear walking paths around the park.
