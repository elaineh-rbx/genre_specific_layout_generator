# Scene prompt
Create a compact, low-poly fantasy medieval kingdom defense map. A central castle sits at the end of one clearly visible, winding path; place a distinct enemy spawn area at the opposite end, with the path taking a basic goblin roughly 20 seconds to traverse unobstructed. Keep open terrain around the readable route. Add exactly two fixed construction locations beside the path: one Archer Tower site and one Barracks site, each with matching nearby build and upgrade interaction tiles; include a nearby castle-repair tile. The Archer Tower is a raised defensive tower, while the Barracks is a small military building that serves as the origin point for friendly swordsmen. Use only minimal supporting scenery so the castle, path, spawn area, construction sites, and interaction tiles remain immediately legible.

# Agent decision
## Genre
The dominant genre is Strategy, specifically a walkable tower-defense map whose fixed enemy route and construction positions define play.

## Shape and preset
Use `lane-actor-track`: one continuous winding lane runs from a single wave origin to the castle with no branches or self-crossings. The matching preset is Tower Defense.

## Config requirements
Use `buildzone-grid` as exactly two clearly framed construction sites beside the path, one sized for the raised Archer Tower and one for the small Barracks. Use the visible half of `tracker-core` as the central medieval castle at the lane terminus. Use `choke-bottleneck` sparingly as one readable path bend where enemies bunch without obscuring the route.

## Layout requirements
Place one `spawner-npc` at the path entrance opposite the castle. Place the functional half of `tracker-core` on the castle. Place exactly five interaction-tile triggers: Build Archer Tower and Upgrade Archer Tower beside the Archer site, Build Barracks and Upgrade Barracks beside the Barracks site, and Repair Castle beside the castle. Keep each paired build and upgrade tile adjacent to its corresponding fixed footprint. The Barracks footprint also anchors the friendly-swordsman origin.

## Layout components
Build a compact kingdom with the castle as the dominant endpoint and one distinct enemy-entry clearing at the opposite edge. Connect them with one broad, winding, unbroken path calibrated to roughly 20 seconds of unobstructed goblin travel. Keep flat open grass around the lane. Put the two construction footprints on different readable stretches, close enough to influence the route without narrowing it. Add only minimal low-poly medieval props such as a few flags, rocks, and short fence runs. Bound the map with low walls or impassable woodland. Compose the image so spawn, full lane, both sites, and castle are visible together.

## Render order
Use `topdown`: draw the plan first because a continuous, unambiguous enemy lane is required for the game to function, then dress it isometrically.

## Scale, theme, and pipeline cost
The scale is small, set by the brisk solo run and 20-second lane. The theme is clean low-poly fantasy medieval defense. The route is `P6`, because the enemy track must be valid by construction.
