# Scene prompt
Create a 3D K-pop concert venue with a performance stage facing a small audience area. Behind the stage, connect a backstage dressing room containing display areas for four distinct member dresses to view and try on.

# Agent decision

## Genre
The dominant genre is Entertainment because performing for an audience defines the space. Roleplay & Avatar Sim is secondary because players also browse and try on member-inspired dresses.

## Shape and preset
Use `venue-stage`: a compact concert layout whose stage, audience sightlines, and hidden performer side all share one clear orientation. The matching preset is Performance Venue, extended with the requested dressing-room content.

## Config requirements
Use `spectator-bleachers` for a small audience section facing the performance stage, with gentle stepped seating so rear viewers retain sightlines. Use `social-hub` for open audience-floor space where visitors can gather around the show. Use `spawn-first-reveal` so arrival presents the stage and audience composition rather than the backstage door. Use `backstage-support` for the concealed dressing room directly behind the stage. Add visible free-text display geometry for four distinct BLACKPINK member-inspired dresses, each with its own mannequin, rack, or try-on display.

## Layout requirements
The `spawn-first-reveal` requirement belongs here as well: place one arrival marker at the audience-side entrance and orient it toward the stage. The four dress displays must each have a clearly sited interaction position in the backstage dressing room. No scoring, judging, checkpoint, collectible, or combat placements are needed.

## Layout components
Build one performance stage at the front of a compact concert room, one small audience area facing it, and one backstage dressing room connected immediately behind it by a performer-side doorway. The dressing room contains four distinct dress displays, one each for Jennie, Jisoo, Rosé, and Lisa, arranged with enough clearance for avatars to inspect and try them on. Keep audience circulation separate from the backstage approach. Enclose the venue and compose the frame along the audience-to-stage axis while still revealing the room behind.

## Render order
Use `isometric`: render the concert look first and derive the top-down image from it, since the simple stage-to-backstage connection does not need a computed plan.

## Scale, theme, and pipeline cost
The scale is small, driven by one stage, a small audience, and one dressing room. The theme is glossy BLACKPINK-inspired K-pop concert glamour. Use `P3` because `backstage-support` requires a linked transition into the concealed backstage room; the shallow audience tier does not add a separate overhang.
