# Agent decision
## Clarifications resolved
- [author] scale — Q: How long is a disaster course - a short room-sized gauntlet, or a long winding track that takes an NPC a minute to walk? A: Use a short room-sized gauntlet; NPCs should reach the exit quickly so rounds stay fast and the chaos is easy to watch.
- [author] shape — Q: Is the course one fixed track everyone decorates, or does each player get their own plot to lay out from scratch? A: Each player gets their own small plot to lay out from scratch, so everyone can build and score their own disaster machine during the same round.
- [author] goal — Q: Does a round end when the wave is exhausted, when the budget runs out, or on a timer? A: The build phase uses a timer, then the round ends once the NPC wave is exhausted or has reached the exit.
- [agent_inferred] count — Q: How many independent player plots should the first factory support at once? A: Use four plots, a compact multiplayer set that keeps every room-sized course visible and comparable.

## Enriched image prompt
Create a bright cartoony disaster factory containing four equal, isolated player build plots arranged around a shared circulation and viewing area. Each plot is a short room-sized gauntlet with a clearly reserved NPC entrance, one continuous buildable route, and an exit directly across the plot so waves finish quickly. Leave the route itself open for players to construct ridiculous disaster machines from lava, spinning blades, collapsing bridges, giant boulders, tornadoes, lightning, lasers, explosions, rolling objects, and swinging wrecking balls. Give every plot a safe side gallery where its owner can watch exaggerated chain reactions and humorous ragdolls without standing in the hazard path. Keep the factory colorful, readable, and free of realistic gore.

## Genre
The dominant genre is Simulation because players design, upgrade, and evaluate physics-driven disaster machines on personal plots. Strategy is secondary because NPC waves must follow a valid lane from an origin to an exit.

## Shape and preset
Use `plot-isolated`, named BuildZone (Isolated Per-Player Plots): four independent equal plots let players build and score their own machines simultaneously. The matched preset is Physics Sim with its usual shared-world shape replaced by isolated plots while retaining physics contraptions, dynamic hazards, and circulation.

## Config requirements
Use `physics-rig` for spinning, swinging, rolling, pushing, and chain-reaction assemblies. Use `hazard-kill` for lava, blades, tornadoes, lightning, lasers, and explosions inside each plot. Use `destructible-cluster` for collapsing bridges and breakable assemblies. Use `path-circulation` for the safe factory aisle connecting the four plots. Use the P0 side-gallery interpretation of `spectator-zone` so players can watch each gauntlet without adding tiered stands. Draw the visible half of `trigger-finish` as one exit gate per plot.

## Layout requirements
Place four `spawner-npc` wave origins, one at the entrance of each plot, and four `trigger-finish` detectors, one at the opposite exit. Keep one continuous NPC-clear corridor through every build zone even after player hazards are placed. The build timer, budget, scoring, leaderboards, replay camera, modifiers, progression, unlocks, sound, and ragdoll behavior are mechanics rather than extra layout placements.

## Layout components
The factory contains four repeated plot zones, each a room-sized start-to-exit gauntlet with buildable hazard ground and a safe side gallery. A shared aisle links all four plots without crossing their NPC lanes. Solid dividers prevent hazards from spilling into neighboring plots, and factory walls bound the whole map. The plots coexist on one surface rather than loading separately. Compose them in a compact grid around the central aisle so all four courses and their start-to-exit directions are legible together.

## Render order
Use `topdown`: establish four equal plots, uninterrupted NPC corridors, wave origins, exits, dividers, and viewing aisles before dressing the factory in isometric form. The top-down plan is authoritative because every player-built gauntlet must preserve a valid path from spawn to exit.

## Scale, theme, and pipeline cost
The scale band is medium for the full factory, driven by four room-sized plots and avatar-scale hazards that must remain easy to watch. The theme is a bright exaggerated cartoon factory built for chaotic physics and zero gore. `P6` is required for the continuous NPC route in every gauntlet and is reinforced by each `trigger-finish`; no `P4` applies because all four plots coexist in one map.
