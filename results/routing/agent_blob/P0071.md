# Scene prompt
Create a true miniature-scale tabletop battle diorama viewed from an overhead player perspective, centered on a compact 6-by-6 square grid for arranged figurines. The board supports small custom army pieces such as knights, mages, and mech-warriors placed across opposing sides of the grid. Load one selectable board theme per match: a volcano tabletop, a cluttered desktop with books around the board, or a floating-island diorama.

# Agent decision
## Genre
The dominant genre is Strategy because players position miniature armies on a grid before automated tactical battles.

## Shape and preset
Use `board-grid` for a true miniature tabletop board that players operate from overhead rather than walk across. Match the Board & Card Games preset because its regular playing grid directly supports the auto-battler's unit placement.

## Config requirements
Apply `tile-grid` as exactly 36 equal squares in a compact 6-by-6 board, with clear opposing sides and unobstructed unit silhouettes. Draw small collectible-style knights, mages, and mech-warriors as the figurine vocabulary. Produce three separate selectable visual variants while preserving the identical grid: a volcanic tabletop with lava-lit rock dressing, a cluttered desktop with books around the board, and a floating-island diorama with the grid carried on a suspended landform. Only one variant appears in any match.

## Layout requirements
Place one unit-placement socket at the center of each of the 36 squares. Divide the grid into two opposing deployment regions of 18 sockets each, one on either side, while preserving a readable centerline. Army size is not stated, so do not preassign a fixed number of figurines. No avatar spawn, traversal checkpoint, NPC wave emitter, or objective volume is needed.

## Layout components
Build three separate board maps with the same centered 6-by-6 grid and true miniature scale. The volcano variant uses a dark rocky tabletop rim and controlled lava accents outside the squares. The desktop variant frames the grid with a few oversized books and desk objects that never overlap playable cells. The floating-island variant places the full square board on one suspended island silhouette with open air beyond its rim. In every variant, reserve clear opposing halves for armies, keep all 36 cells selectable, and frame the diorama from overhead with the board as the focus.

## Render order
Render `topdown` first and treat it as authoritative, then dress each isometric variant from that plan, because exact square alignment and placement sockets are necessary for tactical setup.

## Scale, theme, and pipeline cost
The scale is small and genuinely miniature. The theme is collectible tabletop fantasy-and-science-fiction with three selectable skins. Use `P4` because the themes are separate maps loaded one per match, plus `SET` because nobody walks on the board geometry.
