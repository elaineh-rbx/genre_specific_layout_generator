# Scene prompt
Create a 3D multiplayer tag-game map set featuring two separate arenas: build the summer map first as the initial play space, with a sporty map as a second distinct arena. Omit additional maps for now.

# Agent decision
## Genre
The dominant genre is Party & Casual: the source describes multiplayer tag rounds with team-tag and infection variants.

## Shape and preset
Use `space-staged` for two isolated multiplayer arenas. Preset is none: the Childhood Game bundle would add a lobby, maze, and dense hiding cover that this sparse tag brief did not request.

## Config requirements
No canonical image option is required. Draw two open, readable tag arenas without inventing a lobby, spectator area, leaderboard, or hide-and-seek maze.

## Layout requirements
Place `spawn-protected` in both arenas. Each arena needs evenly distributed multiplayer start markers around its perimeter, with team-compatible groupings that do not give one side immediate control of the centre. No static scoring volume is needed because tagging another moving player is not a place in the map.

## Layout components
Build exactly two separate arenas and no additional maps. Make the summer arena first and authoritative: a compact outdoor play space with warm seasonal styling, clear running ground, a few broad route-dividing obstacles, and multiple ways around the centre so players cannot be trapped in one corridor. Make the sporty arena second: a distinct athletic-looking space with court or field-inspired markings, perimeter circulation, and similarly open chase routes. Keep both arenas comparable in playable footprint for multiplayer rotation. Bound each arena clearly with safe walls or fencing and keep the composition legible from above. The prompt does not specify detailed summer props or a particular sport, so keep those themes broad rather than adding unsupported landmarks.

## Render order
Use `isometric`: neither arena has topology that must be generated by construction, so the visual identity can lead and the top-down plan can be projected from it.

## Scale, theme, and pipeline cost
Scale is medium, driven by exactly two separate multiplayer arenas. The themes are bright summer recreation and clean athletic sport. Use `P4` because the arenas are distinct maps; no other modifier is forced.
