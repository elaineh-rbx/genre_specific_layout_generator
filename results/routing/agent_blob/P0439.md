# Scene prompt
Create a colorful, storybook-styled 3D world made of separate small region maps for finding a bunny, dog, cat, and cub. Use New Zealand as the home map, with a welcoming central area where the rescued animals return; include four warm animal beds grouped together there and a feeding area beside them.

# Agent decision
## Genre
The dominant genre is Adventure: players travel among regions to find four named animals and bring them home. No secondary genre is necessary because bed-making and feeding are interactions within the rescue journey, not a separate simulation layout.

## Shape and preset
Use `world-chaptered` with the Scavenger Hunt preset, substituting the preset’s usual open world because the brief explicitly requires separate small maps. The build consists of a New Zealand home map plus four animal-search region maps.

## Config requirements
Draw `alcove-secret` as one gentle hiding site suited to each animal and region. Draw `tracker-quest` as a storybook rescue board in the New Zealand home area. Include `gate-chapter` as clearly readable travel thresholds connecting the home to each separate region. The visible animal beds and feeding area are scene-specific geometry: four warm beds grouped together with feeding bowls and a small preparation surface beside them.

## Layout requirements
Place exactly four `collectible-nodes`, one reachable rescue location each for the bunny, dog, cat, and cub, with one node in each search map. Place the functional `tracker-quest` marker on the rescue board at home. Place four return destinations on the four beds and a shared interaction marker at the adjacent feeding area. Travel thresholds must pair each search region back to the New Zealand home map.

## Layout components
Build five small maps: a welcoming New Zealand home clearing and four compact, visually distinct storybook habitats. The home clearing centers on the grouped bed nook, feeding area, rescue board, and four outward travel gates. Each habitat has a short exploratory path from its arrival point to a concealed animal nook, with colorful plants, rocks, and simple landmark props. Bound each region with soft cliffs, foliage, or decorative horizon scenery. Frame the home as the visual anchor and keep each satellite map compositionally self-contained.

## Render order
Use `isometric`: appearance leads, and each simple region can be converted into its own authoritative top-down without topology-critical computation.

## Scale, theme, and pipeline cost
The overall scale is medium because it contains five small maps and four rescue sites. The theme is colorful, gentle storybook adventure. Use `P4` because the regions are genuinely separate maps rather than one continuous surface.
