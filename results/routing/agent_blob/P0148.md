# Scene prompt

Create a fast-paced escape map set in a tight, compact network of clean liminal maze corridors. Place three collectible keys in separate corridor sections throughout the maze, with an exit elevator positioned as the final destination. A visible red-glowing monster stalks the corridors and pursues players through the maze. Keep the lighting simple, bright, and clean.

# Agent decision

## Genre

The genre is Survival. Although keys gate the exit, the round is principally a high-speed escape from a pursuing monster rather than a logic puzzle.

## Shape and preset

Use `warren-looping` so the compact corridor network has interconnected loops and no accidental dead ends where the pursuing monster can unfairly corner players. Start from the Escape preset, retain its escape-exit intent, and drop its crawlspace cover and outside-to-inside shelter assumption because the prompt asks for clean corridors wholly inside one liminal complex.

## Config requirements

Use the visible half of `gate-escape` for a clearly readable exit elevator at the final destination. Draw a tight network of bright, clean liminal corridors with repeated wall modules, simple lighting, loop junctions, and sufficient visual openings for a red glow to telegraph the approaching monster. Do not add lockers, crawlspaces, shelter buildings, or environmental clutter.

## Layout requirements

Place three `collectible-nodes` as keys, exactly one in each of three separate corridor sections and away from the start and exit. Place one `spawner-npc` for the red-glowing monster on patrol-capable ground that does not overlap the player arrival area. Place the functional half of `gate-escape` at the exit elevator, with its trigger gated by collection of all three keys. Place one player start marker in a fourth neutral section with at least two immediate route choices.

## Layout components

The map is one compact, bounded, single-floor interior. A neutral arrival section feeds an irregular network of clean corridors organized into at least three distinguishable key-search sections connected by multiple loops. The monster origin sits across the network from the player start, while the exit elevator occupies a readable terminal alcove beyond the collection circuit. Corridors remain wide enough for responsive passing and pursuit, with corners and junctions breaking long views but no hiding cutouts. Walls form the map boundary. Compose the plan densely, keeping every key and the elevator reachable without a long round.

## Render order

Use `authored_plan`: code must generate the maze first, and that blueprint remains authoritative so every key section and the elevator are reachable while the chase network stays connected.

## Scale, theme, and pipeline cost

Scale is small, driven by the requested tight and fast-paced round. The theme is bright clean liminal horror punctuated by the monster’s red glow. Use `P6` because the maze and zero-dead-end chase topology must be valid by construction; no `P3` applies because play never crosses an exterior boundary.
