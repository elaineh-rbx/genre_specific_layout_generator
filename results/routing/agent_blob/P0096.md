# Scene prompt

Create a 3D climbing game map as a straight-up tower built from plain stylized blocks. Stack walls, climbable trusses, and high platforms vertically into a clear ascent, with the top of the tower as the destination.

# Agent decision

## Genre

The genre is Obby & Platformer because the player deliberately climbs a sequence of traversal obstacles to reach the tower top.

## Shape and preset

Use `course-tower`, a straight vertical ascent with playable platforms stacked above one another. The Tower Obby preset applies, but omit its timed obstacles because the brief requests only walls, trusses, and high platforms.

## Config requirements

Draw `path-track` as one continuous upward route through the tower. Use `obstacle-climb` for vertical trusses, climbable wall passages, and short wall-to-platform transitions. Draw the visible summit area for `winner-zone`. Keep every landing broad enough for R15 avatars and make handoffs from truss tops to high platforms visually obvious. Use only plain stylized block geometry, with no industrial or ruin dressing.

## Layout requirements

Place the initial spawn on a safe ground-level pad directly before the first climb. Place one `winner-zone` on the top platform, centered away from exposed edges. No intermediate checkpoint is required because the prompt does not request one; a fall returns the player to the base spawn. Validate each truss endpoint and landing against the R15 avatar envelope so the avatar can step off cleanly without colliding with walls or undersides.

## Layout components

Build a compact, straight-up tower around one readable vertical route. A broad base zone leads to the first wall-and-truss climb, followed by alternating high block platforms, upright walls, and trusses that carry the player progressively higher. Offset successive platforms enough to expose the intended next climb while retaining the clear tower silhouette; upper platforms may sit over lower ones. The ground is a simple flat base pad, while open air surrounds the climb. Low perimeter blocks define the base, but the vertical course itself remains exposed. Compose the tower from a three-quarter cutaway angle so the base, every truss connection, stacked platforms, and summit are visible.

## Render order

Use `topdown`: plan the connected climb first because an unreachable truss or landing would make the tower impossible, then dress the authoritative plan isometrically.

## Scale, theme, and pipeline cost

Scale is medium, driven by a single compact but tall tower. The theme is minimal stylized blocks with clear contrasting climb surfaces. Use `P6` for valid traversal construction and `P2` because high platforms overhang lower playable surfaces.
