# Scene prompt
Create a simple dungeon layout with four connected rooms: one contains a monster to avoid, one is the exit, and the remaining rooms form the route between them. The exit leads into a separate dungeon-like other world, where a simple axis-shaped object is hidden.

# Agent decision
## Genre
The dominant genre is Survival, with Adventure secondary because the lethal monster drives play while the hidden objective adds a short search.

## Shape and preset
Use `world-chaptered`: the four-room dungeon and the other world are separate maps joined at the exit. No preset remains recognisable; this is a compact custom escape-and-search layout.

## Config requirements
Draw `hazard-kill` as a visibly dangerous monster room whose threshold communicates instant death. Draw `gate-escape` as the structural exit from the first dungeon. No extra hiding spaces or decorative systems are assumed.

## Layout requirements
Place one `spawner-npc` in the monster room, with its patrol ground confined to that room. Place the functional half of `gate-escape` at the exit-room doorway, linking it to the other world. Place one `collectible-nodes` objective—the axis-shaped object—in a concealed but reachable location in the other world.

## Layout components
Build exactly four simple connected dungeon rooms on the first map: an entry/route room, a second route room, a monster room, and an exit room. Connect them in a readable sequence with short stone corridors while keeping the monster room unavoidable enough to create danger but navigable without entering its lethal center. The exit doorway transfers to a separate dungeon-like other world with branching search space and one recess hiding the axis object. Use flat stone floors, masonry walls, sparse dungeon props, and hard enclosing boundaries. Frame each map from above so all rooms and connections remain legible.

## Render order
Use `topdown`: room connectivity, safe passage past the monster, and reachability of the hidden objective must be established before visual dressing.

## Scale, theme, and pipeline cost
The scale is small, driven by exactly four rooms plus one compact search map. The theme is a simple, dim stone dungeon. Use `P4` because the exit leads to a genuinely separate other world.
