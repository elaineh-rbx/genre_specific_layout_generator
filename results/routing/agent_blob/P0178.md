# Scene prompt
Create a compact 3D escape map inside a giant futuristic computer keyboard floating in a dark room. An open keyboard board forms the main traversable space, with a handful of oversized keys built as room-scale puzzle chambers across the board; each key room contains its own hazards and holds one of four key fragments. Arrange raised and separated keys so players cross gaps and reach higher keys via moving platforms, while laser barriers and falling keys create hazards between or within rooms. Place a massive glowing Exit key as the final destination, sealed until all four fragments are collected, with neon RGB lighting, digital effects, and a visible dark-room backdrop around the keyboard.

# Agent decision
## Genre
The dominant genre is Puzzle, with Obby & Platformer secondary because traversal between the puzzle rooms uses gaps and moving platforms.

## Shape and preset
Use `puzzle-open`: the keyboard is one open board that can be explored in flexible order. No preset remains recognisable because the fragment hunt, open board, hazards, and platforming form a custom escape layout.

## Config requirements
Draw `gate-progression` as the massive sealed Exit key. Use `hazard-kill` for red laser barriers and dangerous falling-key zones, and `obstacle-moving` for moving platforms serving raised keys. Draw four key-room chambers as distinct structures, each with a visible fragment presentation point.

## Layout requirements
Place exactly four `collectible-nodes`, one reachable key fragment in each of four key rooms. Place one `winner-zone` trigger on the glowing Exit key, enabled after all four fragments are gathered. Moving-platform routes must connect the main board to every raised room without trapping players.

## Layout components
Build one giant futuristic keyboard floating against a visible dark-room backdrop. Keep the main board open and traversable, with exactly four oversized keys converted into room-scale puzzle chambers distributed across it. Link raised or separated keys with legal jumps and moving platforms; place laser barriers and falling-key hazard lanes within or between rooms. Reserve a prominent edge or far-end position for the enormous glowing Exit key, visible from the board but physically sealed. Use RGB neon strips, digital effects, dark key frames, and open void around the keyboard as the boundary. Frame the board to show all four rooms and the Exit landmark.

## Render order
Use `topdown`: every room, fragment route, moving-platform connection, and final Exit approach must be reachable before visual dressing.

## Scale, theme, and pipeline cost
The scale is medium, driven by four room-sized keys on a compact board. The theme is neon RGB sci-fi hardware in a dark room. Use `P0`; the traversed surfaces remain representable in one plan without stated overhangs.
