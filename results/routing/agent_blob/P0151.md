# Scene prompt

Create a 3D horror game map called "Survive the Rake": a giant, extremely dark forest spanning several minutes of wandering, with dense trees and shadowy ground paths that let players become lost. Scatter random spawn locations throughout the forest; the space is viewed in first person and lit only by a flashlight. A giant white humanoid monster roams among the trees.

# Agent decision

## Genre

The genre is Survival: the endless loop is evading a hostile roaming monster, dying when caught, and respawning elsewhere in the forest.

## Shape and preset

Use `world-open`, taken from outside Survival’s usual set, because this is one contiguous giant forest explored in any order rather than a contained arena, looping corridor warren, or set of escalating biomes. The preset is none; no Survival preset matches a single roaming hunter, random respawns, no role split, and no escape objective without adding unrequested structures or resources.

## Config requirements

No canonical image option is required. Draw a giant, extremely dark forest with dense tree coverage, shadowed natural ground, and a loose network of subtle paths wide and continuous enough for reliable monster navigation. Keep landmarks scarce so players can become lost. Include the visible giant white humanoid monster only as the hostile subject reference, not as fixed environmental geometry. Do not add shelters, escape gates, collectible resources, artificial cover, roads, or settlements.

## Layout requirements

Place one `spawner-npc` origin for the white humanoid on central navigable forest ground, with a patrol region covering the connected path network and avoiding spawn overlap. Scatter multiple player respawn markers broadly around the map, separated from one another and from the monster origin; the prompt gives no exact count, so distribute enough markers to make each death relocate the player unpredictably. Ensure every spawn faces traversable ground and has more than one route away.

## Layout components

The map is one huge continuous woodland zone bounded invisibly by denser impassable forest. Dense trees create irregular sightline breaks across a mostly level shadowy floor. Faint intersecting paths form broad loops and reconnect often enough for dependable pathfinding, but avoid obvious directional signage or a destination. Openings remain small and infrequent, preventing long safe views. Compose the overhead plan as an uneven dark canopy with narrow path seams and no dominant center visible to players.

## Render order

Use `topdown`: the authoritative plan comes first so all patrol paths connect, every random spawn reaches the network, and tree density never traps the monster.

## Scale, theme, and pipeline cost

Scale is huge, driven by several minutes of wandering. The theme is near-black first-person forest horror, lit locally only by flashlights against a pale monster silhouette. Use `P0`; the grounded outdoor forest is one surface with no overhang, interior transition, separate map, or structural-law modifier.
