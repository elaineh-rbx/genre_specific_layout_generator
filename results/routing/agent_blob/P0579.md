# Scene prompt
Create a 3D cyberpunk city scene designed for walking exploration and sightseeing, using a compact layout of several dense city blocks that emphasize street-level urban atmosphere and a layered futuristic skyline.

# Agent decision
## Genre
This is `No Genre`: it is explicitly a walkable environment for exploration and sightseeing, with no additional game rules or objective.

## Shape and preset
No genre shape is assigned. The routing axes remain exterior, single-surface, single-zone, dressed, and grounded-surface: tall buildings create a layered skyline, but the explored circulation stays at street level and no stacked walkable floors are requested. Use the Explorable Place preset.

## Config requirements
Use `path-circulation` for a legible street-and-alley network threading every block. Use `landmark-focal` for one distinctive futuristic tower that anchors the skyline and orientation without becoming an extra district. Use `vignette-photo` for composed neon street views at key intersections. Add `settlement-density` for several tightly packed urban blocks with narrow frontage, dense building massing, and an intentionally compressed street-level atmosphere.

## Layout requirements
Nothing needs placement after segmentation. This sightseeing scene requires no checkpoints, collectibles, triggers, scoring volumes, spawners, or teleporters.

## Layout components
Build one compact city zone containing several dense blocks around a connected network of short streets, alleys, and small intersections. Place the landmark tower toward the rear-center so it remains visible above nearer roofs. Vary building heights to form the layered futuristic skyline while keeping pedestrian routes on one ground plane. Fill street edges with cyberpunk geometry such as neon shopfronts, signs, utility conduits, vents, kiosks, and overhead visual dressing that does not create a second traversable level. Enclose the playable footprint with continuous building fronts and implied streets beyond the frame. Compose the view low enough to emphasize the walkable streets while preserving the skyline silhouette.

## Render order
Use `isometric`: establish the cyberpunk look and skyline composition first, then derive the top-down plan from that authoritative image.

## Scale, theme, and pipeline cost
Scale is medium because the brief asks for several compact, dense blocks rather than a whole city. The theme is neon cyberpunk urban night. The route is `P0`; all traversal is on one contiguous exterior surface.
