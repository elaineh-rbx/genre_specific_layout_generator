# Scene prompt
Create a photorealistic, entity-free backrooms-inspired free-roam interior made from several distinct office-like room chunks stitched together and reused to suggest an endless maze. Use believable fluorescent lighting, worn carpet, stained wallpaper, ceiling tiles, and realistic materials; arrange varied, unsettlingly odd rooms with looping corridors, mismatched openings, and irregular connected spaces.

# Agent decision
## Genre
This is `No Genre`: it is an endless free-roam environment with no entities, objective, puzzle to solve, scoring, or rounds.

## Shape and preset
No genre shape is assigned. Set `axis-enclosure` to interior-only and `axis-structure` to must-be-valid because every reused chunk opening must connect into a continuous looping network. Keep single-surface verticality, a single stitched zone, and grounded-surface play. The preset is none because the scene rejects the focal landmarks and directed circulation of the available place presets.

## Config requirements
Use `path-circulation` for an irregular network of looping office corridors that connects every room chunk while avoiding a clear destination. Add freeform geometry for several distinct odd room chunks, mismatched openings, fluorescent ceiling grids, worn carpet, stained wallpaper, ceiling tiles, and realistic office materials. Explicitly include no entities, population, props suggesting occupants, exit landmark, or exterior view.

## Layout requirements
Nothing needs placement after segmentation. There are no hostile spawners, collectibles, checkpoints, triggers, teleports, objective markers, or scoring volumes.

## Layout components
Build several reusable office-like chunks, each containing a different irregular room arrangement and multiple compatible corridor openings. Stitch them into one large connected floor plan with loops, cross-connections, and no terminal exit, then repeat selected chunks at separated positions to imply continuation beyond the represented area. Vary room proportions, offset doorways, and create unsettling transitions while ensuring every opening meets a traversable corridor. Keep all floors level beneath a continuous low tiled ceiling. Seal the outer frame with corridor continuations that visually imply more space. Compose the top-down footprint to expose the chunk connections clearly.

## Render order
Use `topdown`: draw the authoritative plan first because disconnected openings or isolated chunks would make free roaming fail, then dress that plan as the photoreal isometric interior.

## Scale, theme, and pipeline cost
Scale is large, driven by several stitched and reused chunks. The theme is photoreal, worn, fluorescent liminal office space. Use `P6` because the looping connected structure must be valid by construction.
