## Config requirements
Use `chunk-modular` from Infinite Runner for a handful of distinct room chunks with matching doorway interfaces and `zone-graphics` for isolated photoreal detail clusters that can be streamed with each chunk. Preserve “a handful” without inventing an exact count.

## Layout requirements
Place free-text TriggerZones at every authored chunk exit so the system can select and attach a compatible next room module. Record matching entry and exit anchors for each chunk and prevent visible gaps or overlapping rooms. No NPC, hostile spawner, collectible, finish marker, or exterior transition is required.

## Layout components
The reusable set contains a handful of distinct interior chunks made from odd offices, corridors, openings, and transitional rooms. Each uses the same realistic fluorescent-ceiling, carpet, wallpaper, and tile material family while varying proportions and connections. Solid interior walls form local boundaries, but chunk exits continually reconnect into the endless free-roam layout.

## Render order
Use `topdown`: establish each chunk plan and compatible doorway interfaces first, then dress the validated modules isometrically with photoreal materials.

## Scale, theme, and pipeline cost
Use medium scale so several varied rooms can be shown while stains, ceiling grids, and doorway interfaces remain legible. The theme is extremely realistic, unsettling liminal office space. Route `P6` because endlessly reused room chunks must connect validly by construction.
