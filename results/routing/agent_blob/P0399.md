# Scene prompt

Create a 3D BMX game map as a sunny, stylized dirt-jump park. A compact obstacle-course section leads into a BMX run, with a clear route toward a finish line after the obby; arrange dirt ramps and jumps along the racing path.

# Agent decision

## Genre

Racing is dominant, with Obby & Platformer secondary. The answered brief makes a player-controlled BMX race to a finite finish the final activity, while the compact opening obby is a real movement challenge used to build speed.

## Shape and preset

Use `route-point-to-point`, one continuous progression from the obby start through the BMX run to the finish line. The preset is Obstacle Race, augmented with the explicit dirt-jump park and opening platforming section.

## Config requirements

Draw `startpoint-line` as a clear starting marker before the compact obby. Draw `path-track` through that opening section as a short ordered platform sequence, and `obstacle-jump` as its traversable speed-building obstacles. Draw `lane-corridor` as the readable dirt BMX path after the obby, with stylized dirt ramps and jumps confined to its racing corridor. Draw the visible finish gate for `trigger-finish`. Use `checkpoint-respawn` recovery geometry only as subtle safe pull-offs along the BMX route rather than adding unrelated scenery.

## Layout requirements

Place one `startpoint-line` marker at the beginning of the obby. Place `checkpoint-respawn` recovery points at the transition into the BMX run and after major dirt-jump groups; no exact total is stated, and each must restore a bike aligned forward on safe ground. Place one `trigger-finish` detection volume exactly beneath the finish gate at the terminal end.

## Layout components

The first zone is a compact, low obstacle course with a single ordered route. It feeds directly into a longer dirt-track zone rather than branching. The BMX run uses packed-earth berms, ramps, tabletop jumps, and landing slopes, all connected as a followable point-to-point corridor. Sunny grass borders the track, with simple stylized earth banks enclosing risky edges. Keep the full start-to-finish path visible as one coherent park composition, with the compact obby foregrounded and the finish readable in the distance.

## Render order

Use `topdown`: the authoritative plan is drawn first because both the obby chain and BMX route must connect legally, then the isometric render dresses the plan.

## Scale, theme, and pipeline cost

Scale is medium, combining a compact obby with a longer BMX sprint. Theme is sunny, colorful dirt-jump park. Use `P6` because Racing requires a valid continuous route and the secondary platform sequence must also be traversable by construction.
