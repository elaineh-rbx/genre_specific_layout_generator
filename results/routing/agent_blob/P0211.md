# Scene prompt
Create a compact, classic blocky 3D Roblox game map with eight claimable player plots arranged around a small central hub, spanning roughly 300–400 studs across. Simple walkable grass ground fills the shared space between plots, with no additional structures. Each plot contains an 8x8 green checkerboard planting grid made from 4x4x4 grass blocks, and a billboard positioned at the front displaying the owning player's name and avatar. The grid supports small stylized mushroom props: plain blue mushrooms, red fire-themed mushrooms, satellite-dish-shaped mushrooms, tiny shy mushrooms, and mushrooms with multiple heads.
