# Scene prompt
Create a 3D obby map built as a small, clearly playable tower with many stacked platform sections. The tower initially has a cute, cozy appearance, with a hidden secret incorporated into the structure; when discovered, the entire tower’s visual atmosphere shifts suddenly into an unsettling horror version.

# Agent decision
## Genre
The genre is Obby & Platformer, canonically `obby-platformer`; discovering the secret changes presentation but the game remains a vertical obstacle climb.

## Shape and preset
Use `course-tower` for one compact tower with many short sections stacked above one another. Tower Obby is the matching preset, extended with a concealed structural secret and a whole-map horror state.

## Config requirements
Draw a continuous physics-valid `path-track` through many compact platform sections. Use `obstacle-jump` for forgiving gaps and wrap-around platforms and `obstacle-climb` for short ladders, trusses, and stepped ascents. Draw one concealed side alcove containing the secret, reachable from a safe landing without becoming the main route. Draw the summit as `winner-zone`. The same geometry must support two appearances: initially cute and cozy, then suddenly distressed and unsettling, without changing collision or route readability.

## Layout requirements
Place one secret-discovery trigger inside the concealed alcove, against the secret prop, to switch the entire tower’s visual state at once. Place one `winner-zone` on the summit platform after the final obstacle. No other post-segmentation placements are required.

## Layout components
Build one small open-sided tower with many short stacked obstacle sections, safe intermediate landings, and a singular readable route from base to summit. Add one subtle branch from a mid-tower landing into a hidden alcove, visually integrated into the structure. In the cozy state use rounded pastel platforms, warm lamps, soft decorative trim, and inviting signs. The horror state preserves every surface but changes finishes to cracked, stained variants, extinguishes warm accents, and introduces harsh red or cold lighting. Keep the open void boundary and frame the full ascent plus hidden branch clearly.

## Render order
Use `topdown`: the valid climb and reachable secret branch must be authoritative before both visual states are dressed isometrically.

## Scale, theme, and pipeline cost
Scale is medium: a small footprint contains many stacked sections. The theme shifts from cute cozy pastels to sudden psychological horror. `P6` guarantees route validity, and `P2` handles overhanging stacked platforms.
