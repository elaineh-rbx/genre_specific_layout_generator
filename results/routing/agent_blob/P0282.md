# Scene prompt
Create a colourful cartoonish 3D map with a small number of separate player base plots arranged around a shared central area. Each player has an individual lockable base, with a distinct protected AFK zone where players can stand safely; leave clear routes between the bases for moving through the map.

# Agent decision
### Genre
The dominant genre is Simulation because the game revolves around persistent per-player bases holding collectible valuables, with players circulating between plots to acquire them.

### Shape and preset
Use `plot-isolated`: a small number of independent, equally spaced plots gives every player a separate base without overlap. The closest preset is Sandbox, retaining its isolated plots and collectible resources but dropping the upgrades bazaar because no shop or progression hub was requested.

### Config requirements
Use `path-circulation` for clear walkable routes connecting every base to the shared central area and to the other plots. Draw each base as a distinct cartoonish enclosure with a visible lockable gate or door. Give every plot a clearly marked protected AFK alcove. The shared center should remain open and neutral rather than becoming another player’s territory.

### Layout requirements
Place `collectible-nodes` as the stealable brainrots inside their owning player bases, distributed within the secured area rather than on the public routes; no exact number was supplied. Place one protected AFK volume inside the marked AFK zone of each base. Align one lock interaction marker with each visible base gate so the entire player plot can be secured without blocking public circulation.

### Layout components
Arrange a small number of same-sized player plots around one shared central zone, leaving generous separation between plot boundaries. Each plot contains an individual base enclosure, one lockable entrance, an interior holding area for brainrots, and one visually distinct AFK refuge. Radial or ring-like paths connect the shared center to all base entrances and continue between neighboring bases. Use low, readable boundaries to distinguish ownership while keeping the overall map composition open and legible from above.

### Render order
Use `isometric`: the colourful base identities and readable ownership composition lead, while the simple symmetric circulation can be derived from the dressed view.

### Scale, theme, and pipeline cost
Scale is medium, driven by several separated personal plots around a common center. The theme is colourful, cartoonish, and playfully competitive. Use `P0`; the map is one walkable surface with no required interiors, overhangs, separate maps, or procedural topology.
