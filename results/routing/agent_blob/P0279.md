# Scene prompt
Create a compact 3D asymmetrical horror game map as a reusable template: a tense but slightly chaotic, humorous environment with a central objective area, hazardous zones, and scattered interactive elements. Arrange multiple survivor routes through the space, with chokepoints and hiding or evasion areas, leading toward a locked exit at the edge of the map that opens after objectives are completed. Keep sightlines, paths, and distinct zones varied enough to support fast-paced pursuit and escape.

# Agent decision
### Genre
The dominant genre is Survival, specifically fast asymmetric pursuit in which survivors complete objectives and escape while one monster hunts them.

### Shape and preset
Use `warren-looping`: multiple interconnected routes circle through the compact map without dead ends, allowing pursuit, evasion, and alternate approaches to objectives. The preset is 1 vs All, whose asymmetric starts, cover, and escape gate all apply.

### Config requirements
Use `cover-los` for localized hiding recesses, blockers, and corners that break monster sightlines while preserving readable exits. Use `hazard-kill` for clearly bounded hazardous zones embedded away from unavoidable route junctions. Use `gate-escape` for the large locked exit structure at the map edge. Draw a central objective area and scattered interactive fixtures as scene-specific geometry, with a tense but playfully chaotic visual language.

### Layout requirements
Place `spawn-protected` starts with survivor positions separated from a screened monster origin. Place the functional half of `gate-escape` as one unlock-and-win trigger aligned to the edge exit. Place interaction markers on every visible objective fixture and interactive element, clustered around the central objective zone but distributed enough to force movement through several routes; the prompt gives no exact count.

### Layout components
Build a compact central objective zone surrounded by several distinct pursuit sectors, hazard pockets, and hiding areas. A looping route web connects all sectors, with selective chokepoints but no trapping dead ends. Scatter interactive fixtures along alternate paths and place the locked exit at one outer edge, reachable from more than one approach. Use cover to vary sightline length and keep hazards visibly distinct. Enclose the active map with a clear themed boundary and frame the central objective and edge exit as opposite compositional anchors.

### Render order
Use `topdown`: invalid loop connectivity or a one-route objective would undermine pursuit, so topology must lead before isometric dressing.

### Scale, theme, and pipeline cost
Scale is medium despite the compact footprint because it needs several distinct fast-round sectors. The theme is atmospheric horror with slightly chaotic humor and stylized hazards. Use `P6` because the no-dead-end pursuit network must be valid by construction.
