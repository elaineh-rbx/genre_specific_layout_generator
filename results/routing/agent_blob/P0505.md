# Scene prompt
Create a Roblox tower defense map set with four separate, player-selectable supernatural battle maps: a spiritual city, a forest, a castle, and a dimensional realm. Each map uses a short, compact enemy lane that largely fills the screen, running from an entry point through clear tower-placement spaces toward a defended core at the end. The spiritual city features urban spirit-world architecture, the forest is a wooded supernatural landscape, the castle uses fortified halls and courtyards, and the dimensional realm is an otherworldly environment surrounding the lane and core.

# Agent decision
## Genre
The dominant genre is Strategy, specifically tower defense; summoning and rarity progression do not change the spatial genre.

## Shape and preset
Use `world-chaptered`, outside Strategy’s usual set, because the spiritual city, forest, castle, and dimensional realm are four separate player-selectable maps. Retain the Tower Defense preset with this substituted overall shape: each map still uses its placement ground, defended core, wave origin, and continuous lane.

## Config requirements
`buildzone-grid` draws clear tower-placement pads along every compact lane. `tracker-core` draws one supernatural defended core per map, four total. `building-interior` draws the castle’s enterable fortified halls linked to its courtyards. Give the four maps distinct original treatments: urban spirit-world architecture, haunted woodland, stone castle halls and courts, and an abstract otherworldly realm. Keep permanent decoration away from lanes and deployment pads.

## Layout requirements
Place four `tracker-core` objective markers and four `spawner-npc` wave origins, one paired set in each map. Place one player arrival area per map beside its core-side deployment ground. Each short lane must be continuous from entry to core, and every tower pad must be accessible without crossing the enemy route. Unit rarity, summoning, trading, quests, rewards, and the 34-unit roster are mechanics rather than layout placements.

## Layout components
Build four compact bounded battlefields. The spiritual city lane winds between stylized urban buildings; the forest lane crosses supernatural woods; the castle lane passes between courtyards and fortified halls; the dimensional lane runs through a strange open realm around its core. Each map contains one entry, one short route, flanking deployment pads, and one terminal core. Use sparse thematic props and elevated framing so each lane largely fills its screen.

## Render order
Use `topdown`: all four enemy lanes must be valid and readable before their respective isometric dressing passes.

## Scale, theme, and pipeline cost
Scale is large overall because there are exactly four maps, though each is compact. The theme is original supernatural sword-and-spirit fantasy. Use `P4` for separate maps, `P6` for valid lanes, and `P3` for the castle’s hall-to-courtyard transitions.
