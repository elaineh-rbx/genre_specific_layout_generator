# Scene prompt
Create a 3D third-person anime-inspired combat map set across a few dense Tokyo city blocks. Use high-quality brick, concrete, and glass building facades rather than basic block geometry, with streets and sidewalks forming the main fighting routes between closely packed mid-rise buildings. Include a small number of key buildings with real enterable doors and simple interiors; keep the remaining buildings as exterior set dressing. Place a yellow noob training dummy NPC in a clear street-level combat space.
