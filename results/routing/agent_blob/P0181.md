# Scene prompt
Create a 3D escape-room map set in a single grimy basement room. Place a prominent bomb with a four-digit keypad in the room, alongside a basketball hidden among the basement clutter, a visible rock-paper-scissors station with an NPC opponent, and a four-digit code placed somewhere for players to discover by looking around the room.

# Agent decision
## Genre
The genre is Puzzle: three room-scale challenges culminate in entering a code to defuse the bomb.

## Shape and preset
Use `interior-single`, keeping the complete challenge inside one basement. Use the Escape Room preset with its room sequence replaced by this single room and its exit gate omitted because the final objective is the bomb.

## Config requirements
Draw `button-solve` as the bomb’s four-digit keypad. Use `facade-clue` for the discoverable four-digit code, positioned on a surface naturally visible during a thorough search but not from spawn. Draw one basketball concealment spot amid clutter. Use `npc-population` for one visible rock-paper-scissors opponent and its station. The bomb remains the central hazard and visual anchor.

## Layout requirements
Place one `collectible-nodes` basketball in the chosen clutter concealment spot. Place the functional half of `button-solve` on the bomb keypad, reachable after the other challenges. Place one `npc-population` marker at the rock-paper-scissors station, away from the hidden basketball and code so the three puzzles occupy distinct search areas.

## Layout components
Build one enclosed grimy basement room with stained concrete walls, a level floor, exposed pipes, dim utility lights, shelves, boxes, and discarded furniture. Organize exactly three readable puzzle areas: a prominent bomb and four-digit keypad, an NPC rock-paper-scissors table, and a cluttered search area hiding one basketball. Put the four-digit code elsewhere on a wall, object face, or shelf backdrop that rewards looking around. Preserve open circulation between all stations and keep the bomb visible from most of the room. Hard walls form the boundary; frame the scene from an elevated corner to show all three activity areas without exposing the hidden answers too plainly.

## Render order
Use `isometric`: the room has simple topology, while atmosphere, visual search, and separation of the three puzzle stations should lead.

## Scale, theme, and pipeline cost
The scale is small, driven by one room and three puzzles. The theme is tense, grimy industrial basement. Use `P0`; all geometry fits one unobstructed floor plan.
