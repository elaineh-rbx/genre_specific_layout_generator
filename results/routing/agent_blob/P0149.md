# Scene prompt

Create a 3D backrooms horror map: a small, plainly playable interior maze of empty, unsettling rooms and corridors that loops back on itself after a few minutes of exploration. The space has no exit route and no visible inhabitants.

# Agent decision

## Genre

The genre is Survival because the stated game loop is to endure and keep exploring for as long as possible, even though the horror comes entirely from the empty space rather than a pursuing actor.

## Shape and preset

Use `interior-endless`: the whole map is an enclosed, apparently unbounded network of repeating rooms and corridors with no exit. The Liminal Horror preset supplies that exact shape, but drop its hostile spawner, pickups, and hiding-cover bundle because the prompt explicitly requires no inhabitants and describes no collectible objective.

## Config requirements

No canonical image option is required. Draw only the small maze of empty, unsettling rooms and corridors, using repeating modular architecture and subtle variations to create the impression of an endless interior. Keep the environment plainly traversable and omit enemies, visible inhabitants, exit signage, resource props, lockers, crawlspaces, and objective landmarks.

## Layout requirements

Nothing must be placed after segmentation beyond one ordinary player arrival marker in an unremarkable room. There are no `spawner-npc`, `collectible-nodes`, checkpoints, escape gates, or objective triggers. Site the arrival away from any obvious visual endpoint and ensure at least two corridor choices are visible from it.

## Layout components

Build one compact, bounded implementation of an apparently endless single-floor interior. Connect empty rooms of varied rectangular proportions with low, repetitive corridors, offset doorways, and several loop junctions. The path network must return to earlier-looking spaces after roughly a few minutes of walking, while procedural repetition conceals the physical boundary. Use walls as the hard enclosure and provide neither an exterior nor an exit room. Compose the plan as a dense irregular loop network with the arrival room off-center and repeated room modules distributed around its outer circulation.

## Render order

Use `authored_plan`: code generates the maze blueprint first and keeps it authoritative, ensuring every procedural section connects and the exploration path loops without an accidental sealed region.

## Scale, theme, and pipeline cost

Scale is small, based on a few minutes before repetition rather than a sprawling unique floor. The theme is empty liminal horror with anonymous finishes, repetitive geometry, and unsettling uniform light. Use `P6` because the endless maze’s connected looping structure must be valid by construction; no interior transition is needed because the entire map is inside.
