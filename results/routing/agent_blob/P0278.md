# Scene prompt
Create a 3D solo exploration horror map set in an open outdoor field with a few scattered buildings.

# Agent decision
### Genre
The dominant genre is Adventure because the player’s stated activity is solo exploration. Horror is the visual theme, not a second layout genre, and the brief explicitly rejects an asymmetric killer-survivor mode.

### Shape and preset
Use `world-open` for one contiguous outdoor field that can be explored in any order. The closest preset is Exploration, retaining its open-world shape and directional landmarks but dropping hidden alcoves and a defined trail because neither was requested.

### Config requirements
Use `landmark-focal` for the few scattered buildings, spaced as visible points of interest that pull exploration across the field. Their silhouettes and surrounding ground should be distinct enough to orient the player. Do not add `building-interior`, because the prompt does not say the buildings are enterable.

### Layout requirements
Nothing invisible needs placement: the brief specifies no collectibles, quest tracker, checkpoint, teleporter, spawn network, gate, or trigger volume.

### Layout components
Create one open outdoor field as the main zone, with a few buildings scattered apart rather than grouped into a settlement. Leave traversable field ground between them so the player can approach each structure from multiple directions. Vary local emptiness and building silhouette to keep the sparse map legible without inventing extra landmarks. The boundary should be naturally obscured in darkness rather than expressed as an intrusive wall. Compose the frame so the field dominates and several separated buildings remain readable as exploration anchors.

### Render order
Use `isometric`: the horror atmosphere, silhouettes, and spacing of the field and buildings lead, and no topology requires a generated plan first.

### Scale, theme, and pipeline cost
Scale is medium because the brief asks for an open field with only a few structures but gives no enormous dimensions. The theme is lonely outdoor horror with dark, sparse visual storytelling. Use `P0`; a single top-down surface captures the full walkable layout, with no stated interiors, overhangs, separate maps, or structural-validity constraint.
