## Enriched image prompt
Build a short, playable 3D obby across one giant realistic desktop keyboard scaled to fill a room-sized platform. Cover the floor with recognizable raised keyboard keys and arrange a compact forward jump route that requires the player to leap from key to key to escape. Preserve the proportions and material feel of a real desk keyboard while enlarging keycaps, gaps, and the keyboard frame for avatar-scale traversal. End the route at a clear escape landing beyond the final keys.

## Genre
The dominant genre is Obby & Platformer because the author explicitly resolves the game as an obby based on jumping between keys.

## Shape and preset
Use `course-flat`, Path (Flat Course): the route progresses horizontally over the keyboard deck. Match the Classic Obby preset, retaining its sequential jump track but omitting moving obstacles and checkpoints because the author asked for a short, compact course.

## Config requirements
Use `path-track` for the ordered key-to-key route and `obstacle-jump` for the gaps between enlarged keycaps. Use `winner-zone` in both streams for the visible escape landing beyond the final key. The realistic keyboard case and a floor densely filled with recognizable keys are required scene-specific visible geometry.

## Layout requirements
Place one `winner-zone` WinnerZone over the escape landing at the far end of the keyboard route. No `checkpoint-respawn` is needed for this deliberately short course.

## Layout components
One room-sized keyboard platform contains a realistic outer frame, a floor packed with enlarged keycaps, a readable start at one edge, a compact sequential path across selected keys, jump gaps, and one clear escape landing at the opposite end. The whole keyboard remains visible as the composition's subject.

## Render order
Use `topdown`: the key sequence and jump spacing must form a complete playable route before the realistic keyboard is dressed.

## Scale, theme, and pipeline cost
Use small scale because the author chose a room-sized compact deck and individual key gaps are the critical detail. The theme is a realistic desktop keyboard enlarged to giant avatar scale. `P6` is required because every jump in the obby path must be valid by construction.
