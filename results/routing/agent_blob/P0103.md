# Scene prompt
Create a 3D obby escape map built on a realistic, giant desktop keyboard that fills a room-sized platform. The floor is densely covered with oversized keys arranged in a compact keyboard layout, forming the jumping route across the deck.

# Agent decision
## Genre
The genre is Obby & Platformer, as the author explicitly says the player escapes by jumping between keys. There is no secondary genre.

## Shape and preset
Use `course-flat`: the route progresses horizontally across one room-sized keyboard deck. Start from the Classic Obby preset, retaining its sequential track, safe checkpoints, and jump obstacles, but drop moving obstacles because the brief describes fixed keyboard keys rather than moving machinery.

## Config requirements
Draw `path-track` as an ordered crossing over selected oversized keys, with physics-legal gaps and an unmistakable start-to-exit direction. Use `checkpoint-respawn` as a few keys visually distinguished as broad safe landings. Use `obstacle-jump` for jumps between rows, over missing-key gaps, and around raised key clusters. Add `winner-zone` as the escape landing beyond the keyboard’s far edge.

## Layout requirements
Place the functional `checkpoint-respawn` markers on the start key and at a small number of broad intermediate safe keys, spaced so failure does not reset the entire short course. Place one `winner-zone` trigger on the terminal escape landing. Validate every required key-to-key jump against the avatar movement limits and keep decorative dense keys from creating ambiguous alternate critical routes.

## Layout components
The sole main zone is a compact, room-sized realistic desktop keyboard mounted on a rectangular deck. Fill it densely with oversized keycaps in recognizable staggered rows, including the function row, alphanumeric field, modifiers, spacebar, arrows, and number pad. The traversable path begins near one deck edge, crosses chosen key rows through a deliberate sequence of gaps and height changes, and ends on a clear escape pad at the opposite edge. Use the keyboard casing as the boundary, with a surrounding room floor below as failure space. Compose the view from a raised diagonal angle that preserves the recognizable keyboard silhouette and makes the highlighted route readable.

## Render order
Use `topdown`: the valid key-to-key jump chain must be planned first, then converted into the authoritative realistic isometric keyboard scene.

## Scale, theme, and pipeline cost
Scale is small, set by one room-sized platform and a short playable crossing. The theme is a realistic giant desktop keyboard with restrained office materials. Route through `P6` because the obby’s jump sequence must be valid by construction.
