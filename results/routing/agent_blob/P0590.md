# Scene prompt
Create a 3D layout with a very long river running the full length of the map, centred on the existing build and positioned directly in front of the player. Surround the river with a simple forest setting along both banks.

# Agent decision

## Genre
The answer is No Genre: the request adds a landscape feature and setting but names no game activity.

## Shape and preset
No genre shape applies. Keep the routing axes at their defaults: exterior, single-surface, one zone, dressed structure, and grounded play. Use the Explorable Place preset, reduced to a river-centered scenic environment; there is no requested landmark structure.

## Config requirements
Apply `water-body` as one very long river extending continuously from one end of the map to the other. Use `terrain-relief` only for low natural banks, with no cliffs, caves, or overhangs. Draw `path-circulation` as narrow walkable bank clearances running beside the water. Compose `vignette-photo` so the river is centered directly in front of the player and its length dominates the view. Add simple forest vegetation along both banks without blocking the river corridor.

## Layout requirements
Place one uncatalogued arrival marker on the near bank at the centerline of the existing build, facing straight along or across the river so the requested feature is immediately in front. No collectibles, triggers, hazards, or objectives are requested.

## Layout components
Build a single river channel spanning the map’s complete long axis, centered on the existing build. Give it two continuous, gently shaped banks and reserve slim walkable strips beside them. Place simple forest trees in irregular bands beyond both banks, denser toward the outer map edges while keeping a clear view down the water. Close the distant ends through perspective and forest screening rather than abrupt walls. The outer tree line forms the lateral boundary. Frame the scene from the player’s current side with the river centered and visibly receding through the full map.

## Render order
Use `isometric`: render the long forest-river composition first, then derive the uncomplicated top-down arrangement.

## Scale, theme, and pipeline cost
Scale is large because the river runs the whole map length. The theme is a simple natural forest river. Use `CHECK` because the flowing water is a real play-space feature; the open, unlayered channel should not self-occlude.
