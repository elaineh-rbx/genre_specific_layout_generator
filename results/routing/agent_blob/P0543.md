# Scene prompt
Create a 3D game map with a cartoony hedge maze containing 10 hidden brainrot collectibles placed throughout its winding corridors. Position a player base directly outside the maze entrance, with a clear path between the base and the hedge-lined maze gateway.

# Agent decision

## Genre
The dominant genre is Adventure because finding ten targets and returning them to base is a scavenger hunt. Puzzle is secondary because the traversable hedge maze supplies the spatial challenge.

## Shape and preset
Use `puzzle-maze`, a solvable labyrinth with one entrance connected to an external base. The preset is Maze / Labyrinth from the secondary Puzzle genre, retaining its looping corridors and collectible placement while bending them to a scavenger-hunt objective.

## Config requirements
Use `path-loop` for winding hedge corridors that reconnect rather than producing long punitive dead ends. Draw a clearly identifiable hedge gateway, an open staging area outside it, and a compact player base directly opposite the entrance. The ten brainrots themselves are not image config because they must be placed against the generated maze topology.

## Layout requirements
Use `collectible-nodes` for exactly 10 hidden brainrot pickup positions distributed throughout distinct maze branches, not clustered near the entrance. Each must have enough corridor clearance to see and collect it. Place one delivery trigger at the player base outside the gateway and one player spawn inside that base. The collectible positions remain valid respawn locations after delivery.

## Layout components
Build one cartoony hedge maze with a single readable gateway, looping winding corridors, and a guaranteed traversable route through its full footprint. Put the player base immediately outside the entrance, separated by one short clear path and open forecourt. Hedge walls form the maze boundary; the base side remains open and visually safe. Compose the plan so the base, gateway, and broad maze footprint are all legible while hiding the ten collectible locations within corridor turns.

## Render order
Use `authored_plan`: a maze must be procedurally guaranteed solvable before the top-down and isometric images dress it with cartoon hedges.

## Scale, theme, and pipeline cost
Scale is medium, driven by ten distributed hiding positions. The theme is playful cartoony hedge labyrinth with a simple collection base. Route `P6` because maze connectivity and reachability must be valid by construction.
