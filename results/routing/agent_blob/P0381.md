# Scene prompt

Create a 3D alpine forest mountain map with a single winding paved path descending from a high starting point to the bottom over a roughly thirty-second run. The narrow road snakes through rocky slopes and trees, with repeated left and right bends and exposed edges where the terrain drops away; place the tyre at the top of the descent.

# Agent decision

## Genre

The dominant and sole genre is Racing. This is a timed, finite downhill run whose controlled racer is a rolling tyre.

## Shape and preset

Use `route-point-to-point` for one directed descent from the summit to the mountain base. Match the Downhill Descent preset, retaining off-road danger and pacing markers but dropping course recovery checkpoints because leaving the path explicitly restarts the run from the top.

## Config requirements

Use `hazard-kill` for the exposed road edges and steep drop-away terrain that ends an off-course attempt. Use `marker-distance` as subtle roadside increments that communicate progress down the short descent. Draw `startpoint-line` at the summit and `trigger-finish` as a visible finish marker at the bottom. Use `terrain-relief` for the rocky alpine mountain, slopes, and elevation loss, with conifers flanking the route without blocking it.

## Layout requirements

Place one `startpoint-line` marker and the single tyre at the summit, centered and oriented down the first straight. Place one `trigger-finish` detection region across the road at the mountain base. The sole restart position is the summit start, not an intermediate `checkpoint-respawn`, so every fall resets the full run.

## Layout components

Build one compact mountain zone with a narrow paved road descending continuously for a roughly thirty-second run. Sequence repeated left and right bends through rocky slopes and alpine trees, preserving clear sightlines into each turn. Expose selected outer edges to steep terrain drops while keeping the road itself continuous. The high summit start and low finish are the two terminal zones, connected only by the winding road. Frame the full descending route legibly from above.

## Render order

Use `topdown`: establish the continuous summit-to-base road plan first, then dress it isometrically. The plan is authoritative because a broken or ambiguous descent would make the timed run unplayable.

## Scale, theme, and pipeline cost

The scale band is small, driven by the requested thirty-second replayable run. The theme is realistic alpine forest and rocky paved mountain road. Use `P6` for a valid continuous racing route and `tiered` for strong elevation without overhangs.
