# Scene prompt
Create a small modern indoor escape-room map consisting of one clean room. A large, clearly visible keyboard occupies the main area of the room, with a locked exit door set into one wall opposite it.

# Agent decision
## Genre
The genre is Puzzle because players press the correct keyboard sequence to unlock an escape exit.

## Shape and preset
Use `interior-single` for one enclosed room that is the entire map, rather than a sequence of chambers. The preset is Word / Quiz Puzzle, with its open shape replaced by this indoor room and its clue facade omitted because none was requested.

## Config requirements
Use `button-solve` for the large physical keyboard and its individually pressable raised keys. Use `gate-solve` for the locked exit door that blocks completion until the correct sequence is entered. The room should be clean, modern, uncluttered, and visually focused on those two fixtures.

## Layout requirements
Place `button-solve` interaction points across every usable key surface on the large keyboard, preserving clear spacing between adjacent keys. Place one unlock state and one completion trigger at the exit door opposite the keyboard. The player start belongs near the wall facing the keyboard, with an unobstructed route to both the keys and the door.

## Layout components
Build one small rectangular modern room with a flat floor and plain enclosing walls. Put the oversized keyboard in the main floor area as the dominant object, leaving avatar-width circulation around it. Set one locked exit door into the opposite wall, centered or otherwise aligned so the relationship between keyboard and exit reads immediately. Keep the remaining floor open and omit unrelated furniture, additional rooms, props, or horror dressing. Frame the room so the keyboard and locked door are both clearly visible.

## Render order
Render `isometric` first and treat it as authoritative, then derive the top-down view, because the simple one-room topology is not at risk and the visual relationship between keyboard and exit leads.

## Scale, theme, and pipeline cost
Scale is small, driven by one room and one puzzle fixture. The theme is a clean modern indoor escape room. Use `P0`; the entire activity stays on one enclosed surface with no exterior transition, stacking, or procedural topology requirement.
