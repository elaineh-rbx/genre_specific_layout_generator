# Scene prompt
Create a 3D backrooms-style map: one large fixed indoor maze designed to feel endless, with repeating connected rooms, corridors, and dead ends that create a small but playable exploration floor. Include spaces where hostile entities can appear or roam; there is no exit.

# Agent decision
## Genre
The dominant genre is Survival because the goal is to avoid hostile entities for as long as possible, with no exit or puzzle completion.

## Shape and preset
Use `interior-endless` for one fixed interior floor whose repeating corridors, rooms, and dead ends create the illusion that it continues without a boundary. The preset is Liminal Horror. Retain its hiding geometry and hostile origins, but drop `collectible-nodes` because no resources or items were requested.

## Config requirements
Draw `cover-los` as shallow wall recesses, offset room openings, low partitions, and occasional alcoves where a player can break an entity’s sightline. Repeat near-identical room proportions, corridor turns, ceiling panels, wall coverings, and fluorescent fixtures to make the finite floor feel endless. Include deliberate dead ends and subtle variations in stains, missing panels, and furniture remnants, but no visible exit gate or exterior opening.

## Layout requirements
Place several `spawner-npc` origins for hostile entities in separated rooms and corridors, out of direct view from the player start and distributed so entities can appear or roam across the whole floor. Place one player start in a comparatively open room with multiple onward routes. No exit trigger, winner zone, key pickup, collectible node, or checkpoint is needed because survival duration is the only objective.

## Layout components
Build one enclosed floor of repeating connected rooms, long and short corridors, branching junctions, and true dead ends. Use repeated modules to imply far greater extent than the compact fixed layout actually has. Entity-roaming routes should cross the central network, while side recesses and offset doorways provide temporary sightline breaks. The continuous interior shell is the hard boundary, concealed through repetition rather than presented as an outer wall. Compose the view around monotonous vanishing corridors and near-identical rooms, with no landmark that reads as an exit.

## Render order
Render `topdown` first and make it authoritative, then dress the isometric image from that plan; the connected roaming network must be traversable even though the space intentionally includes dead ends.

## Scale, theme, and pipeline cost
Use a small scale for the first playable build, made to feel large through repetition. The theme is oppressive fluorescent backrooms liminal horror. Route with `P6` because the endless-interior structure must be valid by construction.
