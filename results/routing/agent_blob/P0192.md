# Scene prompt

Create an open 3D terrain island for exploration, with hidden treasure chests distributed across the landscape. Each chest is a unique, ornate custom-modeled 3D treasure chest placed in a distinct discoverable location.

# Agent decision

## Genre

The genre is Adventure because the player explores an island to discover hidden collectible targets.

## Shape and preset

Use `world-open` from the Scavenger Hunt preset: one contiguous island explored freely for treasure. Keep collectible objectives and discovery alcoves, while the compass and count remain UI rather than a physical tracker board.

## Config requirements

Build `path-trail` as a loose network of walkable terrain routes connecting the island’s major areas while leaving room for off-path searching. Add `alcove-secret` as secluded pockets behind rocks, vegetation, small ruins, and shoreline formations. Draw a plural set of unique ornate custom-modeled treasure chests, each with a distinct silhouette, decoration, and environmental setting; no exact chest count was supplied. Use `water-body` as the surrounding sea that establishes the island boundary.

## Layout requirements

Place one `collectible-nodes` interaction marker on every ornate treasure chest. Distribute the chest markers across distinct, reachable locations, mixing visible landmark-adjacent finds with concealed alcove finds and avoiding clusters that make several discoveries feel identical. No physical compass or counter object is needed because those are interface functions.

## Layout components

Build one self-contained terrain island with a central rise, lower wooded ground, rocky outcrops, a beach edge, and a few weathered ruin fragments to create distinct search regions. Thread paths between these regions and branch short side routes toward secluded chest settings. Place every chest on stable reachable ground with enough clearance to approach and interact, using foliage, boulders, ruins, elevation, and shoreline curves to hide them without making them inaccessible. Surround the island with open sea and use the shoreline as the natural boundary. Frame the island isometrically so the main terrain regions read clearly while individual treasure placements still reward closer exploration.

## Render order

Use `isometric`: establish the varied terrain, ornamental chest designs, and discovery atmosphere first, then derive the top-down plan from that authoritative image.

## Scale, theme, and pipeline cost

The scale is medium, a reasonable default for a focused explorable island with multiple distinct hiding areas. The theme is stylized natural-island treasure adventure with weathered ruins. Use `CHECK` for the surrounding sea; the traversable land itself remains one continuous surface.
