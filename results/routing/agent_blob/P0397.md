# Scene prompt

Create a 3D obby map as a ten-level vertical tower, with stacked platforming sections that rise upward and become progressively more difficult on each higher level. Use one consistent simple cartoon obby look throughout, and place treadmill platforms along the course.

# Agent decision

## Genre

Simulation is dominant, with Obby & Platformer secondary. The original “1+ speed” loop makes increasing the speed stat the main progression, while the ten-stage obstacle course contributes genuine player-controlled platforming.

## Shape and preset

Use `course-tower`, a vertically stacked ascent of ten distinct platforming levels. This shape comes from outside Simulation’s usual set because the answered brief explicitly requires a tower. The preset is Stat Grinder with its shape replaced by `course-tower`; retain the training-station concept, but omit the preset’s unrequested shop, rebirth pad, and purchase gates.

## Config requirements

Draw `station-training` as treadmill platforms embedded along the climb, visibly usable as speed-training stations. Draw `path-track` as the ordered chain of platforms through all ten levels, and `obstacle-moving` as treadmill conveyors that also affect traversal. The style stays consistently simple, colorful, and cartoon-like.

## Layout requirements

Place the functional half of `station-training` on each treadmill platform; the brief does not fix a treadmill count, so distribute them regularly without inventing one. Place `checkpoint-respawn` as one safe pad at the start of each of the ten levels, for ten checkpoints total. Place `winner-zone` once at the summit after level ten.

## Layout components

Build ten vertically stacked levels around a central tower axis, each with a safe level-entry platform and a progressively harder sequence of jumps. Ramps, wraps, and short connecting platforms carry players upward between levels; treadmill platforms appear along the critical route. Keep all required gaps physics-legal. The tower rises from a compact start base, is bounded by open void around the course, and should read in frame as one clear bottom-to-top ascent.

## Render order

Use `topdown`: the authoritative plan is drawn first because the ten-level critical path and every jump connection must remain valid, then the isometric view dresses that plan.

## Scale, theme, and pipeline cost

Scale is medium, driven by ten stacked stages rather than a broad footprint. Theme is a clean, consistent cartoon obby. Use `P6` because the platform chain must be valid by construction, plus `P2` because tower levels overhang one another.
