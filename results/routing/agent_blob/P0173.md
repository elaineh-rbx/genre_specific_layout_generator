# Scene prompt
Create a 3D first-person maze escape map as a compact stone dungeon. A network of solid stone-walled corridors and stone floors forms a maze sized for a clean route of about 60 seconds, with a clearly distinct 3D exit door at the maze’s far end.

# Agent decision
## Genre
The genre is Puzzle because the player navigates a physical labyrinth to find its exit before time expires.

## Shape and preset
Use `puzzle-maze` for a procedurally solvable corridor network. The preset is Maze / Labyrinth, retaining `path-loop` but omitting collectible items because the key was optional and the final scene does not require one.

## Config requirements
Use `path-loop` for stone corridors that reconnect and reduce excessive backtracking. Draw solid dungeon-stone walls and floors, a distinct start area, and one clearly recognizable 3D exit door at the far end. Do not add puzzle buttons, clue facades, item sockets, or a required key.

## Layout requirements
Place one player start marker in the maze’s starting region and one completion trigger immediately inside the sole exit door. Ensure all corridor widths support first-person avatar movement and that the intended clean route takes about 60 seconds. The 90-second countdown and restart are mechanics and add no geometry.

## Layout components
Build one compact enclosed stone-dungeon maze on a single level. Use a network of solid-walled corridors with several junctions, useful loops, and misleading branches, all bounded by continuous outer stone walls. Separate start and exit across the footprint, keep the exit out of direct initial sight, and provide exactly one valid exit opening. The floor remains continuous and flat, without stacked crossings. Compose the top-down footprint for clear validation while the dressed view emphasizes close first-person stone corridors.

## Render order
Render `authored_plan` first and treat the computed blueprint as authoritative, then generate top-down and isometric views from it. The maze must be provably connected and the exit reachable.

## Scale, theme, and pipeline cost
Scale is small, calibrated to a roughly 60-second clean run within a 90-second limit. The theme is a simple solid-stone dungeon. Use `P6` because maze topology must be valid by construction; no exterior transition, separate map, or stacked-surface pass applies.
