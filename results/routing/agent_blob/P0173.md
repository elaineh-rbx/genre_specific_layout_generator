# Agent decision

## Clarifications resolved
- [author] theme — Q: What should the maze be made of - hedges, stone dungeon, sterile lab corridors? A: Use a simple stone dungeon maze: solid stone walls and floor, with a clearly distinct 3D exit door.
- [author] scale — Q: How long should a clean run take - the timer length implies the maze size. A: Keep it small enough that a clean run takes about 60 seconds; set the countdown to 90 seconds so it is plainly playable.
- [agent_inferred] optional key — Q: Should the optional exit key be required? A: Omit the key in the initial build; the prompt marks it optional and the maze itself is the required challenge.

## Enriched image prompt
Create a small, fully 3D first-person stone dungeon maze with solid stone floor, high solid stone corridor walls, one clear starting point, and one clearly distinct 3D exit door. Size the solvable route for about a 60-second clean run, with connected corridors and loop-backs but no view over the walls. Keep the exit reachable without a key and exclude HUD or restart-screen elements from the scene.

## Genre
The dominant genre is Puzzle.

## Shape and preset
Use `puzzle-maze`, because the solvable corridor topology is the puzzle itself. The matched preset is Maze / Labyrinth, retaining its loop-back corridors and dropping its optional `collectible-nodes` because no key is required.

## Config requirements
`path-loop` draws stone corridors that reconnect and reduce excessive backtracking while preserving false choices. Reach outside Puzzle's shortlist to Survival's `gate-escape`, drawing the single visually distinct 3D exit door in the outer stone wall. The solid stone floor and high walls remain direct scene geometry. No key, clue facade, button, or receptacle geometry is included.

## Layout requirements
Place one free-text SpawnZone at the maze entrance and one `gate-escape` trigger against the distinct door at the reachable maze end. No `collectible-nodes` or solve-input placements are required. The 90-second timer and restart behavior are non-spatial and add no layout placement.

## Layout components
The map is one enclosed stone maze with a single floor, high walls, connected corridors, loop-backs, one entrance, and one exit door. Its critical solution path should take about 60 seconds at normal movement speed. The outer wall seals the boundary, and the full authored maze plan should fill the frame with entrance and exit distinguishable.

## Render order
Use `authored_plan`: `puzzle-maze` is supported by the procedural maze generator, and a computed solvable route must be authoritative before top-down and isometric dungeon renders are dressed from it.

## Scale, theme, and pipeline cost
The scale band is small, driven by the roughly 60-second clean route and 90-second countdown. The theme is a simple stone dungeon. `P6` is required because the maze and exit must be valid by construction; no other modifier is forced.
