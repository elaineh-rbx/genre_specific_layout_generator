# Scene prompt

Create a bright, tropical pirate-adventure map split into three separate ocean regions reached by teleportation. Sea 1 contains 20 small colorful islands, Sea 2 contains 10, and Sea 3 contains 30; each island is compact, roughly a beach that can be crossed in ten seconds, surrounded by open water. Arrange distinct island clusters across each sea with clear shorelines and ocean travel space between them.

# Agent decision

## Genre

The dominant genre is RPG, with Adventure secondary. Fruit powers, levels, money, trading, and player bounties define a progression RPG, while sailing among many islands supplies the exploration layer.

## Shape and preset

Use `world-chaptered` for three genuinely separate sea maps reached by teleportation, with each sea internally open for flexible island visits. Preset is none because the exact three-sea, 60-island structure does not retain a recognizable generic RPG or Adventure bundle.

## Config requirements

Apply `island-cluster` separately to all three seas: Sea 1 has 20 compact colorful islands, Sea 2 has 10, and Sea 3 has 30. Apply `water-body` to the open navigable ocean surrounding and separating every island. Draw the visible forms of `teleporter-link` as standardized pirate-fantasy travel markers connecting the three regions.

## Layout requirements

Place the functional endpoints of `teleporter-link` at safe, obvious shoreline arrival areas in each of the three sea maps. Use one paired travel network linking Sea 1, Sea 2, and Sea 3, with destinations clear of water and enough landing room around each marker. No fruit, economy, or bounty mechanics become layout geometry.

## Layout components

Build three separate ocean regions. Sea 1 contains exactly 20 small islands, Sea 2 exactly 10, and Sea 3 exactly 30, for 60 islands total. Each island is roughly a beach crossed in ten seconds, with a distinct clear shoreline and colorful tropical dressing. Arrange islands into readable clusters while preserving open sailing channels between them. Open ocean defines each map boundary. Frame each sea from high above so every island count, cluster, shoreline, and travel corridor remains legible.

## Render order

Render `topdown` first and treat it as authoritative, because the exact per-sea island counts and navigable spacing must be preserved before dressing.

## Scale, theme, and pipeline cost

Scale is huge because three maps contain 60 islands despite each island being small. The theme is bright, colorful tropical pirate adventure. Use `P4` for three separate sea maps and `CHECK` for open-water travel between island landmasses.
