# Scene prompt
Create a 3D horror survival map set inside a sprawling mansion that players can get lost in, with many connected rooms, long hallways, and search areas. Scatter five physical keys throughout separate parts of the house, with small paper clues placed in rooms or corridors indicating their locations. Place a single locked escape door at the mansion’s exit, opening from the interior to end the route.

# Agent decision
## Genre
The dominant genre is Survival: a pursuing monster pressures players while they search an enclosed mansion and escape.

## Shape and preset
Use `warren-looping` for an interconnected mansion circulation pattern with zero dead ends, allowing both searching and fair monster evasion. The preset is Escape. Keep its looping shape, hiding geometry, and exit, but drop `building-interior`: the mansion is the whole interior-only map, so there is no outside-to-inside transition to build.

## Config requirements
Draw `cover-los` as wardrobe recesses, under-stair cutouts, alcoves, and furniture-screened corners that interrupt long monster sightlines while preserving traversable loops. Draw the visible half of `gate-escape` as one imposing locked door at the mansion exit. Add small paper clue props on desks, side tables, and corridor consoles; their markings should visibly read as clues without requiring legible generated text.

## Layout requirements
Place one `spawner-npc` origin for the scary monster in a deep interior room, away from the player start and escape door, with access to the looped hall network. Place exactly five key pickups, each in a different, well-separated search area. Place paper-clue interaction markers in rooms or corridors, associated with the key locations they indicate. Place the functional half of `gate-escape` as one win trigger on the interior side of the locked exit door.

## Layout components
Build a sprawling mansion of many connected rooms, long hallways, stair halls, and distinct search areas. Arrange major corridors as interlocking loops with cross-connections and no dead-end traps. Distribute the five keys across separate wings and floors, with clues along reachable search routes. Use walls, doors, stairs, furniture, and hiding recesses as the primary geometry. The enclosing mansion shell is the boundary, and the composition should make the entrance-side escape door readable while deeper wings recede into darkness.

## Render order
Render `topdown` first and make it authoritative, then dress the isometric view from that plan; invalid loop connectivity would make the chase unfair and the mansion unplayable.

## Scale, theme, and pipeline cost
Use a large scale because the mansion must support many rooms and meaningful searching. The theme is dark, ornate mansion horror. Route with `P6` because the zero-dead-end warren must be valid by construction; no `P3` is needed because play never crosses an exterior boundary.
