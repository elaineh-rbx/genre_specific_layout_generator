# Scene prompt
Build a 3D underground maze of carved stone tunnels, with looping routes, dead ends, and a single exit placed as the clear destination.

# Agent decision
## Genre
The genre is Puzzle because navigating a solvable maze to its sole exit is the complete activity.

## Shape and preset
Use `puzzle-maze`, whose procedurally valid tunnel topology is the puzzle itself. The preset is Maze / Labyrinth, with its usual collectible items omitted because the prompt asks only for navigation.

## Config requirements
Use `path-loop` for corridors that reconnect into recognizable looping routes, while also adding deliberate carved-stone dead-end branches as scene-specific geometry. The single exit should be visibly distinct at the far destination, but no clue walls, buttons, item sockets, or collectible props are requested.

## Layout requirements
Place one exit objective trigger across the sole valid exit opening, beyond the final traversable corridor. Place the player start at the opposite navigational region of the maze so the exit is not immediately reachable or visible. Nothing else needs post-segmentation placement.

## Layout components
Build one enclosed underground network of carved stone tunnels. Include several loops that offer alternate approaches, multiple convincing dead ends, junction chambers that help orientation, one starting pocket, and exactly one exit chamber or opening. Every corridor must be wide and high enough for avatar traversal, with continuous stone floors and no stacked crossings or overhang-dependent route layers. Seal the outer boundary in rock so there are no accidental exits. Compose the top-down footprint as a dense but readable maze with start and exit separated across it.

## Render order
Render `authored_plan` first and treat the generated blueprint as authoritative, then produce top-down and isometric images from it. A computed plan is required because the maze must be connected and solvable while preserving loops, dead ends, and exactly one exit.

## Scale, theme, and pipeline cost
Scale is medium, allowing meaningful wrong turns without an oversized run. The theme is a classic subterranean carved-stone labyrinth. Use `P6` because maze topology must be valid by construction; no exterior transition, separate-map, or stacked-surface pass is needed.
