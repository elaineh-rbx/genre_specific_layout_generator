# Scene prompt
Create a 3D keyboard-themed escape map built as a flat keyboard layout crossed key to key. Form a compact vertical slice of about twelve distinct key-rooms/stages, with themed spaces arranged across selected keys and vertical obstacle structures rising around them. Connect the progression through puzzle doors, collectible key routes, checkpoints, hidden shortcuts, and secret side areas; include physical speed-boost lanes and jump pads where appropriate. End the route at a clearly marked exit key.

# Agent decision
## Genre
The dominant genre is Obby & Platformer, with Puzzle secondary because solved doors gate the obstacle progression.

## Shape and preset
Use `course-flat`, following the keyboard horizontally from key to key. Start from Classic Obby, retain its sequential track and checkpoints, and add the requested puzzle gates, shortcuts, collectibles, boosts, and exit.

## Config requirements
Draw `path-track` as about twelve distinct key-room stages in one ordered chain. Use `obstacle-jump` for vertical structures and jump-pad approaches, `path-shortcut` for hidden alternate lines, and `gate-progression` for physical puzzle doors. Draw `checkpoint-respawn` pads at stage starts and `winner-zone` as the marked exit key. Include secret side alcoves, speed-boost lanes, jump pads, and collectible-route landmarks without adding unrelated scenery.

## Layout requirements
Place about twelve `checkpoint-respawn` functions, one at each stage opening. Place `collectible-nodes` for keys and coins along the main route and riskier side routes, including secret areas. Place `powerup-buffs` on the visible speed lanes and jump pads. Place one `winner-zone` trigger on the exit key. All critical jumps must remain within 11 studs horizontally and 7.2 studs vertically.

## Layout components
Build a flat giant keyboard world with about twelve selected keys expanded into distinct themed rooms or platforms. Link them in a readable start-to-exit sequence, with occasional doors between keys and short vertical obstacle structures rising within stage footprints. Add hidden bypasses that reconnect downstream, compact secret side areas, visible collectible lines, boost lanes, and jump pads. Keep non-course keys as boundary scenery or fall space. Frame the whole compact board so the route, side branches, and final exit key remain legible.

## Render order
Use `topdown`: the complete stage chain, reconnecting shortcuts, puzzle gates, and legal platform spacing must be valid before visual dressing.

## Scale, theme, and pipeline cost
The scale is medium, driven by about twelve key-room stages. The theme is bright, polished, original keyboard fantasy. Use `P6` because the obby route and every reconnecting shortcut must be valid by construction.
