# Scene prompt
Create a 3D game map showing a flat, bright stylized cartoon field with collectible leaves scattered across the ground.

# Agent decision
## Genre
The dominant genre is Simulation, canonical genre `simulation`, because collecting leaves to buy upgrades makes the rising incremental economy the game rather than simple exploration.

## Shape and preset
Use `world-open`, interpreted here as one shared, persistent flat field where every player gathers leaves. The closest family is Incremental Simulator, but the preset is none because its storefront hub, purchase gates, and hub-to-production circulation are not present in the spatial brief and should not be invented.

## Config requirements
No canonical image-config option is required. The image should establish a broad, unobstructed cartoon grass field with a bright palette and a clearly readable ground surface; the collectible leaves themselves belong to layout placement rather than the base image.

## Layout requirements
Use `collectible-nodes` for the leaves. Place many individual leaf pickups across the traversable field in a loose, even scatter, preserving enough spacing for each pickup to read clearly and avoiding an unusable concentration at the spawn edge. The prompt gives no exact leaf count, so no numeric count should be inferred.

## Layout components
The build is a single flat field zone with no internal barriers, buildings, roads, water, or relief. Its terrain is level stylized green ground extending across the whole playable area. Leaf pickup sites should cover the field while leaving a modest clear arrival patch near one edge. The boundary should be visually soft but unmistakable, such as a distant cartoon hedge or low perimeter fence, without creating additional zones. Compose the scene from a slightly elevated angle so the field’s breadth and the distributed leaves are both legible.

## Render order
Use `isometric`: render the bright stylized field first as the authoritative image, then derive the top-down plan, because no topology-sensitive route needs construction.

## Scale, theme, and pipeline cost
The scale is medium, driven by the need for a useful collectible scatter across one field. The theme is bright stylized cartoon countryside. Use `P0`; the map is one flat, walkable surface with no overhangs, transitions, or separate maps.
