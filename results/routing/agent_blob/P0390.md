# Scene prompt
Create a 3D meme-bright cartoon game map with colorful, simple environments. An open central collection area leads toward a clearly separated safe zone, with larger brainrot characters positioned around the active paths. Place multiple individual player bases around the safe zone, each with its own area for displaying collected brainrots.

# Agent decision
## Genre
The dominant genre is Simulation because collecting, displaying, and earning from brainrots is the persistent loop. Survival is secondary because larger hostile brainrots chase collectors back to safety.

## Shape and preset
Use `plot-isolated`: multiple equally spaced personal bases ring shared activity ground without overlapping. The preset is Sandbox, retaining its personal plots and shared collectibles while replacing its generic shop hub with the requested safe zone.

## Config requirements
Use `path-circulation` for broad active routes from the central collection ground to the safe zone and onward to every base. Draw the safe zone as a bright protected plaza with an unmistakable boundary. Draw multiple large hostile brainrot character models along active paths and equip each player base with a dedicated display area and clear placement pedestals; these are scene-specific geometry without canonical option IDs.

## Layout requirements
Place `collectible-nodes` as multiple collectible brainrots across the open central area and along exposed approach paths, never inside the safe zone. Place `spawner-npc` origins for larger hostile brainrots around the outer collection ground, with patrol ground that reaches the active paths but stops at the safe boundary. Add one ownership marker and a set of brainrot display slots to each individual base, with no canonical IDs.

## Layout components
Build an open central collection field connected by several wide paths to one clearly bounded safe-zone plaza. Arrange multiple equally sized personal bases in a ring outside or around that plaza, each separated from its neighbors and facing inward for easy navigation. Every base contains a display pad area for collected brainrots. Larger brainrot figures occupy the exposed route network, while colorful simple props frame the collection ground. Keep the safe zone central and visually dominant in the composition.

## Render order
Render `isometric` first and make it authoritative, because the colorful spatial identity and readable relationship among field, safe zone, and bases lead the design.

## Scale, theme, and pipeline cost
Scale is medium, driven by multiple player plots around one shared field. The theme is meme-bright, colorful cartoon absurdism. Use `P0`; all play occurs on one open, non-overlapping surface.
