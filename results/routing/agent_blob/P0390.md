- [author] goal — Q: Is the base one per player, or one shared base everyone places into? A: Give each player their own base so they can place and collect money from their own brainrots.

## Enriched image prompt
Create a colorful, simple 3D collection-and-chase map in a meme-bright cartoon style. Place one shared open collection field in the center, with cool small collectible creatures distributed across reachable ground and larger hostile creatures roaming the field. Arrange equal, clearly separated personal base plots around the outside, one per active player. Give every base a visible safe deposit area where its owner can place collected creatures for display and earnings. Connect the shared field to all bases with short, broad routes that offer multiple ways back and avoid dead-end corners. Keep the collectible field dangerous and the individual bases visually safe and easy to identify.

## Genre
Simulation is dominant, with Survival secondary for the chase back to safety.

## Shape and preset
Use `plot-isolated`, Isolated Per-Player Plots, because each player has an independent base for placed collectibles. Use the Sandbox preset, retaining its isolated plots and collectible loop while replacing the generic shared hub with the requested personal safe bases.

## Config requirements
Use `resource-shared` for the central brainrot collection field used by everyone and `path-circulation` for broad return routes from that field to every personal base. The isolated base plots are the safe display grounds. Do not add interiors, towns, shops, or unrelated progression gates.

## Layout requirements
Use `collectible-nodes` for small brainrot pickups distributed across the shared field. Use `spawner-npc` for larger hostile brainrots, with origins and patrol ground kept inside the shared field and away from the bases. Use `trigger-task` at one deposit/display station on each player plot. Place one free-text SafeZone over each personal base so a successful return is spatially explicit. The collection index and money calculation are mechanics.

## Layout components
The map has one central shared collection-and-chase zone surrounded by a repeating ring of equally sized, non-overlapping personal base plots, one per active player. Broad paths connect every plot to the shared center through more than one approach, preventing forced dead ends during a chase. Small collectible creatures occupy accessible field locations; larger threats patrol only the central ground. Each base has a visible safe boundary and one place-down display station. The outer plot ring forms the map boundary.

## Render order
Use `topdown`: the equitable plot spacing, shared-field access, and multiple safe return routes should be established before meme-bright dressing.

## Scale, theme, and pipeline cost
Scale is medium, driven by readable collectible creatures and distinct personal bases around one shared field. The theme is a colorful simple meme-cartoon world. Use `P0`; the map is one continuous surface with no overhang, interior transition, separate map, or validity-critical procedural route.
