## Enriched image prompt
Create a compact 3D forest search map with an eerie, unsettling atmosphere. Arrange dense but traversable trees around open patches so a player can search the whole area within a few minutes. Place one partially concealed, reachable destination for the missing person near the far side of the forest, with enough surrounding ground for the discovery to read clearly. Use the player's own avatar only as gameplay identity; do not add random player substitutes to the environment.

## Genre
Adventure is dominant because the activity is exploring a forest to locate a narrative target.

## Shape and preset
Use `world-open`, Open World, as one contiguous forest that can be searched in any order. The preset is none because a single-person search does not justify the multiple collectible nodes, quest board, hidden alcoves, or landmark bundle of the available Adventure presets.

## Config requirements
Use the visible portion of `npc-population` for the single missing person and the small discovery clearing they occupy. Keep tree clusters and search clearings as scene-specific forest geometry; no unrelated landmarks or quest structures are added.

## Layout requirements
For `npc-population`, place one Zone for the missing person near the far side of the map, partially screened by forest but reachable from the rest of the search ground. No hostile spawner, collectible set, or checkpoint is required.

## Layout components
One compact forest zone fills the frame. Dense tree clusters create partial concealment while several connected open patches preserve circulation. The missing-person destination sits toward the far edge in a small readable clearing. A thicker tree belt forms the natural boundary, and no separate maps or enterable structures are present.

## Render order
Use `isometric`: render the eerie forest composition first and derive the plan from it, because the search space does not require exact procedural topology.

## Scale, theme, and pipeline cost
Use medium scale so individual trees, the discovery clearing, and a person remain legible while the map still takes a few minutes to search. The theme is eerie and unsettling forest. Route `P0` because the build is one grounded exterior surface without overhangs, interior transitions, or separate maps.
