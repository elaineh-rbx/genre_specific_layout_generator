# Scene prompt
Create a 3D game map set in an eerie, unsettling forest search area compact enough to cross in a few minutes of walking, with dense woodland paths and clear spaces for finding a missing person.

# Agent decision
## Genre
The dominant genre is Adventure because the player explores a forest toward one narrative search objective. The request to use each player’s own avatar is a character-system requirement and does not alter the map.

## Shape and preset
Use `world-open` for one compact forest search area that can be investigated in any order. The closest preset is Exploration, retaining its free exploration structure and trail network while replacing its unrequested landmark and secret alcoves with the missing-person destination.

## Config requirements
Use `path-trail` for dense but legible woodland paths connecting the search clearings. Use `npc-population` for the one missing person and the clear patch of forest they occupy. Add dense eerie trees, undergrowth, roots, fallen logs, rocks, and sparse clearings as explicitly requested scene geometry.

## Layout requirements
Place the functional half of `npc-population` once for the missing person, in a reachable clearing away from the initial entrance but connected to the path network. Place one player start marker at a clear forest trailhead, oriented into the main search path. The missing-person clearing should not be visible directly from spawn, but must have at least one plainly walkable approach.

## Layout components
Build one compact woodland zone crossed by a branching network of footpaths. Start with a modest trailhead clearing, then divide the route among several small search clearings before reconnecting around the missing-person location. Use dense tree clusters, shadowed undergrowth, exposed roots, damp earth, mossy rocks, and occasional fallen logs to create unease without obstructing every sightline. Keep the terrain mostly continuous and walkable, with gentle variation rather than cliffs or tunnels. A dense outer tree wall and impassable brush enclose the play space. Compose the forest with a readable foreground trail, layered dark trunks in the middle ground, and the objective clearing deeper within the map.

## Render order
Render in `isometric` order because the eerie woodland mood and layered sightlines lead, while the compact path plan can be projected afterward.

## Scale, theme, and pipeline cost
Use a small scale, explicitly only a few minutes across on foot. The theme is eerie, damp, shadowed woodland with restrained realism. Route through `P0`; this is one continuous outdoor surface with no required interiors, overhangs, or separate maps.
