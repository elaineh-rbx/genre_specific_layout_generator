# Scene prompt
Create a 3D sci-fi runner-style corridor shooter with a fixed player position near the foreground, able to shift only left and right. Two parallel lanes scroll toward the player: one lane carries approaching enemy drones, while the other carries upgrade walls that can be shot. Build the space as finite, short corridor levels with a clear endpoint beyond the advancing lanes.

# Agent decision
## Genre
The dominant genre is Shooter, with Infinite Runner secondary for the automatic world scrolling and lateral reaction play. The finite levels prevent Infinite Runner from owning the classification or its genre-wide route.

## Shape and preset
Use `lane-snap` from outside Shooter’s usual set: exactly two rigid parallel lanes cross the fixed player’s lateral movement band. The preset is Lane Runner, retaining its lane geometry and moving-obstacle concept while replacing endless modular chunks and coin trails with finite shooter content.

## Config requirements
Use `obstacle-moving` for the enemy drones advancing along one lane. Use `hazard-kill` for the enemy front that ends the run if it reaches the player. Draw shootable sci-fi upgrade walls advancing in the second lane, and keep both lanes visually distinct all the way to the endpoint.

## Layout requirements
Use `spawner-npc` at the far end of the enemy lane to emit drones toward the player. Place `powerup-buffs` against each visible upgrade wall in the upgrade lane. Place one fixed player start spanning a left-right movement line near the foreground and one terminal trigger at the far endpoint of each short level.

## Layout components
Build a short straight sci-fi corridor with two parallel lanes: one drone lane and one upgrade-wall lane. Both begin beyond the foreground player line and converge visually on a clear finite endpoint. Side barriers enforce the corridor, while lane markings preserve the two choices. Compose symmetrically from the fixed player view so both incoming streams remain readable.

## Render order
Use `topdown`: lane separation, scroll direction, and endpoint continuity must be valid before dressing.

## Scale, theme, and pipeline cost
Scale is small, reflecting finite short levels. The theme is clean sci-fi combat with drones and technological upgrade gates. Use `P6` because `lane-snap` requires structurally valid lane geometry.
