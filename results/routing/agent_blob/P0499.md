# Scene prompt
Create a high-fantasy multiplayer game map with up to 8 separate player base plots, each containing its own visible 3D grid for arranging swords and other fantasy-style base equipment. Arrange the plots as distinct, evenly spaced base areas within a shared map, with open approach space around each base for monster waves.

# Agent decision
## Genre
The dominant genre is Strategy, with Puzzle secondary because the author explicitly frames the physical item-combining grid as a puzzle system. Defending separate economies against monster waves remains the map-defining activity.

## Shape and preset
Use `plot-isolated`, taken from outside Strategy’s usual shapes: eight massive, independent, evenly spaced plots prevent one player’s base from overlapping another. The preset is none; neither a shared battlefield nor a tabletop puzzle preset captures separate walkable bases with wave approaches.

## Config requirements
`tile-grid` draws one clearly divided, visible 3D merge grid inside each player plot, for eight grids total. `tracker-core` draws one fantasy base-heart structure beside each grid, also eight total. Each plot includes broad open ground around the grid for arranging swords and other fantasy equipment while keeping monster approaches clear.

## Layout requirements
Place eight `tracker-core` objective markers, one on each base-heart. Place eight `spawner-npc` wave origins, one at the outer edge of each plot and aimed toward its corresponding base. The grid cells themselves remain visible geometry; item drops, purchasing, merging, and equipment statistics are mechanics rather than additional layout placements.

## Layout components
Build one shared map containing eight equal, separated player plots arranged in a spacious ring. Each plot has a central square 3D grid, an adjacent defended base-heart, and a broad open approach extending outward to its monster origin. Simple paths connect the inner edges of the plots without crossing wave approaches. Use level stone-and-grass ground, low plot borders, sword racks, banners, and fantasy equipment silhouettes. A fortified perimeter encloses the shared map. Frame the composition high enough to show all eight plots and their one-to-one symmetry.

## Render order
Use `topdown`: the eight plots, grids, cores, and wave approaches must remain clearly separated and consistently paired before the isometric dressing pass.

## Scale, theme, and pipeline cost
Scale is large because eight independent bases need usable approach space. The theme is straightforward high fantasy with stonework, banners, swords, and monster-facing fortifications. Use `P0`; all permanent geometry lies on one non-overlapping surface.
