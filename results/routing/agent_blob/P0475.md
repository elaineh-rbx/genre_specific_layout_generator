# Scene prompt
Create a 3D game map showing a small, quirky, stylized contemporary suburban neighborhood for a lighthearted mystery game, with traversable streets and neighborhood locations that can serve as settings for self-contained cases involving missing items or unexplained events.

# Agent decision

## Genre
The dominant genre is Adventure, with Puzzle secondary. Traversing a neighborhood and discovering case locations is the spatial backbone, while solving each mystery supplies the puzzle progression.

## Shape and preset
Use `world-open` as one small contiguous neighborhood whose streets and case locations can be visited freely. The preset is none: Scavenger Hunt partly fits missing-item cases, but its hidden alcoves and physical quest board were not requested, while the broader unexplained-event cases need sequenced mystery locations instead.

## Config requirements
Draw `path-trail` as a readable network of traversable suburban streets and sidewalks linking every case setting. Draw `gate-progression` as subtle physical closures at later case locations that can open after the previous mystery is solved. Use `settlement-density` for a small, coherent neighborhood of quirky contemporary houses, yards, corner lots, and civic or commercial locations rather than isolated buildings. Give each case location a distinct silhouette and prop cluster so players can recognize it from the street.

## Layout requirements
Place `collectible-nodes` as missing objects and inspectable evidence at their scene-specific hiding places, attached to believable props rather than scattered randomly. Place one case-start marker and one case-completion trigger at each mystery location. Sequence the completion triggers so each solved case unlocks the next location, but keep the street network continuously traversable. The prompt gives no case count, so do not invent a fixed quantity.

## Layout components
Build one small suburban district with a central street loop, short side streets, sidewalks, front yards, and several visually distinct neighborhood locations suitable for self-contained mysteries. Keep walking distances short and use fences, hedges, parked vehicles, mailboxes, and playful signage as spatial clues and boundaries. Avoid a maze: intersections should preserve easy orientation and return routes. Compose the neighborhood around a readable main street with case sites distributed along and just off it.

## Render order
Use `isometric`: render the quirky neighborhood character first, then derive the uncomplicated connected street plan; exact topology is not itself the puzzle.

## Scale, theme, and pipeline cost
Scale is small, as explicitly requested for a compact neighborhood. The theme is quirky, stylized, contemporary suburban mystery with a lighthearted tone. The route is `P0`; one flat connected exterior map captures all required geometry.
