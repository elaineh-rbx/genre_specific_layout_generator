# Scene prompt
Create a bright anime-fantasy 3D game map built as a cluster of colorful floating islands with glowing crystals and dramatic waterfalls dropping into the clouds below. The central main island holds a giant crystal castle, with five separate temple islands arranged around it and connected by long bridges; each temple is visually distinct and serves as a boss arena. Design this as the starting map within a set of separate level-unlocked maps, creating the feeling of a vast world without one continuous trillion-block landmass.

# Agent decision

## Genre
The dominant genre is RPG (`rpg`) because XP, levels, weapon upgrades, coins, enemies, and level-unlocked maps drive progression. Action (`action`) is secondary because mobs and five temple bosses define the encounters.

## Shape and preset
Use `world-chaptered`, taken from outside RPG’s usual shape set: the displayed island kingdom is the starting chapter within a set of genuinely separate level-unlocked maps. The preset is none because no RPG preset honestly matches both the chapter structure and radial floating-island boss layout.

## Config requirements
Draw `island-cluster` as one central castle island plus exactly five temple islands; `landmark-focal` as the giant glowing crystal castle; `hazard-kill` as exposed island and bridge edges over the clouds; `choke-bottleneck` as five long bridges leading to boss arenas; and `terrain-relief` as dramatic raised island profiles. Draw `water-body` as waterfalls dropping from island edges, while each temple receives a distinct bright anime-fantasy silhouette.

## Layout requirements
Place one protected player start near the crystal castle and `spawner-npc` emitters for the opening mobs on nearby combat ground, clear of the spawn itself. Place one boss emitter at each of the five temple arenas, for exactly five bosses. Place one travel endpoint in the castle hub for each future level-unlocked map; these links are progression markers, not additional starting-map geometry.

## Layout components
Build exactly six floating islands: one large central island with a giant crystal castle and five smaller temple islands arranged radially around it. Connect each temple directly to the central island with one long bridge, for five bridges total. Give every temple an open collision-clean boss arena and unique architecture. Add glowing crystal outcrops, colorful terrain, clouds below, and dramatic waterfalls spilling from island edges. Keep the outer boundary open to sky and compose the castle as the dominant center with all five temples readable around it.

## Render order
Use `topdown`: render the radial plan first and make it authoritative so all five bridges connect cleanly and every boss island remains reachable.

## Scale, theme, and pipeline cost
Scale is large, driven by six islands and future separate maps, not the rejected trillion-block request. The theme is bright anime fantasy with glowing crystal architecture. Use `P4` for level-unlocked separate maps and `CHECK` for floating-island open-air play and waterfalls.
