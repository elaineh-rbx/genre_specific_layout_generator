## Enriched image prompt
Build a compact separate lobby room with gathering space for 1–4-player groups and a clear teleport departure point. Its destination is a large enclosed horror maze sized for a roughly 10–15 minute four-player run. Generate a valid route from entrance to exit while preserving random true dead ends. Line the maze with dark corridors, volumetric fog, heavy shadows, realistic flickering lights, small side rooms, and hiding spots that provide evasive cover near dead ends. Distribute exactly five generator-repair stations, each paired with one key fragment, across distinct maze branches. Place a locked exit gate at the terminal edge. The pursuer is a player-proportioned pitch-black figure with glowing white eyes; reserve concealed approach points around the maze and support a final dark-red emergency-light state.

## Genre
The dominant genre is Survival because a stalking threat and escape under pursuit define play. Puzzle is secondary because five generator interactions and fragments unlock the exit.

## Shape and preset
Use `puzzle-maze` from outside Survival’s usual shapes: the maze’s solvable topology is the main space. Match Puzzle’s Maze / Labyrinth preset, but explicitly drop `path-loop` because the author requires true dead ends. The maze is the dominant top-level shape; the small lobby is a separate subordinate map.

## Config requirements
Use `cover-los` for hiding spots and small side rooms near dead ends. Use `gate-escape` for the locked terminal exit. Use `trigger-task` from the shared catalogue for five visible generator-repair stations. Use `teleporter-link` as the group departure point between the lobby and maze maps. No ambient population is added.

## Layout requirements
Place exactly five `collectible-nodes` key fragments, each beside a different generator station. Place the layout half of exactly five `trigger-task` stations at dispersed branches rather than along one corridor. Place `spawner-npc` origins at concealed approach points distributed around the maze, including one persistent final-phase origin away from the exit gate. Place the `gate-escape` win trigger at the maze exit. Pair the lobby and maze `teleporter-link` endpoints.

## Layout components
There are two map segments: the main `puzzle-maze` map and one `interior-single` lobby room. The maze contains an entrance, connected corridors, random true dead ends, small rooms, hiding recesses, five generator-and-fragment sites, concealed hostile approaches, and one exit gate. Keep all dead ends reachable and the entrance-to-exit route valid. The lobby contains only compact group waiting and teleport space.

## Render order
Use `authored_plan`: generate and solve the maze blueprint before top-down and isometric dressing, because a sealed route would make escape impossible.

## Scale, theme, and pipeline cost
Use medium scale, balancing a 10–15 minute search with legible small rooms, generators, and hiding spots. The theme is polished Roblox horror with realistic low lighting, fog, shadows, flicker, and emergency red accents. Use `P6` for valid maze construction and `P4` for the separate lobby and maze maps.
