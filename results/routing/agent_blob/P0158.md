# Scene prompt
Create a Roblox horror game layout for “Yourself” with a small separate multiplayer lobby room leading into a large, compact maze designed for a roughly 10–15 minute four-player search. The maze is a dense network of shadowy corridors with random true dead ends, intermittent small rooms, and concealed hiding spots arranged to give players occasional escape routes. Scatter five distinct key-fragment locations throughout the maze, each set in or beside a generator repair area. Use heavy fog, flickering lights, deep shadows, and a dark industrial-horror atmosphere. Place a locked exit gate at the maze perimeter as the final destination. In the final escape state, shift the maze lighting to dark red and add visible emergency alarm fixtures along the corridors. The pursuing figure is a black, player-shaped humanoid silhouette with glowing white eyes, appearing against the maze’s darkness.
