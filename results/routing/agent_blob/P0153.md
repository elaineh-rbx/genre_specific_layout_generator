# Scene prompt

Create a 3D horror survival map set in a pitch-black, claustrophobic underground facility on one compact floor. Build a labyrinth of narrow corridors, small connecting rooms, walls, doors, obstacles, and floor traps, with routes able to rearrange during a round. Scatter throwable decoy objects such as rocks and alarm clocks through rooms and corridors. Place a distinct exit at the far end of the facility, reached through the unreliable maze.

# Agent decision

## Genre

Survival is dominant because players evade a noise-seeking blind monster while escaping. Puzzle is secondary because echolocation is used to navigate a shifting labyrinth and its traps.

## Shape and preset

Use `puzzle-maze`, taken from outside Survival’s usual set, because a compact labyrinth with a reachable exit needs authored solvable topology even while routes rearrange. Use the Puzzle genre’s Maze / Labyrinth preset, retaining its loop corridors and collectible-object intent, then add the Survival exit and hostile origin.

## Config requirements

Use `path-loop` for narrow facility corridors that reconnect through small rooms; `hazard-kill` for floor traps embedded in the route; and the visible half of `gate-escape` for a distinct exit structure at the far end. Draw modular walls, doors, and obstacles with clear echolocation-readable silhouettes and interchangeable corridor segments that support rearrangement. Keep the facility pitch-black in presentation, but do not encode sound-wave effects as geometry.

## Layout requirements

Place `collectible-nodes` as throwable rocks and alarm clocks scattered across multiple rooms and corridor branches; no count is stated. Place one `spawner-npc` for the blind monster on connected patrol ground away from the survivor arrival. Place the functional half of `gate-escape` at the far-end exit. Place one survivor start marker at the opposite side. Register each movable wall or door segment with valid alternate connections so every rearranged state preserves a route to the exit.

## Layout components

Build one compact single-floor underground facility bounded by hard walls. A survivor start area feeds a dense maze of narrow corridors, small connector rooms, doors, obstacle pinch points, and several loops. Distribute traps and decoys across side branches without blocking circulation. The exit occupies a distinct terminal room across the facility from the start. Use modular junctions and sliding wall or door assemblies for shifting routes, but keep fixed safety paths and patrol clearances. Compose the plan as a dense irregular rectangle with no exterior.

## Render order

Use `authored_plan`: code generates the maze and its valid rearrangement states first, and that blueprint remains authoritative so every state keeps the exit reachable.

## Scale, theme, and pipeline cost

Scale is small, fixed to one compact floor. The theme is pitch-black industrial claustrophobia revealed in momentary echolocation outlines. Use `P6` because both the initial maze and every rearranged route state must be valid by construction; no stacked surface or exterior transition is present.
