# Scene prompt
Create a 3D adventure map set in a dense magical pine forest at dusk. A narrow dirt path forms a short, guided route through tightly packed tall realistic pine trees, with glowing red and green mushrooms scattered beside the path and among the forest floor. Use moody, foggy atmospheric lighting that limits distant visibility; the path leads from the foreground through the dense midground forest to a small mysterious glowing clearing as the destination.

# Agent decision
## Genre
The dominant genre is Adventure: this is a purely exploratory guided journey with a clear spatial destination and no combat or hostile survival loop.

## Shape and preset
Use `route-guided` for one short directed dirt path through the forest. The closest preset is Guided Trail, retaining the path and destination landmark while omitting its interior-to-exterior reveal option because this scene stays outdoors throughout.

## Config requirements
Use `path-trail` for the narrow dirt route threading between tightly packed pines. Use `landmark-focal` for the small mysterious glowing clearing that pulls the player to the end of the route. Add glowing red and green mushrooms beside the path and across the forest floor as explicit scene-specific geometry.

## Layout requirements
No collectibles, checkpoints, NPC spawners, triggers, or other post-segmentation placements are required. The physical end clearing itself is the destination; its approach must remain unobstructed and reachable along the path.

## Layout components
Build one narrow dirt path beginning in the foreground, bending through a dense midground of tall realistic pine trees, and terminating at one small glowing clearing. Keep the route focused with no major branches, using tree trunks, roots, moss, needles, rocks, low ferns, and fog-softened undergrowth to enclose it. Scatter both red and green luminous mushrooms along path edges and in visible pockets between trees, reserving the strongest glow for the destination clearing. Dense impassable woodland forms the outer boundary. Compose the map as a clear foreground-to-background progression: path entrance first, dark layered pines through the middle, and the clearing glow visible only as a distant pull through fog.

## Render order
Render in `isometric` order because the dusk lighting, fog depth, mushroom glow, and path-to-clearing composition lead; the simple route plan can be projected afterward.

## Scale, theme, and pipeline cost
Use a small scale, driven by a short atmospheric walk. The theme is moody magical realism at foggy dusk, with restrained red and green bioluminescence. Route through `P0`; the scene is one continuous outdoor surface with no required overhang, interior transition, or separate map.
