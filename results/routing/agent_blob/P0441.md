## Enriched image prompt
Create a realistic small arcade-room display centered on exactly one playable 3D pinball machine. Model the machine with a cabinet, glass-covered inclined playfield, ball, flippers, bumpers, targets, rails, ramps, lights, and an upright backbox, all composed for a fixed first-person viewing position directly in front of it. Place a few additional arcade cabinets only as unplayable peripheral set dressing, without competing with the pinball machine. Keep the room compact and visually realistic. No walking route is needed; choosing pinball from the menu places the view at the machine, and the controls remain UI buttons rather than physical floor objects.

## Genre
The genre is Simulation because the first playable build is a realistic operated model of a physics-based pinball machine.

## Shape and preset
Use `set-display`, Zone (Display Set), taken from outside Simulation's usual set because the machine is the deliverable and the room is arranged to view and operate it without walking. Preset is none: Physics Sim would add hazards and circulation that this fixed display does not need.

## Config requirements
Use `physics-rig` for the realistic pinball cabinet and its inclined playfield, flippers, bumpers, ramps, rails, targets, ball, and reactive assembly. Use `spawn-first-reveal`, reached from Entertainment, for a clear fixed viewing bay directly in front of the playable machine. Additional cabinets are simple unplayable background props.

## Layout requirements
Place `spawn-first-reveal` as one SpawnZone or fixed view anchor centered in front of the pinball cabinet and aimed at the complete playfield and backbox. No traversal markers, cabinet triggers, or placements for the UI controls are needed; the menu selects the machine and the buttons operate it from the fixed view.

## Layout components
The build is one small enclosed arcade room arranged around one playable pinball display. The main machine occupies the focal wall and a clear viewing bay sits directly in front. A few unplayable cabinets line peripheral walls as dressing. The room boundary is closed and there is no player circulation route. Compose the frame so the pinball playfield, cabinet depth, controls, and backbox dominate while secondary cabinets remain readable as context.

## Render order
Use `isometric`: realistic machine form and room composition lead, and no walkable topology or computed route is involved.

## Scale, theme, and pipeline cost
Use small scale, corresponding to Room, because the single machine and its mechanical parts must remain legible. The theme is a realistic compact arcade with one detailed pinball centerpiece. Use `P0` plus `SET`: the room and machine are real geometry, but nobody walks through the build.
