# Scene prompt
Create a small, dense FPS arena set in a sunflower garden, built for 8 players. Arrange tall sunflower rows as cover, with clear lanes running between the rows for movement and sightlines.

# Agent decision
## Genre
The genre is Shooter, with no secondary genre. The original brief explicitly defines an eight-player free-for-all FPS.

## Shape and preset
Use `lane-network`, with clear routes threaded between dense sunflower rows. The preset is none: the free-for-all brief does not support opposing team bases, bomb sites, elevated firing positions, or world pickups, so the published mode bundles would add unrequested geometry.

## Config requirements
Use `cover-los` by alternating tall full-body sunflower rows with shorter planter edges and gaps that provide waist-high peeking cover. Use `path-loop` so cross-paths reconnect the long garden lanes and prevent dead ends. Show `spawn-protected` as small recessed clearings screened by dense flowers and garden structures, while keeping the central lanes readable.

## Layout requirements
Place exactly 8 functional `spawn-protected` markers in separate perimeter clearings, distributed evenly around the arena and oriented toward different lanes. Each spawn must be screened from every other initial spawn and from the longest sightlines. No team bases, capture zones, loot, powerups, or NPC spawners are required.

## Layout components
Build one small, dense rectangular garden arena. Arrange tall sunflower beds in long parallel and slightly offset rows, creating several clear firing lanes with short cross-paths that reconnect them into loops. Break up the rows at measured intervals with low planter walls, gardening benches, trellises, watering tanks, and open soil patches, all serving as readable cover without cluttering movement. Reserve a modest central crossing as the main engagement space and place the eight screened spawn clearings around the outside edge. Enclose the map with a hedge and low garden fence. Use flat earth and grass terrain, and frame the map from a raised diagonal angle that clearly reveals lanes, cross-connections, and the strong yellow-green flower pattern.

## Render order
Use `topdown`: balanced spawn separation, connected lane circulation, and controlled sightlines must be laid out first, then dressed into the authoritative isometric garden view.

## Scale, theme, and pipeline cost
Scale is small, driven by the explicit eight-player arena scope. The theme is a dense, sunny sunflower garden with grounded FPS readability. Use `P0` because all play occurs on one flat, contiguous outdoor surface.
