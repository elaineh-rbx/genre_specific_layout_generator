# Scene prompt
Create a 3D zombie-apocalypse map set inside a spooky, abandoned single-room arcade. The compact arcade floor is filled with rows of decayed game cabinets, prize machines, scattered tables, and damaged counters, with open aisles and clear spaces between them for movement; dim, eerie lighting frames the room.

# Agent decision
## Genre
Survival is dominant, with Shooter secondary because the goal is to outlast timed zombie waves using guns.

## Shape and preset
Use `interior-single`: the entire playable map is one compact arcade room and the player never crosses an exterior boundary. Preset is none. Horde Defense captures the wave mode but assumes a generic bounded arena with destructible structures and hiding cutouts that the brief does not request.

## Config requirements
Draw one spooky abandoned arcade interior with rows of decayed game cabinets, prize machines, scattered tables, and damaged counters. Arrange these props into navigable aisles and localized sightline breaks without turning them into dedicated hiding lockers or adding unrequested destructible behavior. Use dim eerie lighting, dead screens, grime, and restrained decay to establish the zombie-apocalypse atmosphere.

## Layout requirements
Use `spawner-npc` for zombie wave origins placed at several separated points along the room perimeter, sited so zombies enter through readable aisles rather than appearing beside the player. Place one unkeyed player spawn in a clear central or near-central floor pocket with multiple escape directions. The timer is gameplay and adds no layout volume.

## Layout components
The map is a single room-sized rectangular arcade. Cabinet rows occupy the main floor in short parallel clusters, separated by open cross-aisles; prize machines sit near one side, damaged counters line another edge, and scattered tables punctuate wider movement pockets. Every prop stays grounded on one floor. Solid arcade walls enclose the boundary, with no outside area or secondary room. Compose the scene diagonally across the aisles so the room’s compactness, prop variety, and clear movement channels all read at once.

## Render order
Use `isometric`: the abandoned-arcade mood and prop composition lead, then the uncomplicated floor plan is derived from that authoritative image.

## Scale, theme, and pipeline cost
Scale is small, explicitly one room-sized arcade floor. The theme is dark, decayed arcade horror with eerie low light. The route is `P0`; the whole map is one enclosed ground surface, so there is no outside-to-inside transition or occluded level.
