# Scene prompt

Create a compact clean-tech-lab puzzle room with bright minimal walls and lighting, centered on a room-sized floor laid out as a standard computer keyboard. Build the keyboard from oversized 8x8-stud key tiles arranged in recognizable letter rows, including distinct Delete and F4 keys; leave a clear approach around the floor edges. Place a locked exit door on one side of the room beyond the keyboard, with the intended letter-tile route leading across the floor toward it.

# Agent decision

## Genre

The genre is Puzzle: progress depends on crossing letter tiles in the correct sequence to unlock the room.

## Shape and preset

Use `interior-single`, making one enclosed clean-tech laboratory the entire map. Start from the Word / Quiz Puzzle preset but substitute this interior shape for its open puzzle space because the prompt explicitly calls for a room.

## Config requirements

Draw `gate-solve` as a locked exit door beyond the keyboard floor. Add `button-solve` as oversized pressable letter keys forming the input sequence. The standard keyboard must include recognizable staggered letter rows and distinct F4 and Delete tiles, with each tile measuring 8 by 8 studs. Also draw selected trap keys so they look physically separable from the supporting floor while remaining visually ambiguous until activated.

## Layout requirements

Place the functional side of `button-solve` on every key tile so crossings can register in order; mark the intended E-S-C-A-P-E sequence as six ordered inputs leading toward the door. Site trap triggers on Delete, F4, and selected letter tiles, with each trigger tied to its own falling or lethal tile. Place one `gate-solve` unlock target on the exit door after the final correct input.

## Layout components

Build one compact rectangular lab with bright minimal walls, an evenly lit ceiling, and a clear perimeter walkway. Center a room-sized keyboard floor made from 8-by-8-stud tiles, arranged in standard functional, number, and staggered letter rows. Keep F4 and Delete distinct and legible. Put the entrance approach on one short side and the locked exit door directly opposite, beyond the keyboard, so the intended letter route crosses the floor. Enclose the room completely and frame the composition around the keyboard grid and exit.

## Render order

Use `topdown`: draw the keyboard plan first because recognizable key adjacency and the ordered letter route are necessary for the puzzle to work, then dress that plan as the isometric lab.

## Scale, theme, and pipeline cost

The scale is small, driven by one compact room and 8-by-8-stud keys. The theme is bright, minimal clean-tech laboratory. Use `P0`; the entire puzzle occupies one visible interior surface with no outside transition or overhang.
