# Scene prompt

Create a bright, modern avatar-fashion mall with simple, open storefronts arranged for easy browsing. Each avatar shop faces the shared mall walkway, displaying outfit selections in clean retail-style sections without enclosed interiors.

# Agent decision

## Genre

The genre is Roleplay & Avatar Sim, focused on avatar customization rather than housing or town life.

## Shape and preset

Use `interior-single`: the entire map is one enclosed fashion mall, and players never cross between an exterior and an interior. The preset is none. Dress Up supplies runway and social-showcase assumptions that are absent here, while this brief is specifically a browsable catalog mall.

## Config requirements

Use `path-street` as a broad shared pedestrian mall walkway linking every open shopfront. Render the avatar shops as clean retail bays facing that circulation spine, with visible outfit displays divided into legible fashion sections. Do not use `building-interior`: the shops are intentionally open storefronts without separately entered rooms.

## Layout requirements

Place an outfit-selection interaction point at each displayed outfit or display grouping, aligned just in front of its retail bay so players can browse without blocking the main walkway. These are uncatalogued interaction triggers rather than drawn geometry. No teleporters, vehicles, NPC population, or property zones are required.

## Layout components

Build one bright, modern mall interior around a wide central pedestrian walkway. Arrange simple open storefront bays along both sides, all facing the shared circulation space and remaining fully visible from it. Divide each bay into clean retail-style outfit sections with display plinths, wall panels, mannequins or avatar stands, and generous clear floor in front for browsing. Connect the entire mall with the uninterrupted central path and short cross-aisles into each bay. Use a flat polished floor, bright neutral walls, strong store signage, and a sealed mall envelope; there are no back rooms or enclosed shop interiors. Frame the composition so the central walkway and repeated storefront rhythm are immediately readable.

## Render order

Use `isometric`: establish the bright retail character and storefront presentation first, then derive the top-down circulation plan; visual organization leads.

## Scale, theme, and pipeline cost

The scale is medium, driven by several browsable shop bays around one shared walkway. The theme is clean, bright contemporary avatar retail. Use `P0`; the map is a single flat interior with no outside-to-inside transition and no overhanging playable levels.
