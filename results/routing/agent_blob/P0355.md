## Enriched image prompt

Place a readable central fighting area with several substantial ruined structures and decayed barricades that break sightlines without clogging movement. Surround it with four distinct perimeter approaches where endless zombie waves can enter, each visible enough for defenders to read the incoming direction. Use rotten wood, corroded metal, crumbling masonry, damp ground, sparse sickly vegetation, and heavy low fog. Keep the boundary closed and the floor circulation simple, with no exit route or unrelated rooms. Frame the central holdout ground, all cover, and all four wave approaches in one isometric view.

## Genre
The dominant genre is Survival.

## Shape and preset
Use `space-bounded`, a BoundaryZone (Contained Arena), because the endless holdout takes place in one enclosed combat space. The preset is Horde Defense.

## Config requirements
Use `destructible-cluster` for rotting barricades and ruined structures that can break down under pressure. Use `cover-los` for substantial decayed cover around the central ground, with open lanes between it. The zombie actors themselves are placed by the layout stage rather than baked into the static image.

## Layout requirements
Place `spawner-npc` as exactly four Spawner origins, one at each perimeter approach, all aimed toward the central holdout area and none directly on the player’s starting ground. No exit gate is required because the mode continues through endless waves.

## Layout components
The map contains one central holdout zone, four perimeter approach lanes, distributed ruined cover, breakable barricade clusters, a continuous arena floor, and one enclosing boundary. Every approach connects directly to the center without hidden dead ends. Keep all four origins and the full boundary readable in frame.

## Render order
Use `isometric`: render the horror atmosphere and decayed arena composition first because the simple bounded topology does not need a computed plan, then derive the top-down layout.

## Scale, theme, and pipeline cost
The scale band is medium because cover and four wave approaches must remain legible across one arena. The theme is outright dark, foggy, rotting horror. The pipeline cost is `P0`: one bounded single-level surface needs no special structural pass.
