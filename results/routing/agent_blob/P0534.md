# Scene prompt
Create a 3D shared zoo management map as a bright modern, family-friendly park. Arrange six clear animal enclosures along clean visitor paths, with spaces suitable for animals, birds, and reptiles; use a welcoming central visitor area connecting the enclosure routes.

# Agent decision
## Genre
The genre is Simulation: the whole server jointly operates and visits one persistent zoo while progression unlocks animals.

## Shape and preset
Use `plot-shared` from the Tycoon preset: one right-sized zoo plot shared by all players. Keep its central hub and circulation, but omit a purchase-gated expansion wall because the brief unlocks animals within six already-built enclosures rather than locking whole map zones.

## Config requirements
`social-hub` is the welcoming central visitor plaza where every enclosure route begins and returns. `path-circulation` forms clean, family-friendly walking loops linking all six habitats without dead ends or service-road conflicts. `npc-population` draws the non-hostile zoo inhabitants in their appropriate enclosure ground. The six enclosures should be visibly distinct: animal paddocks, a tall bird habitat, and controlled reptile exhibits, all with modern fencing, viewing edges, signs, planting, and shelter.

## Layout requirements
Place six groups of `npc-population` habitat markers, exactly one group inside each enclosure and never on visitor paths. Keep each group constrained by its enclosure boundary and suited to that enclosure’s animal category. No event trigger positions are added because the scene brief does not define a physical event station.

## Layout components
Build one central visitor plaza with entry frontage, seating, signs, and six radiating or looping path connections. Arrange exactly six clear enclosures around it, balancing larger open paddocks with a tall enclosed bird habitat and smaller secure reptile exhibits. Paths should make a simple loop so visitors can see every habitat and return to the hub without backtracking. Use flat, clean modern paving, planted buffers, transparent viewing barriers, shaded animal shelters, and a continuous family-safe perimeter around the zoo. Compose the map in a welcoming isometric overview with the plaza centered and all six enclosures individually legible.

## Render order
Use `isometric`: the inviting park composition and visual hierarchy lead, then derive the top-down circulation plan from that authoritative view.

## Scale, theme, and pipeline cost
Scale is medium, driven by exactly six starter enclosures plus a central hub. The theme is bright modern zoological park design with clean materials, colorful wayfinding, and friendly landscaping. `P0` applies because the entire walkable zoo fits on one unobstructed surface with no forced extra capture pass.
